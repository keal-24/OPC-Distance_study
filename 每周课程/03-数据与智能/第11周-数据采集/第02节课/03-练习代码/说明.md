# 03-练习代码

**这个文件夹故意留空。** 本节课你要自己新建一个 Node 项目：

```text
03-练习代码/
└── collector/              ← npm init 在这里
    ├── node_modules/        ← npm install express 自动生成
    ├── package.json
    ├── mock-server.js       ← 11 个端点的假数据服务，端口 3001
    ├── first-fetch.js       ← 第一个读接口的脚本
    ├── error-case.js        ← 故意触发 SyntaxError
    ├── error-case-fixed.js  ← 先判状态码和类型再解析
    ├── limit-case.js        ← 429 重试
    ├── timeout-case.js      ← 超时
    ├── ua-case.js           ← 看自己的请求头
    └── 接口清单.md
```

## 为什么这些文件必须你自己敲

`mock-server.js` 有 200 多行，看起来像"作业的脚手架"，抄一遍也能跑。**但你必须自己敲**，因为后面五节课所有的"抓不到"都要靠它复现：

```text
第 73 节：你要能改 /html 的返回，造出"改版"
第 74 节：你要能解释 page=999 为什么返回 200 而不是 404
第 75 节：你要能说清 /api/dirty 里七个字段各脏在哪
第 76 节：你要用 /api/change 造出"一条数据变了"
第 77 节：你要靠 /api/limit 造出"这次跑失败了"
```

**这个文件从第 72 节一直用到第 77 节，一行都不用改。** 所以第一次敲的时候看清楚每个端点为什么这么写。

`first-fetch.js` 只有十几行，但它定下了这一周的动作顺序：先打印状态码，再打印内容类型，最后才 `json()`。

## 怎么建（一步步）

1. 打开 `第02节课\03-练习代码`，在地址栏输入 `cmd` 回车；
2. `mkdir collector` 然后 `cd collector`；
3. `npm init -y`、`npm install express`；
4. 新建 `mock-server.js`，把第 2 步的代码敲完；
5. `node mock-server.js`，看到 11 个端点列出来；
6. 另开一个 cmd，用 `curl.exe -i` 逐个请求，把结果记进 `接口清单.md`；
7. 依次写 `first-fetch.js`、`error-case.js`、`error-case-fixed.js`、`limit-case.js`、`timeout-case.js`、`ua-case.js`，每写完一个就 `node` 跑一次。

**遇到 `EADDRINUSE` 不要慌**，先回去找那个还开着服务器窗口，按 `Ctrl + C`。
