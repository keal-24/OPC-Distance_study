# 03-练习代码

**这个文件夹故意留空。** 本节课你要自己新建：

```text
03-练习代码/
├── 数据来源判断表.md      四节：四条路对比 / 判断顺序 / 合规五问 / 三个需求
└── decide.js              把判断顺序写成函数
```

## 为什么这些文件必须你自己敲

这节课没有一行代码是"技术难点"。`decide.js` 里全是 `if`，你第 2 周就会写。

**但判断顺序必须从你手指里敲出来。** 因为你脑子里觉得"我知道先找 API"，手上却会先把 `needsJsRender` 的分支写在最前面 —— 写代码会暴露你真实的默认假设。

`数据来源判断表.md` 同理：抄一遍和填一遍是两件事。填的时候你必须在"不确定"和"确定"之间做选择，这个选择就是判断力。

## 怎么建（一步步）

1. 打开 `B:\OPC-Distance_study\每周课程\03-数据与智能\第11周-数据采集\第01节课\03-练习代码`；
2. 在地址栏输入 `cmd` 回车，确认路径最后一段是 `03-练习代码`；
3. 用 VS Code 新建 `数据来源判断表.md`，先写表头再填内容，四节缺一不可；
4. 新建 `decide.js`，按第 3 步的代码自己敲，别复制；
5. 跑 `node decide.js`，对着第 3.3 节的输出逐行核对；
6. 改一个用例的输入（比如把人造边界用例的 `datasetAvailable` 改成 `false`），再跑一次，看结论变不变；
7. 把三个练习题做完，把结论补进 `数据来源判断表.md`。
