# 03-练习代码

**这个文件夹故意留空。** 本节课你要复制上一节的项目，新建一个脚本和一个数据目录：

```text
03-练习代码/
└── collector/            ← 从第04节课 xcopy 过来
    ├── mock-server.js    一行不改
    ├── node_modules/
    ├── inspect-dirty.js  打印每个字段的码点（体检）
    ├── clean.js          七个清洗函数 + 双份输出
    └── data/             程序自己建、自己写
        ├── raw.json      原始脏数据，一个字符都不改
        ├── clean.json    洗干净的 7 条
        └── diff.md       清洗前后对照表
```

## 为什么这些文件必须你自己敲

清洗是最容易被"抄过去"的一节：函数就那七个，每行都看得懂。

**但你必须自己敲，因为这一节的难点是"决定"，不是"语法"：**

```text
中间的全角空格要删还是留成半角？      → 留（只折叠，不删除）
价格缺失写 0 还是 null？             → null（0 是免费，null 是不知道）
10/04/2026 能不能猜？                → 不能（猜错两个月，而且你不会发现）
相对时间"3 天前"能不能算？           → 算，但要标 estimated
```

**这四个决定，抄代码是学不到的。** 每个决定的代价都不一样，而你要为数据质量负责。

`data/raw.json` 也必须由程序写出来，不要手写几条假数据 —— 你要亲眼看到 `¥` 和 `８９９` 从接口原样落盘，才会对"覆盖原始文件"这件事有警惕。

## 怎么建（一步步）

1. 打开 `第05节课\03-练习代码`，地址栏输入 `cmd` 回车；
2. `xcopy /E /I /Y "..\第04节课\03-练习代码\collector" collector`；
3. `cd collector`，`del` 掉上一节的分页脚本和状态文件；
4. `mkdir data`；
5. 确认 mock-server 在跑，写 `inspect-dirty.js`，跑一次，把码点对照进笔记第一节；
6. 写 `clean.js` 的前两个函数（`toHalfWidth` + `cleanText`），跑，只看 name 和 note 有没有变干净；
7. 加 `cleanPrice`，跑，确认 `"¥1,299.00"` 变成 `1299`；
8. 加 `cleanDate`，跑，确认那条 `10/04/2026` 进了警告；
9. 加缺失统计和 `writeDiff`，跑，`type data\diff.md` 对着看。

**每一步都只加一个函数，跑一次。** 七个函数一起写完再跑，出错时你不知道是谁的错。
