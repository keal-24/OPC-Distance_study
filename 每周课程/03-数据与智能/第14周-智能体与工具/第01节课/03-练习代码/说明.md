# 03-练习代码

**这个文件夹故意留空。** 本节课你要自己新建：

```text
03-练习代码/
└── agent/
    ├── package.json        ← npm init -y 生成
    ├── .env                ← MOCK=true
    ├── seed.js             ← 你自己敲，造 200 条订单
    ├── check-db.js         ← 你自己敲，打印表名和行数
    ├── chat.js             ← 你自己敲，一次问答
    ├── agent.js            ← 你自己敲，最小循环
    └── data/
        └── app.db          ← seed.js 生成，不要手工复制到别处
```

## 为什么这些文件必须你自己敲

这一节只有 90 行代码，但它是整周的地基。后面六节课的 `agent.js` 都是在这个循环上改的：

```text
第 93 节 → 加工具说明书
第 94 节 → 把 decide() 换成真模型
第 95 节 → 加参数校验和结果回传
第 96 节 → 加轮次日志和停止原因
第 97 节 → 加人工确认
第 98 节 → 换成真 SQL 工具，跑 5 个业务问题
```

**循环的结构如果你只是复制过去，第 95 节"结果没回传"那个错你根本看不懂** —— 因为你不知道自己漏了哪一行。

## 怎么建（一步步）

1. 进 `第01节课\03-练习代码`，新建文件夹 `agent`；
2. 在 `agent` 里打开 cmd（地址栏输入 `cmd` 回车），确认路径最后一段是 `agent`；
3. `npm init -y`；
4. `npm install better-sqlite3 dotenv`；
5. 新建 `.env`，写 `MOCK=true`；
6. 按课件顺序敲 `seed.js` → `check-db.js` → `chat.js` → `agent.js`；
7. 每敲完一个就跑一次，对照课件的"屏幕上应该看到什么"。

**不要一次把四个文件都敲完再跑。** 出错时你不知道是哪个文件的错。

## 检验自己有没有真学会

做完后，不看课件回答这五个问题：

- `chat.js` 和 `agent.js` 的输出都提到"200 条订单"，哪个是真查的？你怎么证明？
- 循环里 `history` 数组存的是什么？如果删掉 `history.push(...)` 这一行，`decide` 会怎样？
- 为什么 `MAX_ROUNDS` 不能省？模型不是会自己说"答完了"吗？
- 把 `dispatch` 里 `list_tables` 的分支删掉，跑 `node agent.js`，你预测会看到什么？实际是什么？
- 你现在能想到的、最像"智能体"的一个日常需求是什么？它真的需要循环吗？
