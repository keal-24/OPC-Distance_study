## 为什么这三个文件必须你自己敲

`mock-llm.js` 是这一周唯一一个"你要用五天"的文件。第 95 到 98 节课的所有实验，都建立在它能正确返回 `tool_calls` 上。

它必须做对三件事，缺一个后面就塌：

```text
第一轮返回 tool_calls，content 是 null
arguments 是 JSON 字符串，不是对象
第二轮（看到 role:"tool"）返回最终答案
```

**第 3 件事最重要。** 如果你写错，第 96 节课诊断死循环时，你会以为是自己循环写错了，其实是假模型不认工具结果。

`llm.js` 必须做对一件事：`MOCK` 是字符串，`"false"` 也是真值。

## 怎么建（一步步）

1. 从 `第03节课\03-练习代码` 往上一层，执行课件里的 `xcopy`；
2. `cd 第03节课\03-练习代码\agent`，`node check-db.js` 看到 200；
3. `type .env`，确认 `MOCK=true`，三个变量为空；
4. 敲 `llm.js`，跑 `node -e "console.log(require('./llm').USE_MOCK)"`，必须是 `true`；
5. 敲 `mock-llm.js`，用课件里那条单测命令，必须看到 `content: null` 和 `finish_reason: "tool_calls"`；
6. 最后敲 `probe.js`，三个问题跑完，对照课件的三段输出。

**第 5 步不通过，不要往下走。** 后面所有课都靠它。
