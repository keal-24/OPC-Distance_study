## 为什么 CSV 要手写、xlsx 可以用包

**CSV 的规则只有四条，而且每一条都会让 `split` 出错。** 你自己写一遍状态机，以后任何 CSV 错位你都能定位到是引号、换行、`\r` 还是字段数。

xlsx 不一样：它是 zip + XML + 共享字符串表 + 样式表，自己解要几百行，而且没有教学价值。**这种"复杂度高但不长见识"的活，交给 `exceljs`。**

判断标准写在这里，以后你自己决定引不引包：

```text
规则少、坑多、手写 50 行能讲清  → 自己写
复杂度高、规范长、手写要几百行  → 用包
```

## 为什么样本必须自己造

`名单.csv` 里那一行 `"北京市,海淀区"` 是你自己敲的，你才知道逗号在引号里。

`预算.xlsx` 里那个 `A4:A5` 是你自己合并的，你才会相信"合并单元格只有一个格子有值"。

**从网上随便下一个 CSV，你永远不知道它藏了什么。** 自己造的样本，每个字段都是你控制的，出错时你能定位。

## 怎么建（一步步）

1. 复制上一节的 `doc-parser`；
2. `npm install exceljs`，用 `node -e` 验证；
3. 记事本照抄 `名单.csv`，**引号和换行一个都不能少**；
4. Excel 打开 `名单.csv`，另存为 `名单-excel.csv`；
5. Excel 造 `预算.xlsx`：两个 sheet、一个标题合并、一个 `A4:A5` 纵向合并；
6. 写 `parseCsv`，先只跑 CSV；
7. 写 `readXlsx`，先打印 `ws.model.merges`；
8. 最后写 `readTable` 统一结构。

**先跑 CSV 再跑 xlsx。** 两个一起写，出错时你分不清是哪个的问题。
