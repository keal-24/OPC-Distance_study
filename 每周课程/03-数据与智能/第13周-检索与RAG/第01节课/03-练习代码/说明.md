# 03-练习代码

**这个文件夹故意留空。** 本节课你要自己新建一个项目，这一周七节课都往里加文件：

```text
03-练习代码/
└── rag-app/                 ← 你自己建，这一周唯一的项目根
    ├── package.json         ← npm init -y 生成
    ├── node_modules/        ← npm install 生成，不提交
    ├── .env                 ← 第 89 节课才用，现在可以没有
    ├── data/
    │   ├── docs/            ← 5 个 txt
    │   └── rag.db           ← 第 86 节课生成
    ├── out/
    │   └── chunks-preview.json
    ├── tools/
    │   ├── seed-docs.js
    │   ├── count-kb.js
    │   └── check-chunks.js
    └── split.js
```

**后面六节课不再新建项目。** 第 86 节课的 `build-index.js`、第 87 节课的 `search-keyword.js` 都加在这个 `rag-app` 里。这样数据库、路径、依赖只配一次。

## 为什么这些文件必须你自己敲

这一周的代码大部分是三十行左右的小脚本，看起来"复制粘贴也一样"。不一样的地方在这三处：

1. **路径。** 你的 `data\docs` 在哪、`out` 在哪，复制的人永远会搞错一层，然后花半小时查 `ENOENT`。自己敲一遍，路径感就长在手上。
2. **正则。** 切分全靠几个正则，全角半角差一个字符，结果完全不同。抄的时候眼睛会滑过去，敲的时候会卡住。
3. **参数。** `TARGET`、`MAX`、`OVERLAP` 这三个数字，你要亲手改一次、跑一次、看一次输出，才知道它们各自管什么。

课件里的代码是对照用的标准答案。**先自己写，卡住了再看。**

## 怎么建（一步步）

1. 打开 `第01节课\03-练习代码`，新建文件夹 `rag-app`；
2. 进入 `rag-app`，在地址栏输入 `cmd` 回车；
3. 依次执行：

```text
mkdir data data\docs out tools
npm init -y
npm install better-sqlite3
```

4. 用 VS Code 打开 `rag-app` 这个文件夹（不是打开整个课程仓库）；
5. 打开 `package.json`，确认没有 `"type": "module"`。有就删掉这一行；
6. 按课件第 2 步建 `tools\seed-docs.js`，跑一次，确认 `data\docs` 下有 5 个 txt；
7. 按第 3 步写一版"只按标题切"的 `split.js`，看 34 这个数字；
8. 按第 4 步替换成完整版，看 10 这个数字；
9. 按第 5 步写 `tools\check-chunks.js`，确认 0 个问题。
