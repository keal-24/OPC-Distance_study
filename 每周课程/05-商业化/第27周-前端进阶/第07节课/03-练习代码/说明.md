## 一句话原则

> **"专业"不是好看，是一致。**

```text
间距来自同一套（4 的倍数）
字号只有 6 种
颜色是语义命名
每个状态有同一套界面
```

**客户说不出"这个系统很专业"，但他能感觉到"用起来顺"。**

## 一致性只能靠两样东西

**一、变量。**

```css
/* ❌ 五个数字没规律 */
.card { padding: 14px; }
.list__item { padding: 13px 15px; }
.btn { padding: 0 18px; }

/* ✅ 有节奏 */
.card { padding: var(--space-4); }
.list__item { padding: var(--space-3) var(--space-4); }
.btn { padding: 0 var(--space-4); }
```

**二、一个会自动报错的脚本。**

**靠"我注意一下"是没用的。** 你写两千行 CSS，第 1500 行一定会随手写个 `13px`。

**`check-css.js` 会拦住你。**

## 三个必须做的实验

**一、故意删空状态**

用空租户打开订单页 → **一片空白**。

**这就是客户第一次登录看到的界面。** 没有文案、没有引导，他会以为系统坏了。

**二、故意硬编码颜色**

```css
.btn--primary { background: #1f6feb; }
```

**第一版脚本查不到（只查 px）。** 加上颜色规则后能查到。

**这说明：脚本能拦住什么，取决于你写了什么规则。**

**三、真手机上走五个步骤**

```text
微信点链接 → 登录 → 首页 → 订单 → 详情 → 返回
```

**每一步记三个数：用了多久、哪里犹豫、哪里想退出。**

**你会至少发现一个问题。** 通常是"返回后列表滚回顶部"这种模拟器测不出来的。

## 一个省一次客服的细节

**如果客户会从微信点进来：**

```html
<p style="font-size:14px;color:#8b919c">
  如果在微信里打不开，点右上角「⋯」→「在浏览器打开」
</p>
```

**微信内置浏览器会拦 Excel 下载。** **导出按钮旁边加这一句，能省掉一次客服电话。**
