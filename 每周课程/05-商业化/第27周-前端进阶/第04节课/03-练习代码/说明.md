## 一句话原则

**每一条错误提示都要回答"客户下一步该做什么"。**

```text
❌ 格式不正确          → 什么格式？
❌ 密码太弱            → 怎样才算强？
❌ 金额无效            → 哪里不对？

✅ 请填写 11 位手机号，以 1 开头
✅ 密码里要有至少一个数字
✅ 金额最多两位小数，比如 1299 或 1299.50
```

**判断方法：把提示读给自己听，你能不能立刻改对？**

## 三个必须背下来的时机

```text
输入中（无错）   → 不校验
输入中（有错）   → 校验（让错能消失）
离开输入框       → 校验
提交             → 全量校验
```

**为什么"输入中无错时不校验"：**

**客户刚打了一个 `1`，你立刻说"请填写 11 位手机号"——他会觉得你在催他。**

## 一个 90% 的人会漏的细节

```js
input.focus({ preventScroll: true });
```

**不加 `preventScroll`，浏览器会在聚焦时自动滚动，把你用 `scrollIntoView` 算好的位置打乱。**

**现象：** **提交失败后页面滚到某处，然后又跳走了。**

**这个 bug 很难查，因为它只在"延迟聚焦"的时候出现。**

## `type="text"` + `inputmode` 而不是 `type="number"`

| | `type="number"` | `type="text"` + `inputmode="numeric"` |
|---|---|---|
| 手机键盘 | 数字键盘 | 数字键盘 |
| 上方箭头按钮 | 有（难看） | 无 |
| 能输入 `e` / `+` / `-` | 能 | 不能 |
| 能精确控制 | 不能 | 能 |

**选右边那个。**
