## 三个必须背下来的数字

```text
379700 分 / 3 件  →  126567 / 126567 / 126566
                     （加起来 379700，一分不差）

11300 分含 13% 税  →  税 1300，不含税 10000
                     （用减法保证 1300 + 10000 = 11300）

100 分 / 3 份      →  34 / 33 / 33
```

**以后看到任何金额分摊代码，先拿这三组数试。**

## 一个思想，比代码重要

**"让浮点只出现一次，而且只在最后。"**

```text
❌ 每一步都可能是浮点：
   price = parseFloat(x) → price * qty → round(that) → toFixed(2)

✅ 浮点只出现一次：
   入口：字符串 → 整数分（正则 + 整数运算，零浮点）
   中间：全整数
   除法：一次 round，然后立刻用整数修正（splitByWeights 的补余数）
```

**记住这个，比记住任何一个函数都有用。**
