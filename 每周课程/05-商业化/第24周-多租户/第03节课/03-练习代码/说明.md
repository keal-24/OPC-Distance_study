# 03-练习代码

**这个文件夹故意留空。**

这节课你在 `saas-lab` 里新增这些文件：

```text
saas-lab/
├── src/
│   ├── server.js              Express 入口
│   ├── middleware/
│   │   ├── auth.js            验签 + 查用户
│   │   └── tenant.js          查租户 + 检查状态
│   └── routes/
│       ├── auth.js            注册 / 登录 / 退出
│       └── me.js              /api/me
└── migrations/
    └── 004_tenant_slug.sql    给 tenants 加 owner_user_id
```

## 这节课最容易搞错的三处

**一、`cookieParser()` 必须在路由之前挂。**

```js
app.use(cookieParser());      // 先
app.use('/api/auth', authRoutes);  // 后
```

反了的话 `req.cookies` 是 `undefined`，`auth.js` 里 `req.cookies.token` 直接抛错，你会看到 500 而不是 401。

**二、本地开发时 `secure` 必须是 `false`。**

本地是 `http://localhost`，cookie 带 `secure: true` 浏览器会直接拒收。**开了它，你会以为登录接口坏了。**

**三、`bcryptjs` 不是 `bcrypt`。**

`npm install bcrypt` 在 Windows 上经常要编译原生模块，报 `node-gyp` 一堆错。用 `bcryptjs`，纯 JS，慢一点点，装得上。

## 这节课的验证顺序

```text
1. 注册 → 返回 201 + cookie
2. 数据库里查 → tenants 一行、users 一行、owner_user_id 有值
3. 重复注册同邮箱 → 409
4. 登录 → 200 + cookie
5. /api/me 带 cookie → 自己的信息
6. /api/me 不带 cookie → 401
7. 改 status = suspended → 403
8. 改回来 → 200
9. 做 x-tenant-id 攻击实验 → 能看到别人数据
10. 删掉那段代码 → 看不到了
```

**第 9 和第 10 步必须都做。** 只看别人写"这样是漏洞"，你不会有肌肉记忆。自己敲一遍 `curl`，看到别人家的数据从你的接口里出来，那个感觉你以后写代码时会记得。
