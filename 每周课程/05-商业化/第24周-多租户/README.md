# 第24周 · 多租户 · 第162—168节课

## 第二个客户来了不用重写

---

## 这一周的目标

把前 23 周做的"一个人的应用"改造成**一套代码服务多个客户**的架构。

这一周结束，你要能做到这五件事：

1. **说清三种隔离方案的区别** —— 独立部署、独立库、共享库，为什么一人公司只能选第三种；
2. **给每张业务表加 `tenant_id`** —— 包括唯一约束和索引怎么配合改；
3. **让 `tenant_id` 只从服务端来** —— 客户端传什么都不算数；
4. **把查询封死在一个入口** —— 不靠"写代码时小心一点"；
5. **自己当黑客攻一次** —— 用客户 A 的登录态去拿客户 B 的数据，全部失败才算过。

## 为什么排在这一周

前面 23 周，你做的东西都默认**只有一个人用**。

第 3 周的 `chat-app`、第 9 周的后台管理、第 10 周的文件上传，这些代码里没有任何地方在问"这条数据属于谁"。

**第一个客户用起来不会有任何问题。第二个客户注册进来，你的代码就开始把两家公司的数据混在一起。**

到那时候改，改的是每一张表、每一条 SQL、每一个接口，还要停机导数据。改不动的结果就是给每个客户单独部署一套——五个客户五套代码，你一个人维护，光改一个错别字要改五遍。

**这是整个 36 周里唯一一个"做错了只能重写"的决定。** 所以它排在你开始接活之前。

```text
第 5 周  你学会建表
第 9 周  你学会做后台
第 24 周 你学会让表分得清是谁的
第 25 周 才开始谈收钱
```

**先能隔离，再谈收费。** 反过来的顺序会让你在收到第一笔钱的时候不敢让第二个人注册。

## 这一周的技术前提

**数据库用 PostgreSQL，通过 `DATABASE_URL` 连。**

第 5 周你已经装过一个库。这一周不换技术栈，只加一列、加一层中间件。

**如果你第 5 周用的是 SQLite**，这一周的 SQL 照样能跑，只需要改两处：

| PostgreSQL | SQLite |
|---|---|
| 参数占位符 `$1`、`$2` | `?` |
| 类型 `UUID`、`JSONB` | `TEXT` |

**为什么示范用 PostgreSQL：** 第 34 周要私有化部署，PostgreSQL 是唯一一个客户和云厂商都不挑的选项。而且它有行级安全（RLS），这一周第 4 节会用到。

**连接串放 `.env`**，这一周的代码读的是：

```text
DATABASE_URL=postgres://用户名:密码@主机:5432/saas_lab
```

**`.env` 不进 Git。** 第 4 周学过，这里再说一遍，因为这一周会新建一个项目目录，很容易忘了复制 `.gitignore`。

## 这一周的四条铁律

这四条比命令重要。命令可以查，判断错了没有救。

```text
一、tenant_id 只从服务端会话推导，永远不从请求参数读。
    只要有一个接口从 req.body 读 tenant_id，整套隔离就是假的。

二、任何 SQL 里出现业务表，就必须出现 tenant_id 条件。
    写不出来说明这条查询本来就不该存在。

三、唯一约束必须带 tenant_id。
    UNIQUE(email) 会让第二个客户永远注册不了同一个邮箱。

四、越权一律返回 404，不返回 403。
    403 等于告诉攻击者"这个 ID 存在，只是你没权限"。
```

## 这一周最容易出事的三个地方

**第一：更新和删除漏写租户条件**

查询（`SELECT`）漏了租户条件，你会看到别人的数据，很明显，测试时容易发现。

`UPDATE` 和 `DELETE` 漏了租户条件，**没有任何报错，功能看起来完全正常**，只是你把别人的数据改了或删了。

**这一类错误上线三个月都不会被发现，直到客户打电话问"我的数据怎么少了"。**

**第二：文件下载和导出接口**

文件是存在磁盘或对象存储里的，路径里往往只有一个 `id`。

```text
GET /files/8f3a...          ← 这个 id 是谁的？代码里没问
```

**数据接口查得再严，文件接口漏一个，等于全漏。**

**第三：AI 生成的"顺手版本"**

你让 AI 加一个接口，它会写：

```js
app.get('/api/orders/:id', async (req, res) => {
  const { rows } = await db.query('SELECT * FROM orders WHERE id = $1', [req.params.id]);
  res.json(rows[0]);
});
```

**这段代码语法没错、能跑通、功能正常，但它没有任何租户过滤。**

AI 不知道你在做多租户，除非你在提示词里写死。第 162 节会给你一段可以直接用的提示词前缀。
