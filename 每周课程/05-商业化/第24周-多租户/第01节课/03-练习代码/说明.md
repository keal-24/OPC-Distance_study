# 03-练习代码

**这个文件夹故意留空。**

这一周你要在这里建一个项目，七节课都在里面改：

```text
03-练习代码/
└── saas-lab/              ← 你自己建，第 162 节建好后一直用
    ├── .env               ← 不提交，放数据库连接串
    ├── .gitignore         ← 先建这个，再建 .env
    ├── package.json
    ├── migrations/
    ├── scripts/
    ├── src/
    └── tests/
```

## 为什么不复制现成项目

**因为这个项目要你自己一个个文件写出来。**

这一周的文件不多，二十来个，但每一个都在解决一个具体问题：连接池、认证中间件、租户中间件、仓储层、越权测试。**抄一遍，你就只记住了"有这么个文件"；写一遍，你才知道为什么参数是这个值。**

## 这一节只做骨架，不写业务

第 162 节结束时，你手上应该只有：

```text
✅ package.json（装了 express / pg / dotenv / nodemon）
✅ .gitignore
✅ .env（连接串正确，npm run ping 输出 saas_lab）
✅ src/db/pool.js
✅ scripts/ping.js
✅ 六个空文件夹
✅ 笔记里一份"哪张表要加 tenant_id"的清单
```

**没有 server.js，没有路由，没有建表 SQL。** 那些是后面几节的事。

## 建完先想一个问题

**在写第一行 SQL 之前，先回答：**

```text
客户 A 的人登录进来，系统凭什么知道他是客户 A 的？
```

想不清楚，第 164 节你会写得很难受。**这一节的清单就是为了回答这个问题做准备的。**
