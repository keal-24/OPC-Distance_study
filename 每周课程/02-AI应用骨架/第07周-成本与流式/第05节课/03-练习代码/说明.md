## 三个硬要求

### 一、先命令行验证，再上浏览器

`e05-stream.js` 不经过浏览器、不经过 Express。

**它只验证"上游有没有流、我的解析对不对"。**

**这一步不过，别浪费时间调前端。**

### 二、`buffer` 必须保留残余

```javascript
buffer = buffer.slice(boundary + 2);
```

**每收到一块就把 `buffer` 清空的写法，会把被切断的 JSON 丢掉。**

**症状：偶尔丢一两个字，或者 JSON 解析失败。**

### 三、`{ stream: true }` 前后端都要

**Node 的 `TextDecoder` 要，浏览器的 `TextDecoder` 也要。**

**中文场景漏了这个，页面会零星冒 `�`。**
