## 三个硬要求

### 一、未登记的 feature 默认不缓存

```javascript
const policy = CACHE_POLICY[feature];
if (!policy) return { enabled: false, ... };
```

**这是白名单思维。** 默认关，要开就登记。

**反过来（默认开）意味着：新功能上线忘了登记，就悄悄缓存了用户隐私。**

### 二、`scope` 不是 global 就必须带 userId

```javascript
const cacheUserId = policy.scope === "global" ? null : userId || "anon";
```

**这一行写错就是数据泄漏。**

**而且要能说出匿名用户共享 `anon` 的风险。**

### 三、`undefined` 一律换 `null`

```javascript
userId: userId || null        // 不是 userId
```

**`JSON.stringify({a: undefined})` 是 `"{}"`，字段直接消失。**

**消失的字段 = 少一个维度的键 = 串答案。**
