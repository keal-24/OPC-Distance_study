## 三个硬要求

### 一、必须先有 `tokens.js`

`limits.js` 要 `estimateTokens`，`llm.js` 也要。

**如果 `limits.js` 直接 import `llm.js`，就形成循环依赖。**

**循环依赖的症状是"有时候能跑、有时候 undefined"。** 这种 bug 查一天都查不出来。

### 二、裁剪顺序不能错

```text
裁剪历史 → 检查单条长度 → 检查总 token
```

**先检查总量再裁剪，等于先拒绝用户再用他的额度，逻辑反了。**

### 三、截断必须能看到

`finish_reason: "length"` 不许只躺在 `raw` 里。

**要变成 `truncated: true` 一路传到前端。**
