## 三个硬要求

### 一、每个写接口都要挂具体权限

**`DELETE` 挂 `user.delete`，`PATCH` 挂 `user.update` + 条件 `user.role`。**

**漏一个就是漏洞，而且能通过 F12 直接利用。**

### 二、`permissionsOf` 必须返回副本

```javascript
return [...(ROLE_PERMISSIONS[role] || [])];
```

**不复制的话，任何人 `push` 一个权限就改了全局配置 —— 运行时提权。**

### 三、前端判断权限，不判断角色

```javascript
// 好
if (hasPermission("user.delete"))

// 坏
if (user.role === "admin")
```

**判断角色的话，加新角色时前端要改一堆地方。**
