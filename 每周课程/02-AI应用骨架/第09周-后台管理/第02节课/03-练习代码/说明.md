## 三个硬要求

### 一、`SELECT` 明确列字段，绝不用 `*`

**`SELECT *` 会把 `password_hash` 查出来。**

**只要有一处不小心返回给前端，就是泄露。**

**要"泄露需要主动动作"，不要"防止泄露需要主动动作"。**

### 二、四种状态全做

**加载中（骨架屏）、有数据、空、出错。**

**少一个，用户就会以为系统坏了。**

**"空"状态最重要 —— 新部署的系统第一眼就是空的。**

### 三、`render` 里手动 `esc()`

```javascript
// 错
render: (row) => `<span>${row.nickname}</span>`

// 对
render: (row) => `<span>${esc(row.nickname)}</span>`
```

**`col.render` 返回的是 HTML，`renderTable` 不会再 esc 它。**

**这是灵活性的代价：你要自己记得。**
