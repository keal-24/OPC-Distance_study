## 三个硬要求

### 一、乐观锁必须检查 `changes === 0`

```javascript
const result = db.prepare("UPDATE ... WHERE id = ? AND updated_at = ?").run(...);
if (result.changes === 0) return { ok: false, reason: "CONFLICT" };
```

**不检查就会"显示保存成功但值没变" —— 这是最坏的体验。**

### 二、不许删/降级最后一个管理员

**这不是安全校验，是"业务不变量"。**

**不加的话，你会把自己锁在后台外面，只能去数据库手动改。**

**真实发生过的事故。**

### 三、软删除必须把邮箱腾出来

**`alice@example.com` 被软删除但邮箱字段没改 → UNIQUE 约束还在 → 她无法重新注册。**

**加 `.deleted.时间戳` 后缀。**
