## 三个硬要求

### 一、上传用 XHR，不用 fetch

**`fetch` 没有上传进度事件。**

**这是浏览器 API 的现实，不是你的选择。**

**注意 `xhr.withCredentials = true`，否则 Cookie 不带，401。**

### 二、批量删除要如实报告部分失败

```json
{ "deleted": [1,2], "failed": [{"id": 999, "reason": "NOT_FOUND"}] }
```

**"全成功/全失败"会让用户误判。**

### 三、切换筛选必须清空 `picked`

**不清的话，用户会删掉"看不见的文件"。**

**`load()` 里也要清理"已不在当前列表"的 id。**
