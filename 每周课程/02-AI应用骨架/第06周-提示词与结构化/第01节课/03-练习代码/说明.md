# 03-练习代码

**这个文件夹里没有现成代码。** 本节课你要在这里建出这一周唯一的项目：

```text
prompt-lab/
├── .env                  ← 你自己建，绝不能提交
├── package.json          ← 你自己建
├── src/
│   ├── llm.js            ← 从第 20 节课的 chat-app 复制，改两处
│   ├── mock-llm.js       ← 从第 20 节课复制，一行不改
│   └── prompts.js        ← 你自己写（这节课的主战场）
├── experiments/
│   └── e01-system.js     ← 你自己写
└── results/              ← 想存跑分结果就建，不强制
```

## 为什么单独建一个项目

```text
chat-app 是"能用"的产品
prompt-lab 是"要反复试"的实验台
```

把实验代码塞进产品，两边都会乱。**这一周七个实验都在这个 `prompt-lab` 里做。**

## 后面的课怎么继续用

第 37—42 节**不会再建新项目**，都在这个 `prompt-lab` 里加文件。

所以这个目录要留好，别删。**下一节课的路径会直接指到这里。**

## 三个硬要求

### 一、`.env` 不能提交

先确认仓库根目录 `.gitignore` 里有 `.env`。

提交前跑 `git status --short`，看到 `.env` 就停手。

### 二、提示词放文件，不放代码中间

所有 `system` 写进 `src/prompts.js`，用对象管理，带 `id` 和 `version`。

**不许在 `experiments/*.js` 里直接写一长串 `system` 字符串。** 那样你没法对比版本，也没法在第 42 节做模板化。

### 三、每次改提示词，只改一处

改一处 → 跑一次 → 记录差别。

一次改三处，输出变好了你也不知道是哪句起作用。
