## 本节课的四件实事

1. 检查 `chat-app` 的 `.gitignore` 是否完整、是否生效；
2. 写一个合格的 `README.md`（含"怎么跑"和"已知限制"）；
3. 用 `git add -n` 演练，确认没有 `node_modules` / `.env` / `data`；
4. 正式提交，并用四个检查动作验证。

## 这节课没有"代码"，但有必须自己撞的坑

- `git add .` 在课程仓库根目录会把 `sandbox`、所有练习文件一起加进去；
- `.gitignore` 写成 `.env*` 会把 `.env.example` 也忽略掉；
- 先 `git add node_modules` 之后再加 `.gitignore`，规则不生效。

**这三个坑都必须自己踩一次。**
