# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己建：

```text
03-练习代码/
├── rescue-lab/        ← 主练手仓库（restore / reset / reflog / stash / clean）
├── remote-demo/       ← 模拟远程仓库（git init --bare）
└── work/              ← 从 remote-demo 克隆出来干活
```

## 这节课为什么必须建三个目录

因为 `revert` 的练习必须有一个"远程仓库"，否则你看不到 `non-fast-forward` 这个报错。

**没有真实远程，就练不出"push 被拒"的判断力。**

## 这节课的危险操作都在这里做

```text
reset --hard        会丢未提交改动
clean -f            直接删文件，不进回收站
push --force        覆盖远程历史
```

**这三个都只在这个文件夹里做，绝不要在课程仓库里做。**

## 必须自己经历的两次"心疼"

**第一次：`reset --hard` 丢掉改了一半的文件**

课件第 10 步的错误 1 会让你真的做一次。做完你会明白为什么"先 git status"是一条铁律。

**第二次：`push --force` 后别人仓库的分叉**

课件第 7 步会演示。做完你会明白为什么"push 过的只用 revert"。

## 必须自己拿到的三个真实输出

**① `reset --hard` 的特有提示**

```text
HEAD is now at 916f25f 第一次提交：创建 f.txt
```

**② `push` 被拒绝的完整提示**

```text
! [rejected]        main -> main (non-fast-forward)
```

**③ `revert` 合并提交的报错**

```text
error: commit XXX is a merge but no -m option was given.
```

**这三条原文要抄进笔记。**
