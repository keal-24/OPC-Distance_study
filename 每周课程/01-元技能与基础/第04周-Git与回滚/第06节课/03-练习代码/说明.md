# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己建**三个**练手仓库：

```text
03-练习代码/
├── conflict-lab/      ← 内容冲突（UU）
├── addadd-lab/        ← 新增冲突（AA）
└── moddel-lab/        ← 修改/删除冲突（UD）
```

**三个都要建。** 因为三种冲突的处理方式不一样，只练一种等于没练。

## 为什么必须自己造冲突

**因为"读冲突标记"这个能力，只能在自己造过、自己撞过之后才长得出来。**

- 你复制别人的冲突文件，看不出哪行是谁改的；
- 你不亲手 `git merge` 一次，不理解为啥 `--abort` 那么重要；
- 你不亲眼看到 `commit -a` 把 `<<<<<<<` 提交进去，下次还会踩。

## 最容易漏的一步

`git checkout --ours` 之后**必须再 `git add`**。

很多人以为换完文件就完事了，结果 `git commit` 一直被拒绝，看着干净的文件找不到原因。

## 必须自己亲眼看到的三个现象

**① 普通 commit 会被拒绝**

```text
error: Committing is not possible because you have unmerged files.
```

**② `commit -a` 会绕过这个保护**

提交成功，然后 `git grep "<<<<<<<"` 能搜出来。

**③ `--abort` 会丢掉你的修改**

改了一半按 abort，全没了。

**这三个现象必须自己撞一遍，看一遍原文。**
