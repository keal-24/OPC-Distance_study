## 为什么必须自己建 merge-lab

因为这节课要在同一个仓库里做**三种不同的合并**，还要用 `git reset --hard` 撤销重来。

**在课程仓库里做会把你的作业搞乱。**

## 必须自己观察的四件事

**① 快进的输出**

```text
Updating f37cdc2..9ad3294
Fast-forward
```

**注意没有"Merge made"。**

**② 三方合并的输出**

```text
Merge made by the 'ort' strategy.
```

**这句出现说明产生了合并提交。**

**③ squash 的输出**

```text
Squash commit -- not updating HEAD
```

**看到这句就必须马上去 `git commit`。**

**④ 三种合并后的图**

用 `git log --oneline --graph` 对比，你会发现形状完全不同。
