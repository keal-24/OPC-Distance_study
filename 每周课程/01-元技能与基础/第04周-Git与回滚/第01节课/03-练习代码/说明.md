# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建一个**独立的练手仓库**：

```text
03-练习代码/
└── sandbox/          ← 你自己建，git init 在这里
    ├── .git/         ← git init 自动生成
    ├── README.md
    └── ...（你自己建的文件）
```

## 为什么必须单独建 sandbox

因为这一周要做的实验包括：

```text
删分支
强制回退（reset --hard）
制造并解决冲突
游离 HEAD
```

**这些操作在课程仓库里做，可能把你的作业弄丢。**

**规则：这一周所有危险操作都在 `sandbox` 里做。**

## 怎么建

1. 新建文件夹 `sandbox`；
2. 进去，在地址栏输入 `cmd` 打开终端；
3. `cd` 确认路径里有 `sandbox`；
4. `git init`；
5. 配好 `user.name` 和 `user.email`；
6. 开始做课件的实验。

## 这一课的实验重点是"看内部"

课件会让你用这些命令看 Git 内部：

```text
type .git\HEAD                  看 HEAD 里写的是什么
type .git\refs\heads\main       看分支文件里写的是什么
git cat-file -p HEAD            看提交对象的真实内容
git cat-file -p HEAD^{tree}     看目录树
git ls-files --stage            看暂存区
dir .git\objects                看内容存哪
```

**这些不是"必须日常使用"的命令，但它们能让你真正理解 Git 是什么。**
