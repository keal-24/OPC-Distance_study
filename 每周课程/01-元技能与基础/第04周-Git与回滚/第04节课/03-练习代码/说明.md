# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己建：

```text
03-练习代码/
└── branch-lab/      ← 练手仓库
    ├── README.md
    └── task.js      ← 在功能分支上创建
```

## 为什么必须自己建 branch-lab

因为这一节的所有实验都需要"反复切换分支"，**在课程仓库里做会把你的作业搞乱**。

## 必须自己做的四个实验

**实验一：文件消失又出现**

在 `main` 上 `dir` 看不到 `task.js`，切到 `feature-add-task` 就看到了。

**这个体验必须自己经历一次**，否则第一次遇到会以为文件丢了。

**实验二：删分支再用哈希恢复**

```text
git log --oneline feature-add-task    记下哈希
git branch -D feature-add-task        删掉
git branch feature-add-task <哈希>    恢复
```

**实验三：git reflog**

在删掉分支、忘了哈希的情况下，用 `git reflog` 翻出来。

**这是"东西丢了"时的第一反应命令。**

**实验四：stash**

改一半不想提交，但必须切分支。
`git stash` → 切走 → 回来后 `git stash pop`。
