## 分支、回滚、冲突

---

## 这一周的目标

不只是 commit 和 push：开分支做功能、合并、冲突怎么解、改坏了怎么回退、标签怎么打、多个实验怎么并行。

## 为什么排在这一周

你现在只会一条线往前走。一旦要同时试两个方案、或者要紧急修线上 bug，没有分支就会把代码搞乱。这是你目前最明显的技术短板。
