# 第04周 · Git与回滚 · 第22—28节课

## 分支、合并、冲突、回退

---

## 这一周的目标

不只是 `commit` 和 `push`。你要能做到这五件事：

1. **看懂 Git 里到底存了什么** —— 不是背命令，是知道 `.git` 里发生了什么；
2. **把代码正确提交进 Git** —— 哪些该提交、哪些绝对不能提交；
3. **查历史** —— 某个 bug 是什么时候引进来的、某一行是谁改的；
4. **开分支做功能，再合并回来** —— 包括合并出冲突时怎么处理；
5. **改坏了能退回去** —— 包括已经 push 的那种。

## 为什么排在这一周

到第 3 周结束，你已经有一个能跑的对话应用了。但你现在只敢"往前加东西"，不敢改。

**不敢改的原因不是不会写代码，是没有退路感。**

这一周就是给你退路：

```text
改错了 → git restore 丢掉
提交错了 → git reset / revert 撤销
合并冲突 → 有标准流程处理
退过头了 → reflog 救回来
```

**这一周学完，你才敢在真实项目上动手。**

这一周所有实验都在 `03-练习代码/` 里**单独建的练手仓库**里做，**不要在课程仓库根目录做**。

因为这一周要做的操作包括：


**在课程仓库里做，你的作业真的会消失。**

每个 `03-练习代码/说明.md` 里都写清了这节课要建哪个练手仓库。

## 这一周的四条铁律

这四条会跟着你一辈子：

```text
一、任何 git commit 之前，先跑 git status --short。
    看到 UU / AA / UD / DU，停下来解决，不要提交。

二、已经 push 的提交，只用 revert，不用 reset。

三、git reset --hard 之前，永远先 git status。
    工作区不干净，先 stash 或 commit。

四、`.env` 绝对不能提交，提交了就要去吊销密钥。
```

---

## 这一周最危险的三条命令

**第一：`git reset --hard`**

它同时改历史、暂存区、工作区。**未提交的改动会永久消失，`reflog` 也救不回来。**

**第二：`git clean -xfd`**

`-x` 会连 `.gitignore` 里的也删掉 —— 也就是 `node_modules` 和 `.env`。**在别人项目里跑一次，可能毁掉他几小时的安装和他的密钥。**

**第三：`git push --force`**

会覆盖远程历史。**如果别人已经拉过，他的仓库和远程就分叉了。** 两个人互相 force，代码会互相丢。

**这三条不是"不能用"，是"用之前必须知道自己在干什么"。**

## 周末的验收

不要急着进下一周。先确认这五条：

- [ ] 我能打开 `.git` 文件夹，说出 `HEAD`、`objects`、`refs` 各是什么
- [ ] 我的 `chat-app` 已经正确提交（没有 `node_modules`、没有 `.env`、没有 `data/`）
- [ ] 我做过一次完整的分支 → 合并 → 解决冲突 → 提交
- [ ] 我用 `git reflog` 救回过一次"已经消失"的提交
- [ ] 我做过一次 `revert`（包括合并提交的 `-m 1`）

**另外：**

- [ ] 每节课的 `NOTES.md` 都填了，没有大片空白
- [ ] 「卡在哪」那一栏写了真实内容（不是"没有卡住"）
- [ ] 我能用三句话讲清"restore / reset / revert 各管什么"

> **最后一条才是真标准。** 讲不出来，说明你只是跟着敲了七个命令，没真的理解。
>
> **一周七节课，落一节课没关系，但第 27、28 节不能落。** 因为冲突和回退是"敢不敢用 Git"的分水岭。

## 这一周不用学什么

明确排除，避免你分心：

```text
git rebase              第 4 阶段（工程可靠性）
git bisect              第 4 阶段（找哪个提交引入 bug）
git worktree            用不到
git submodule           用不到
图形化 Git 客户端       会用命令行之后自然就会
GitHub Actions / CI     第 6 阶段（上线运维）
Pull Request 流程       第 4 阶段会专门讲协作
提交规范（Conventional Commits）  第 4 阶段
```

**这一周只用命令行。** 因为报错信息全在命令行里，图形界面会把它藏起来。**你必须先看懂报错。**
