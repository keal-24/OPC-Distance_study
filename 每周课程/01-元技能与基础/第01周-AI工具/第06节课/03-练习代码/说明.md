# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这些文件：

```text
shop/ 文件夹（含 config.js、format.js、cart.js、index.js、README.md）、debug.js、twice.js、git-log.md
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么不让复制

- 复制粘贴学不会：手会了脑子没会；
- 敲的过程会遇到拼写、括号、缩进问题，这些问题正是你要练的；
- 这一周的课专门练"读懂代码"和"安全修改"，没亲手敲过就做不到。

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成课件里要求的名字；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. 自己敲代码，`Ctrl + S` 保存。

## 提醒

先确认 Windows 已打开"文件扩展名"显示，否则你新建的 `xxx.js` 实际会叫 `xxx.js.txt`，程序跑不起来。
