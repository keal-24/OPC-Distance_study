# 第01周 · AI工具 · 第 1 节课-7

## 怎么让 AI 替你写代码，又不被它带进坑

---

## 这一周的目标

把 WorkBuddy、Codex 这类工具真正用起来：

- **怎么下指令**（五要素：背景 / 任务 / 要求 / 限制 / 验收）
- **怎么读代码**（先找入口、再看数据、再找岔路口、最后手算输出）
- **怎么读报错**（类型 → 消息 → 位置）
- **怎么安全改文件**（只改一处、看 diff、能回退）
- **改坏了怎么救**（`git restore`、存档点习惯）
- **什么时候不该用它**（密钥、钱、删数据、部署、合同）

## 为什么排在第一周

这是整条路线里唯一的**元技能**。

后面 35 周你都在用 AI 写代码，但没人教过你怎么用。**用得好省一半时间，用不好你会花更多时间在调试它写的烂代码上。**

> **而且这不是"以后再说"的事。你已经在用了。**
>
> 前面遇到的问题——占位符直接复制、站错目录、文件里混进重复代码——全都是"不会用 AI"，不是"不会写代码"。

## 每周固定的三条规矩

### 一、`03-练习代码` 是空的，代码全部自己敲

**每一节课的 `03-练习代码` 文件夹里只有一份 `说明.md`，没有现成代码。**

课件里给的代码是**对照用的标准答案**，不是让你复制粘贴的素材。

**为什么：**

- 复制粘贴只会手会，脑子没会；
- 敲的过程会遇到拼错、漏括号、缩进不对，这些正是你要练的；
- 你亲手敲错过、报错过，才知道报错长什么样；
- 这一周练的是"读懂代码"和"安全修改"，没亲手敲过就做不到。

**如果你实在敲不出来：** 打开课件里的代码当参照，但要一行一行对着敲，不能 `Ctrl + A` 全选复制。差别在于：对着敲你会看到每一行；全选复制你什么都看不到。

### 二、所有笔记写在 `02-笔记/NOTES.md`

每节课的 `NOTES.md` 是**你要填的**，不是阅读材料。

**填写标准：** 每一行都要有字。"我还不懂的词"如果真没有，写"暂时没有"，不要留空。

### 三、每节课都要 commit

```text
git add 每周课程/01-元技能与基础/第01周-AI工具/第XX节课
git commit -m "第XX节课：<这节课干了什么>"
```

**周末打开 GitHub 看绿点，一节课都不能缺。**

## 这一周最难的三处，提前告诉你

**第一处：第 3 节课的手算。**
你会很想直接运行看答案。**忍住。** 手算过才知道程序对不对，直接运行只能看到"一个结果"，看不出"这个结果对不对"。

**第二处：第 5 节课的 diff。**
你改了 6 行，diff 里可能显示 20 行变化（因为粘贴时带入了整段）。**学会只改那几行，不要整段覆盖。**

**第三处：第 6 节课的 Git 命令。**
第一次会觉得命令很怪。**但记住三个概念就够了：工作区、暂存区、快照。** 命令只是这三个概念的操作。
