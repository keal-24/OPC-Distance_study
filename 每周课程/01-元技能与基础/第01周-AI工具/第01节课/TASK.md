# 第 1 节课：让人工智能帮你写出第一个小程序

## 先说清楚：这节课要学什么

这节课不是让你马上成为程序员，也不是让你背一堆英文。

这节课只学一件事：**怎样把自己的想法清楚地告诉人工智能，让它帮你写一个小程序；写完以后，怎样检查它有没有写错。**

你不需要提前会写代码，也不需要安装软件。你只需要准备：

- 一台电脑；
- 一个可以和人工智能聊天的工具；
- 能打开、复制和粘贴文字；
- 一个保存文件的文件夹。

如果你已经学过 C 语言，也不要跳步骤。今天练的是“怎样提出要求”和“怎样检查结果”，这和单独会写代码是两件事。

---

## 做完这节课，你必须拿到什么

结束时，你的文件夹里应该有两个文件：

```text
第01节课/
├── TASK.md       这份任务说明
├── try.js        你今天保存的练习代码
└── NOTES.md      你今天的学习记录
```

你还必须做到四件事：

- 能用自己的话解释：人工智能能帮你做什么，不能替你决定什么；
- 能写出一份“背景、任务、要求、限制、检查方法”都写清楚的提问；
- 能让人工智能写出一个简单的日期显示小程序；
- 能用正常输入和错误输入检查这个小程序。

**没有完成这四件事，就不要急着进入下一节课。**

# 第 1 步：先认识人工智能

## 这一步在做什么

你先不要急着复制代码。我们先弄明白：人工智能到底是什么，为什么它有时回答得很像真的，但仍然可能是错的。

## 用人话解释三个词

### 什么是“人工智能”

人工智能可以理解为一个读过大量文字和代码、能够根据你的问题生成回答的工具。

它不是你的老板，也不是负责替你承担后果的人。它只是根据你给它的内容，推测一个可能的答案。

### 什么是“代码”

代码就是写给电脑看的步骤。比如：

```text
先拿到一个日期
再判断这个日期是哪一年
最后把日期显示成中文
```

把这些步骤用电脑能执行的写法写出来，就是代码。

### 什么是“指令”

“指令”就是你发给人工智能的完整要求。

你可以把它想成你交给一个刚来上班的助手的工作单：

- 只说“把这个做好”，助手只能猜；
- 说清楚要做什么、不能改什么、怎样算完成，助手才有可能一次做对。

## 人工智能最擅长什么

它比较适合做有明确规则、可以检查的工作，例如：

- 根据你写好的要求生成一小段代码；
- 解释一条报错信息；
- 把一段文字改成表格；
- 根据几个输入和输出例子补全重复内容；
- 给一个小程序列出测试例子。

## 人工智能不能替你做决定的事情

下面这些事情不能直接相信它：

- 密码、密钥和登录权限；
- 钱、价格和账目；
- 删除数据库里的资料；
- 正式上线和修改服务器；
- 合同、报价和法律判断。

原因很简单：人工智能不知道你的全部情况，而且回答错了也不会替你承担损失。

## 现在做一个口头检查

请你不要看下面的答案，先自己回答：

> 人工智能负责什么？我负责什么？

正确答案应该接近：

> **人工智能负责按照我的要求写出结果，我负责判断这个结果是否符合要求。**

如果你能说出这句话，再进入下一步。

# 第 2 步：认识“指令”的五个组成部分

## 这一步为什么重要

你以后让人工智能帮你写网页、接口、数据库程序，都会用到这五部分。

不要先背英文名称。今天只记下面五个中文词：

```text
背景 → 任务 → 要求 → 限制 → 检查方法
```

它们就像一张工作单的五个格子。

## 第一部分：背景

### 它是什么意思

背景就是告诉人工智能：**你现在在哪个项目里，已经有什么东西。**

### 例子

```text
我正在学习 JavaScript，暂时没有使用其他代码库。
```

这里的“JavaScript”是一种编程语言。你现在不用深入学习它，只要知道：我们今天让人工智能用它写一个小程序。

### 不写背景会怎样

人工智能不知道你的水平和工具，可能给你一大套你没有学过的内容。你会发现它说了很多新词，却不知道从哪里开始。

## 第二部分：任务

### 它是什么意思

任务就是直接告诉它：**这次具体要做什么。**

### 例子

```text
请写一个把日期显示成中文的小程序。
```

## 第三部分：要求

### 它是什么意思

要求就是补充说明：**这个小程序要具备哪些具体行为。**

### 例子

```text
输入一个日期后：
- 如果是今天，显示“今天 时:分”；
- 如果是昨天，显示“昨天 时:分”；
- 如果是今年但不是今天，显示“月日 时:分”；
- 如果不是今年，显示“年年月日”。
```

## 第四部分：限制

### 它是什么意思

限制就是告诉它：**哪些事情不能做。**

### 例子

```text
- 只使用电脑自带的功能，不另外安装东西；
- 只写一个文件；
- 代码中的说明使用中文；
- 不要修改其他文件。
```

## 第五部分：检查方法

### 它是什么意思

检查方法就是告诉它：**怎样才算做对。**

### 例子

```text
请给出至少四组检查例子：今天、昨天、今年以前、输入为空。
```

## 用一个生活例子再理解一次

假设你让别人帮你买水：

- 背景：我在办公室，手里没有水；
- 任务：买一瓶水；
- 要求：买常温、没有气泡的水；
- 限制：不超过 3 元，不要买玻璃瓶；
- 检查方法：拿回来后看是不是常温、是不是没有气泡。

只说“帮我买水”，对方当然可能买错。让人工智能写代码，也是一样的道理。

# 第 3 步：先发一条不清楚的提问

## 这一步为什么要做

你要亲眼看见：**要求说得不清楚，结果就会由人工智能自己猜。**

## 具体操作

1. 打开你正在使用的人工智能聊天工具。
2. 找到可以输入问题的地方。
3. 复制下面这句话。

```text
写一个日期格式化程序。
```

4. 粘贴到输入框。
5. 点击发送按钮。
6. 等它回答完成。

## 你要观察什么

看它有没有回答下面这些问题：

- 日期从哪里输入？
- 要显示成什么样？
- 今天和昨天要不要特殊显示？
- 输入错误时怎么办？
- 要不要安装额外软件？

大概率它不会全部说明。这不是因为它“笨”，而是因为你没有把要求说清楚。

## 把这次回答留下来

1. 用鼠标选中它给出的代码。
2. 复制代码。
3. 先不要急着运行。
4. 打开本节课文件夹：

```text
B:\OPC-Distance_study\每周课程\01-元技能与基础\第01周-AI工具\第01节课\
```

5. 在文件夹空白处点击鼠标右键。
6. 选择“新建”→“文本文档”。
7. 把文件名改成：

```text
try.js
```

8. 如果电脑提示“是否更改文件扩展名”，点击“是”。
9. 用代码编辑器打开 `try.js`。
10. 把刚才的代码粘贴进去。
11. 在代码上方加一行说明：

```javascript
// 这是人工智能根据模糊提问给出的版本
```

12. 按 `Ctrl + S` 保存。

### 做完之后应该看到什么

文件夹里应该出现：

```text
try.js
```

文件打开后，里面有人工智能刚才给出的代码。

### 如果找不到文件

先确认你打开的是这个文件夹，而不是桌面或下载文件夹：

```text
每周课程\01-元技能与基础\第01周-AI工具\第01节课
```

# 第 4 步：写一条完整的提问

## 这一步为什么要做

现在我们把刚才缺少的内容一项一项补上，让人工智能不再猜。

不要自己改词。先完整复制下面的内容。

## 完整提问模板

```text
我正在学习 JavaScript。这是我第一次练习让人工智能帮我写小程序。

任务：
请写一个名为 formatTime 的函数，把一个日期文字转换成中文显示文字。
函数的意思是：我给它一个日期，它返回一段更容易看懂的中文。

要求：
1. 输入是一段日期文字，例如：2026-11-16T12:30:00+08:00。
2. 如果输入的是今天，返回“今天 12:30”这样的格式。
3. 如果输入的是昨天，返回“昨天 12:30”这样的格式。
4. 如果输入的是今年但不是今天或昨天，返回“11月16日 12:30”这样的格式。
5. 如果输入的日期不是今年，返回“2025年11月16日”这样的格式。
6. 如果输入为空、不是日期或无法识别，返回“未知时间”。
7. 请把完整代码写出来，不要用省略号代替代码。
8. 每一段代码后面用中文解释它的作用。

限制：
1. 只使用 JavaScript 自带功能，不安装其他东西。
2. 只写一个文件里的代码。
3. 不要修改我的其他文件。
4. 先解释写法，再给完整代码。

检查方法：
请在代码后面给出至少六个检查例子：
1. 今天的日期；
2. 昨天的日期；
3. 今年其他日期；
4. 去年的日期；
5. 空文字；
6. 完全不是日期的文字。
每个例子都写出应该得到什么结果。
```

## 发送前自己检查五个格子

请用鼠标从上到下看一遍：

- 有没有写“我正在学习什么”？——这就是背景；
- 有没有写“请做什么”？——这就是任务；
- 有没有写具体规则？——这就是要求；
- 有没有写“不允许做什么”？——这就是限制；
- 有没有写“怎么检查”？——这就是检查方法。

五个格子都有内容，点击发送。

## 你可能看到的陌生词

### JavaScript

一种让网页和电脑执行操作的编程语言。今天只需要把它理解为“我们要使用的代码语言”。

### 函数

一段可以反复使用的小程序。你把日期交给它，它把整理后的文字还给你。

### 输入

你交给小程序的内容。今天的输入就是一段日期文字。

### 返回

小程序处理完以后交给你的结果。

### 格式

内容呈现的样子。例如“今天 12:30”就是一种显示格式。

如果人工智能又突然出现你不懂的词，不要猜。复制那个词，然后单独问：

```text
请用完全不懂编程的人能听懂的话解释“这个词”。先说它解决什么问题，再举一个生活中的例子，不要使用新的专业词。
```

# 第 5 步：把完整版本保存下来

1. 等人工智能回答完成。
2. 找到它回答里的完整代码部分。
3. 复制完整代码。
4. 回到 `try.js` 文件。
5. 在原来的代码下面空两行。
6. 添加下面这行说明：

```javascript
// 下面是按照完整要求生成的版本
```

7. 把完整版本粘贴到下面。
8. 按 `Ctrl + S` 保存。

现在 `try.js` 里应该有两份代码：

```text
第一份：只根据模糊提问得到的代码
第二份：根据五个部分完整要求得到的代码
```

## 这里先不要做的事

- 不要把两份代码混在一起；
- 不要删掉第一份；
- 不要看到代码很长就直接相信；
- 不要让人工智能替你判断“已经正确”。

我们下一步就是自己检查。

# 第 6 步：检查人工智能写的代码

## 检查一：先看它有没有完整回答

对照刚才的要求，逐条检查：

- 有没有处理今天？
- 有没有处理昨天？
- 有没有处理今年其他日期？
- 有没有处理去年的日期？
- 有没有处理空输入？
- 有没有处理乱写的文字？
- 有没有给完整代码？
- 有没有使用你没有允许的额外工具？

缺一项，就在人工智能对话框里发：

```text
请对照我刚才列出的 8 条要求，逐条检查你的代码。每一条写“已完成”或“未完成”。未完成的地方请补上完整代码，不要只说思路。
```

## 检查二：让它解释每一段

在对话框里发送：

```text
请从第一行开始，用完全不懂编程的人能听懂的话，一段一段解释这份代码。每次只解释一小段，解释完停下来，不要一次说一大堆新词。
```

如果它说出不懂的词，马上追问：

```text
我不懂“这里的词语”。请不要使用其他专业词，只用生活中的例子解释它为什么要放在这里。
```

## 检查三：用正常内容测试

在完整代码的最后面，添加下面的检查代码。注意：如果人工智能已经给了检查代码，就不要重复添加。

```javascript
console.log(formatTime("2026-11-16T12:30:00+08:00"));
console.log(formatTime("2025-11-16T12:30:00+08:00"));
```

这两行的作用是：把两个日期交给小程序，看它返回什么。

你现在不用急着理解每个符号。只要知道：`console.log` 的作用是把结果显示出来。

## 检查四：专门输入错误内容

继续在最后面加入：

```javascript
console.log(formatTime(""));
console.log(formatTime("这不是日期"));
console.log(formatTime(null));
```

这三组内容分别表示：

- 空内容；
- 完全不像日期的文字；
- 没有内容。

### 合格的结果

错误内容不能让整个程序突然停止。它应该返回类似：

```text
未知时间
```

如果出现红色错误文字，不要慌。把完整错误复制下来，发给人工智能：

```text
我按照要求输入了错误内容，出现了下面的完整错误：

（把错误原样粘贴在这里）

请先告诉我：错误发生在哪一行、用完全不懂编程的话解释原因；再给出只修改必要部分的完整代码。不要改其他功能。
```

## 检查五：看改了几个文件

本节课只要求写一个文件，所以应该只有下面这个文件被你新增或修改：

```text
第01节课/try.js
```

如果人工智能工具自动修改了其他文件，先停下来，不要继续。把多出来的文件名记在 `NOTES.md` 里，并问清楚为什么要改。

# 第 8 步：提交本节课的成果


## 在编辑器里提交

1. 打开编辑器左侧的“源代码管理”图标。
2. 看见 `try.js` 和 `NOTES.md` 出现在改动列表里。
3. 在上方输入框写：

```text
第01节课：人工智能指令与结果检查
```

4. 点击“提交”按钮。
5. 再点击“同步”按钮。
6. 打开 GitHub 仓库网页，确认能看到这两个文件。

## 也可以使用命令提交

如果你已经学过命令行，可以在仓库根目录执行：

```bash
git add -A
git commit -m "第01节课：人工智能指令与结果检查"
git push
```

这里三条命令分别是：

- `git add -A`：把本次改动放进待提交清单；
- `git commit`：在电脑上保存一个版本；
- `git push`：把这个版本上传到 GitHub。

只执行前两条还不算上传完成，必须执行 `git push`，并到 GitHub 网页确认。
