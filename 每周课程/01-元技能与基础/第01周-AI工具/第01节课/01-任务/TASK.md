# 第 1 节课：让人工智能帮你写出第一个小程序

## 先说清楚：这节课要学什么

这节课不是让你马上成为程序员，也不是让你背一堆英文。

这节课只学一件事：**怎样把自己的想法清楚地告诉人工智能，让它帮你写一个小程序；写完以后，怎样检查它有没有写错。**

你不需要提前会写代码，也不需要安装软件。你只需要准备：

- 一台电脑；
- 一个可以和人工智能聊天的工具；
- 能打开、复制和粘贴文字；
- 一个保存文件的文件夹。

如果你已经学过 C 语言，也不要跳步骤。今天练的是“怎样提出要求”和“怎样检查结果”，这和单独会写代码是两件事。

---

## 做完这节课，你必须拿到什么

结束时，你的文件夹里应该有两个文件：

```text
第01节课/
├── TASK.md       这份任务说明
├── try.js        你今天保存的练习代码
└── NOTES.md      你今天的学习记录
```

你还必须做到四件事：

- 能用自己的话解释：人工智能、大语言模型、智能体和工具连接方式分别是什么；
- 能用自己的话解释：人工智能能帮你做什么，不能替你决定什么；
- 能写出一份“背景、任务、要求、限制、检查方法”都写清楚的提问；
- 能让人工智能写出一个简单的日期显示小程序；
- 能用正常输入和错误输入检查这个小程序。

**没有完成这四件事，就不要急着进入下一节课。**

# 第 1 步：先认识人工智能

## 这一步在做什么

你先不要急着复制代码。我们先弄明白：人工智能到底是什么，为什么它有时回答得很像真的，但仍然可能是错的。

## 先认识人工智能世界里的四个常见词

今天会遇到四个英文缩写。**不用背英文，只要先知道它们分别像什么。**以后每次遇到新词，我们都先解释，再使用。

### 第一层：人工智能

人工智能是总称，意思是：让电脑完成一些原本需要人来判断、理解或生成的工作。

你现在使用的 WorkBuddy、Codex，都是帮助你使用人工智能能力的工具。

### 第二层：LLM（大语言模型）

**LLM** 是英文“Large Language Model”的缩写，中文叫“大语言模型”。

你可以先把它理解成：**负责理解文字、根据文字生成回答的核心大脑。**

例如，你输入：

```text
请把这段话改得更容易理解。
```

大语言模型负责读懂你的话，再生成一段新的文字。

它能写文字、解释代码、生成代码，但它不等于一个完整的软件，也不等于它真的理解了你的业务。它只是根据已有信息生成最可能的回答，所以仍然需要你检查。

### 第三层：Agent（智能体）

**Agent** 是英文“智能体”的意思。它不是只回答一句话，而是：**接到一个目标后，自己分成几步，调用工具，做完后再把结果交给你。**

比如你说：

```text
读取这个文件，找出所有金额，算出总数，再生成一份报告。
```

普通聊天可能只告诉你应该怎么做；智能体则可能按照顺序：读取文件、提取金额、计算总数、生成报告。

你要记住：智能体能自己做更多步骤，所以能力更强，**也更需要你限制范围、检查每一步，不能让它随便删除文件或修改重要资料。**

### 第四层：MCP（工具连接方式）

**MCP** 是英文“Model Context Protocol”的缩写。今天不用背这个英文全称，可以先理解成：**让人工智能按照统一方式连接外部工具的接口。**

生活中的例子：

- 大语言模型像一个会思考的助手；
- MCP 像插座和统一插头；
- 文件、数据库、浏览器等工具像不同的电器；
- 接好以后，助手才有办法通过这个连接使用工具。

例如，人工智能本身不能凭空看到你的 GitHub、数据库或本地文件。连接了对应的工具后，它才可能读取或操作这些东西。

**最重要的安全规则：连接工具不等于可以随便操作。**涉及删除文件、修改数据库、发送消息、花钱或上线的动作，都要先看清楚并确认。

## 四个词放在一起怎么理解

```text
人工智能：总称
大语言模型：负责理解和生成文字的核心能力
智能体：围绕目标分步骤完成任务的工作方式
MCP：让人工智能连接外部工具的一种统一方式
```

今天真正要用的是：**人工智能聊天工具 + 大语言模型 + 清楚的提问。**

智能体和 MCP 先做到“知道是什么、知道有什么风险”，后面课程再专门动手使用，不在今天一次塞太多内容。

## 用人话解释三个词

### 什么是“人工智能”

人工智能可以理解为一个读过大量文字和代码、能够根据你的问题生成回答的工具。

它不是你的老板，也不是负责替你承担后果的人。它只是根据你给它的内容，推测一个可能的答案。

### 什么是“代码”

代码就是写给电脑看的步骤。比如：

```text
先拿到一个日期
再判断这个日期是哪一年
最后把日期显示成中文
```

把这些步骤用电脑能执行的写法写出来，就是代码。

### 什么是“指令”

“指令”就是你发给人工智能的完整要求。

你可以把它想成你交给一个刚来上班的助手的工作单：

- 只说“把这个做好”，助手只能猜；
- 说清楚要做什么、不能改什么、怎样算完成，助手才有可能一次做对。

## 人工智能最擅长什么

它比较适合做有明确规则、可以检查的工作，例如：

- 根据你写好的要求生成一小段代码；
- 解释一条报错信息；
- 把一段文字改成表格；
- 根据几个输入和输出例子补全重复内容；
- 给一个小程序列出测试例子。

## 人工智能不能替你做决定的事情

下面这些事情不能直接相信它：

- 密码、密钥和登录权限；
- 钱、价格和账目；
- 删除数据库里的资料；
- 正式上线和修改服务器；
- 合同、报价和法律判断。

原因很简单：人工智能不知道你的全部情况，而且回答错了也不会替你承担损失。

## 现在做一个口头检查

请你不要看下面的答案，先自己回答：

> 人工智能负责什么？我负责什么？

正确答案应该接近：

> **人工智能负责按照我的要求写出结果，我负责判断这个结果是否符合要求。**

如果你能说出这句话，再进入下一步。

# 第 2 步：认识“指令”的五个组成部分

## 这一步为什么重要

你以后让人工智能帮你写网页、接口、数据库程序，都会用到这五部分。

不要先背英文名称。今天只记下面五个中文词：

```text
背景 → 任务 → 要求 → 限制 → 检查方法
```

它们就像一张工作单的五个格子。

## 第一部分：背景

### 它是什么意思

背景就是告诉人工智能：**你现在在哪个项目里，已经有什么东西。**

### 例子

```text
我正在学习 JavaScript，暂时没有使用其他代码库。
```

这里的“JavaScript”是一种编程语言。你现在不用深入学习它，只要知道：我们今天让人工智能用它写一个小程序。

### 不写背景会怎样

人工智能不知道你的水平和工具，可能给你一大套你没有学过的内容。你会发现它说了很多新词，却不知道从哪里开始。

## 第二部分：任务

### 它是什么意思

任务就是直接告诉它：**这次具体要做什么。**

### 例子

```text
请写一个把日期显示成中文的小程序。
```

## 第三部分：要求

### 它是什么意思

要求就是补充说明：**这个小程序要具备哪些具体行为。**

### 例子

```text
输入一个日期后：
- 如果是今天，显示“今天 时:分”；
- 如果是昨天，显示“昨天 时:分”；
- 如果是今年但不是今天，显示“月日 时:分”；
- 如果不是今年，显示“年年月日”。
```

## 第四部分：限制

### 它是什么意思

限制就是告诉它：**哪些事情不能做。**

### 例子

```text
- 只使用电脑自带的功能，不另外安装东西；
- 只写一个文件；
- 代码中的说明使用中文；
- 不要修改其他文件。
```

## 第五部分：检查方法

### 它是什么意思

检查方法就是告诉它：**怎样才算做对。**

### 例子

```text
请给出至少四组检查例子：今天、昨天、今年以前、输入为空。
```

## 用一个生活例子再理解一次

假设你让别人帮你买水：

- 背景：我在办公室，手里没有水；
- 任务：买一瓶水；
- 要求：买常温、没有气泡的水；
- 限制：不超过 3 元，不要买玻璃瓶；
- 检查方法：拿回来后看是不是常温、是不是没有气泡。

只说“帮我买水”，对方当然可能买错。让人工智能写代码，也是一样的道理。

# 第 3 步：在具体工具里发一条不清楚的提问

## 这一步为什么要做

你要亲眼看见：**同一句话，在不同工具里都可以发送，但因为要求不清楚，结果会由人工智能自己猜。**

本节课我们用两个具体工具来练习：

- **WorkBuddy**：国内使用比较方便的人工智能工具。你现在就是在这里和我对话。
- **Codex**：可以直接查看和修改电脑上代码文件的人工智能编程工具。

今天先用 WorkBuddy 或 Codex 其中一个，不需要两个都安装。你已经能打开哪个，就先用哪个完成练习。

>
> 如果你用的是 Codex，下面说的“输入框”就是 Codex 窗口底部的对话输入框；如果它第一次询问是否允许读取文件，先选择“允许本次操作”，因为今天还没有让它修改文件。

6. 检查输入框里的文字和上面完全一样。
7. 点击输入框右侧的发送按钮；如果看不到按钮，按键盘上的 `Enter` 键发送。

## 具体操作：使用 Codex

1. 打开 Codex。

## 你要观察什么

看它有没有回答下面这些问题：

- 日期从哪里输入？
- 要显示成什么样？
- 今天和昨天要不要特殊显示？
- 输入错误时怎么办？
- 要不要安装额外软件？

把 WorkBuddy 或 Codex 想成一个很快的助手：你只说“写一个日期格式化程序”，它不知道你想要哪种显示方式，所以可能给出完全不同的答案。

大概率它不会全部说明。这不是因为工具“笨”，而是因为你没有把要求说清楚。

本课程后面会单独教你安装和使用 WorkBuddy、Codex，不要求你今天同时学会两个工具。

# 第 4 步：写一条完整的提问

## 这一步为什么要做

现在我们把刚才缺少的内容一项一项补上，让人工智能不再猜。

不要自己改词。先完整复制下面的内容。

## 完整提问模板

```text
我正在学习 JavaScript。这是我第一次练习让人工智能帮我写小程序。

任务：
请写一个名为 formatTime 的函数，把一个日期文字转换成中文显示文字。
函数的意思是：我给它一个日期，它返回一段更容易看懂的中文。

要求：
1. 输入是一段日期文字，例如：2026-11-16T12:30:00+08:00。
2. 如果输入的是今天，返回“今天 12:30”这样的格式。
3. 如果输入的是昨天，返回“昨天 12:30”这样的格式。
4. 如果输入的是今年但不是今天或昨天，返回“11月16日 12:30”这样的格式。
5. 如果输入的日期不是今年，返回“2025年11月16日”这样的格式。
6. 如果输入为空、不是日期或无法识别，返回“未知时间”。
7. 请把完整代码写出来，不要用省略号代替代码。
8. 每一段代码后面用中文解释它的作用。

限制：
1. 只使用 JavaScript 自带功能，不安装其他东西。
2. 只写一个文件里的代码。
3. 不要修改我的其他文件。
4. 先解释写法，再给完整代码。

检查方法：
请在代码后面给出至少六个检查例子：
1. 今天的日期；
2. 昨天的日期；
3. 今年其他日期；
4. 去年的日期；
5. 空文字；
6. 完全不是日期的文字。
每个例子都写出应该得到什么结果。
```

## 发送前自己检查五个格子

请用鼠标从上到下看一遍：

- 有没有写“我正在学习什么”？——这就是背景；
- 有没有写“请做什么”？——这就是任务；
- 有没有写具体规则？——这就是要求；
- 有没有写“不允许做什么”？——这就是限制；
- 有没有写“怎么检查”？——这就是检查方法。

五个格子都有内容，点击发送。

## 你可能看到的陌生词

### JavaScript

一种让网页和电脑执行操作的编程语言。今天只需要把它理解为“我们要使用的代码语言”。

### 函数

一段可以反复使用的小程序。你把日期交给它，它把整理后的文字还给你。

### 输入

你交给小程序的内容。今天的输入就是一段日期文字。

### 返回

小程序处理完以后交给你的结果。

### 格式

内容呈现的样子。例如“今天 12:30”就是一种显示格式。

如果人工智能又突然出现你不懂的词，不要猜。复制那个词，然后单独问：

```text
请用完全不懂编程的人能听懂的话解释“这个词”。先说它解决什么问题，再举一个生活中的例子，不要使用新的专业词。
```

# 第 6 步：检查人工智能写的代码

## 检查一：先看它有没有完整回答

对照刚才的要求，逐条检查：

- 有没有处理今天？
- 有没有处理昨天？
- 有没有处理今年其他日期？
- 有没有处理去年的日期？
- 有没有处理空输入？
- 有没有处理乱写的文字？
- 有没有给完整代码？
- 有没有使用你没有允许的额外工具？

缺一项，就在人工智能对话框里发：

```text
请对照我刚才列出的 8 条要求，逐条检查你的代码。每一条写“已完成”或“未完成”。未完成的地方请补上完整代码，不要只说思路。
```

## 检查二：让它解释每一段

在对话框里发送：

```text
请从第一行开始，用完全不懂编程的人能听懂的话，一段一段解释这份代码。每次只解释一小段，解释完停下来，不要一次说一大堆新词。
```

如果它说出不懂的词，马上追问：

```text
我不懂“这里的词语”。请不要使用其他专业词，只用生活中的例子解释它为什么要放在这里。
```

## 检查三：用正常内容测试

在完整代码的最后面，添加下面的检查代码。注意：如果人工智能已经给了检查代码，就不要重复添加。

```javascript
console.log(formatTime("2026-11-16T12:30:00+08:00"));
console.log(formatTime("2025-11-16T12:30:00+08:00"));
```

这两行的作用是：把两个日期交给小程序，看它返回什么。

你现在不用急着理解每个符号。只要知道：`console.log` 的作用是把结果显示出来。

## 检查四：专门输入错误内容

继续在最后面加入：

```javascript
console.log(formatTime(""));
console.log(formatTime("这不是日期"));
console.log(formatTime(null));
```

这三组内容分别表示：

- 空内容；
- 完全不像日期的文字；
- 没有内容。

### 合格的结果

错误内容不能让整个程序突然停止。它应该返回类似：

```text
未知时间
```

如果出现红色错误文字，不要慌。把完整错误复制下来，发给人工智能：

```text
我按照要求输入了错误内容，出现了下面的完整错误：

（把错误原样粘贴在这里）

请先告诉我：错误发生在哪一行、用完全不懂编程的话解释原因；再给出只修改必要部分的完整代码。不要改其他功能。
```
