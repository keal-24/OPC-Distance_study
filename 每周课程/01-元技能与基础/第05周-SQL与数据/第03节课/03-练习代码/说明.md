## 为什么这节课必须自己敲

这节课的坑全是"不报错但结果错"：

- `= NULL` 返回 0 条，不报错，你以为真没有；
- `!=` 漏掉 null 行，少 15 条，不报错；
- `NOT IN` 带 null 返回 0 条，不报错；
- 整数除法丢小数，不报错；
- `AND`/`OR` 优先级，不报错，结果差一半。

**五个坑，五个都不报错。** 这是最危险的一类 bug。

## 数据是随机的，数字会变

`seed-big.mjs` 用了 `Math.random()`，所以每次跑数据都不一样。

**这意味着：课件里的具体数字（44、59、15）在你的机器上会不同。**

**但关系永远成立：**

```text
COALESCE 的结果 - != 的结果 = null 的条数
```

**你要看的是这个关系，不是具体数字。**

## 必须自己亲眼看到的对比

这五个坑，每个都是"两个查询结果不同"：

```text
12345/100      vs  12345/100.0
无括号 AND/OR  vs  有括号
= NULL         vs  IS NULL
!=             vs  COALESCE !=
NOT IN 无null  vs  NOT IN 带null
```

**五个对比都要并排打印出来看。**
