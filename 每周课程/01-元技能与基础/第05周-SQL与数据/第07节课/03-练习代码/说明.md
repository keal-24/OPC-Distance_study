# 03-练习代码

本节课你要自己建：

```text
03-练习代码/
└── backup-lab/            ← 你自己建
    ├── seed.mjs           3 用户 + 300 文章
    ├── disaster.mjs       模拟 DELETE 忘 WHERE
    ├── check-mode.mjs     看 journal_mode
    ├── wal-test.mjs       验证 WAL 下直接复制的坑
    ├── backup-simple.mjs  最简单的备份
    ├── verify-backup.mjs  四层验证

```

## 这节课必须真删一次数据

**这不是可选项。**

`disaster.mjs` 会 `DELETE FROM posts`（不带 WHERE），**300 篇文章瞬间消失**。

**你必须真的跑一次，感受一下那个"删除后文章数: 0"。**

**然后跑 `restore.mjs` 恢复回来，感受一下"失而复得"。**

**这两个感受加起来，才是"为什么备份重要"的完整体验。**

## 必须亲眼看到的三个现象

**① WAL 模式下复制文件会失败**

```text
wal.db 只有 4KB（几乎空）
wal.db-wal 有 50KB（真数据在这）
复制 wal.db → 得到 "no such table: t"
```

**② `db.backup` 不存在**

```text
TypeError: db.backup is not a function
```

**③ `backup()` 返回 Promise**

不 `await` 就 `close`，备份可能不完整。

## 备份的三个"必须"

```text
必须验证  —— integrity_check + 行数对比
必须自动  —— 手动一定会忘
必须演练  —— 没恢复过的备份不算备份
```

## 关于 backups 目录

**这个目录里的文件不要提交进 Git。**

在你的 `.gitignore` 里加：

```text
backups/
*.db
*.db-wal
*.db-shm
```

**为什么：** 数据库是二进制，Git 每次都存完整副本。半年后仓库会变成几个 GB。
