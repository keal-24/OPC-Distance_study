## 必须自己亲眼看到的四组数字

**① UPDATE 忘 WHERE**

```text
changes: 4    ← 全部行被改
```

**② 事务的性能**

```text
无事务 2000 条：~4972 ms
有事务 2000 条：~4 ms
```

差 1243 倍。**你的机器数字会不同，但比例会是这个量级。**

**③ 事务的原子性**

```text
有事务：第二条失败 → 0 条
无事务：第二条失败 → 1 条脏数据
```

**④ 索引的性能**

```text
无索引：~25 ms
有索引：~7 ms
```

**这四组数字必须自己跑出来。** 因为"快 1000 倍"这种话，别人说是故事，自己做是认知。

## 最值钱的产出是三个安全函数

`safeUpdate` / `safeDelete` / `safeRestore` 这三个，写好了可以直接放进项目。

**核心逻辑：**

```text
拒绝空 WHERE → 先 SELECT 预览 → 事务包裹 → 检查 changes → 不对就回滚
```
