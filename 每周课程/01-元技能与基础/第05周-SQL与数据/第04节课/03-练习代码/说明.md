## 为什么这节课必须自己敲

这节课的核心是**两个"看不见"的问题**：

**一、中文排序看着像随机的。**

你不自己跑一遍 `ORDER BY name`，不会相信 SQLite 排中文有多乱。而且它会给你一种"好像有点规律"的错觉，让你以为调调参数就好了。

**二、`NULL` 排序位置和直觉相反。**

`ORDER BY stock ASC` 第一行是 `null`，不是 `0`。这个不实测一次，你永远会记错。

## 必须自己做的三个对比

**① 中文排序**

```text
ORDER BY name                    ← 数据库的乱序
[...rows].sort(localeCompare)    ← 拼音序
```

两个顺序必须并排看。

**② NULL 位置**

```text
ORDER BY stock ASC              ← null 在最前
ORDER BY stock ASC NULLS LAST   ← null 在最后
```

**③ LIKE 大小写**

```text
SELECT 'ABC' LIKE 'a%'              → 1（不敏感）
SELECT 'ABC' LIKE 'a%' COLLATE BINARY → 0（敏感）
```

## 最值钱的产出是 filters.mjs

**这不是练习题，这是可以放进真实项目的代码。**

写完之后，你以后做任何"列表 + 筛选 + 排序 + 分页"的接口，都能直接用它。

**要求：**

- 所有参数缺失时返回全部；
- 所有参数是垃圾值时用默认值，不崩；
- 所有值走 `?` 参数；
- `ORDER BY` 走白名单。
