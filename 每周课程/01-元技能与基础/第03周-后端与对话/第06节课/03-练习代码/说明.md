## 为什么这节课必须自己敲

这节课的错误全是"不报错但会出大事"的类型：

- 密钥写在前端 → 功能正常，但 **F12 就能看到密钥**；
- 不设超时 → 正常情况也能用，但 **模型卡住时请求永远不结束**；
- 错误细节给用户 → 用户能看到你的接口地址和内部结构；
- 用 `.json()` 读错误响应 → 遇到 HTML 错误页时报 `Unexpected token '<'`，**掩盖真错误**。

**这些坑不自己撞一遍，上线后一定出事。**

## 没有密钥怎么办

课件里给了一个**本地假模型**（`src/mock-llm.js`），它会模拟 OpenAI 兼容接口。

它有四个触发词，专门用来测异常：

| 输入包含 | 行为 |
|---|---|
| `慢` | 8 秒后才回复 |
| `出错` | 返回 500 |
| `网页错误` | 返回 HTML 错误页 |
| `空` | 返回空内容 |

**用假模型把整套流程和错误处理练熟，再换成真模型。**

## 绝不要做的事

- 不要把 `.env` 提交到 Git；
- 不要把密钥直接写在 `.js` 文件里；
- 不要把密钥传给前端。

**如果你不小心提交了，立刻去后台吊销这个密钥并重新生成。** 只删文件没用，Git 历史里还在。
