# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己建出新项目：

```text
express-server/
├── package.json
├── .gitignore
├── node_modules/      ← npm install 自动生成，不提交
└── src/
    └── app.js
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么这节课必须自己敲

- 中间件忘了 `next()` 的现象是"浏览器一直转圈"，不自己撞到不会记住；
- 错误处理中间件少写一个参数就完全失效，这个坑代码看起来完全正常；
- 404 兜底放错位置会让**所有页面**都 404。

## 命令要在正确的目录执行

```text
cd express-server
npm init -y
npm install express
npm run dev
```

**在 `03-练习代码` 里执行会装错地方。**

## 装完之后检查

打开 `package.json`，应该看到：

```json

  "express": "^4.22.3"
}
```
