# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己建出这个结构：

```text
hello-server/
├── package.json
├── .gitignore
└── src/
    ├── config.js
    ├── routes.js
    └── server.js
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么这节课必须自己敲

- `"type": "module"` 之后 `require` 会报错，这个错必须自己撞到；
- import 路径少了 `./` 或 `.js`，报错信息说的是"package 找不到"，很容易误判成没装依赖；
- 不监听 `error` 事件时，端口占用会吐一大段看不懂的堆栈。

## 怎么建文件

1. 先新建文件夹 `hello-server`，再进去新建 `src`；
2. 在 `hello-server` 里打开终端（地址栏输入 `cmd`）；
3. `npm init -y` 生成 `package.json`；
4. 用 Visual Studio Code 新建 `.gitignore`（Windows 资源管理器不让建点开头的文件）；
5. 在 `src` 里新建三个 `.js` 文件，自己敲；
6. `npm run dev` 启动。

## 注意目录

**所有命令都必须在 `hello-server` 里执行**，不是 `03-练习代码`，也不是仓库根目录。

跑命令前先 `cd` 确认路径。
