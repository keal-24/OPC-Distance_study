# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己建出：

```text
chat-app/
├── package.json
├── .gitignore
├── node_modules/       ← npm install 生成
├── src/
│   └── app.js          服务器 + 接口
└── public/
    ├── index.html      页面
    └── main.js         页面里的请求逻辑
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么这节课必须自己敲

这节课是前端和后端第一次真正连起来，出错的环节特别多：

- 静态目录路径错 → 页面 404 但接口正常；
- 忘 `Content-Type` → 服务器收不到 body；
- 忘 `JSON.stringify` → 收到 `[object Object]`；
- 不判 `response.ok` → 报 `Unexpected token '<'`。

**这些现象只有自己撞到，才会在下次一眼认出来。**

## 特别注意

`main.js` 在浏览器里的路径是 `/main.js`，**不是 `/public/main.js`**。

因为 `express.static` 已经把 `public` 这个前缀去掉了。
