# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这两个文件：

```text
server.js   你的第一个服务器
logs.md     你的请求记录
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么这节课必须自己敲

- `res.end()` 忘写会导致浏览器一直转圈——这个现象只能自己撞到才知道；
- `Content-Type` 少了 `charset=utf-8` 就是乱码，自己试过才会记住；
- 漏 `return` 会报 `ERR_HTTP_HEADERS_SENT`，但页面看起来还正常，这种"看着对实际错"最危险。

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成 `server.js`；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. 自己敲代码，`Ctrl + S` 保存。

## 启动与停止

```text
启动：在终端里输入 node server.js
停止：在终端里按 Ctrl + C
```

**改代码后必须重启，否则跑的还是旧代码。**
