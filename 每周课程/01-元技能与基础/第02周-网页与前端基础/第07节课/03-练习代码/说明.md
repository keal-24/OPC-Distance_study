# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这三个文件：

```text
index.html   你的个人主页
style.css    样式
main.js      交互（深色切换、字数统计、提交提示）
```

课件里的代码是"骨架 + 示例内容"，**你可以参考结构，但内容必须换成你自己的**。

## 为什么这一节课尤其不能抄

前六节课的代码抄了还能学到东西。这一节课如果抄，你交出来的就是"别人的主页"。

- 名字是别人的；
- "关于我"是课件里的套话；
- 技能列表写着"精通"，但你只学了两周。

**面试官打开一看就知道。这比没有作品更糟。**

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成 `index.html`、`style.css` 或 `main.js`；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. `Ctrl + S` 保存，浏览器按 `F5`，`F12` 看控制台。

## 做完后必须自己检查

- 手机模拟（`F12` → 手机图标）下能不能看？
- 只用键盘（Tab 键）能不能操作？
- 深色模式下所有文字都看得清吗？
- 控制台有没有红色报错？

## 收尾

做完之后，把这个页面的路径写进仓库根目录的 `CONTEXT.md` 的"我的作品"里。
这是你第一个能拿给别人看的东西。
