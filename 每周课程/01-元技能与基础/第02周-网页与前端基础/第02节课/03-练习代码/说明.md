# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这两个文件：

```text
bad.html    全是 div 的对照版本
index.html  语义化版本
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么 HTML 课更不能复制

- HTML 出错不会报错，只会显示不对；
- 只有自己敲过、自己漏过闭合标签，你才会知道"显示乱了"是什么感觉；
- 语义化是一种判断，不是一种写法。照着抄你永远不会判断。

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成 `bad.html` 或 `index.html`；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. 自己敲代码，`Ctrl + S` 保存；
7. 双击文件用浏览器打开，按 `F5` 刷新。
