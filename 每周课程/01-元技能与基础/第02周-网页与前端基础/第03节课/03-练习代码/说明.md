# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这两个文件：

```text
index.html   页面结构（上节课的内容，加一行 link）
style.css    你自己写的样式
```

课件里的 CSS 只作对照，不要整段复制粘贴。

## 为什么 CSS 更不能复制

- CSS 写错了不报错，只会"不生效"，必须自己撞过才知道怎么查；
- 复制来的样式你不会有"这条改成 20px 会怎样"的感觉；
- 这节课的作业是"调出三种间距感觉"，必须自己动手改数值。

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成 `index.html` 或 `style.css`；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. `Ctrl + S` 保存，浏览器按 `F5` 刷新。

## 提醒

`index.html` 和 `style.css` 必须放在同一个文件夹里，否则 `<link href="style.css">` 找不到文件。
