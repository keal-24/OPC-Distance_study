# 第02周 · 网页与前端基础 · 第8-14节课

## 亲手写页面，不是让 AI 写

---

## 这一周的目标

从零做出一个能在浏览器打开、能交互、能给别人看的页面。

这一周你会**亲手敲** HTML、CSS、JavaScript。不是看 AI 生成，是自己写。

## 为什么排在这一周

你必须先自己写过一遍，才知道 AI 写的东西哪里不对。

**跳过这一周的人，后面 34 周永远只能照抄。** 因为当 AI 给你一段样式错乱的代码时，你没有能力判断是哪里错了。

## 每一节课怎么用

```text
第0X节课/
├── 01-任务/TASK.md       ← 先读这个，从头到尾
├── 02-笔记/NOTES.md      ← 边学边填，不能留空
└── 03-练习代码/           ← 故意留空，文件自己新建、代码自己敲
```

**`03-练习代码` 是空的。** 这是规矩：

- 课件里的代码是对照用的标准答案，不是让你复制的素材；
- 复制粘贴只会手会，脑子没会；
- 这一周的错误特点是"不报错，只是显示不对"，只有亲手敲过才知道错在哪。

## 这一周最容易卡住的五个地方

**第一处：第 8 节课看到一堆代码而不是网页。**
你建的文件实际叫 `index.html.txt`。**先去"查看"里勾上"文件扩展名"。**

**第二处：第 10 节课样式完全不生效。**
先按 `F12` 看控制台有没有 `404`。**十次里有八次是 `<link href="...">` 的文件名写错了。**

**第三处：第 11 节课单选按钮能多选。**
两个 `radio` 的 `name` 不一样。**必须完全相同。**

**第四处：第 12 节课结果全是 `NaN`。**
输入框的 `.value` 是字符串，忘了用 `Number()` 转。

**第五处：第 13 节课点了按钮没反应。**
`addEventListener("click", update())` —— **函数名多加了括号。**

## 这一周的七个坑（提前知道）

| 坑 | 现象 | 一句话解法 |
|---|---|---|
| 文件存成 `.txt` | 双击看到代码不是网页 | 打开"文件扩展名"显示，重命名 |
| 中文引号 | 属性失效 | 改成英文 `"` |
| 漏闭合标签 | 后面的内容被吞进前一个标签 | 点开头的 `{` 看是否配对 |
| `width: 100%` 溢出 | 出现横向滚动条 | 加 `box-sizing: border-box` |
| `==` 比较 | 空字符串被当成 0 | 一律用 `===` |
| `innerHTML` 显示用户输入 | 可能被注入脚本 | 用 `textContent` |
| 按钮没写 `type` | 点了页面就刷新 | 写 `type="button"` |

## 这一周不用学的（别被这些分心）

```text
❌ 框架（React / Vue）—— 第 27 周
❌ 响应式布局细节（flex / grid）—— 第 27 周
❌ 打包工具（webpack / vite）—— 第 20 周
❌ CSS 预处理器（Sass）—— 用不到
❌ 动画库、UI 组件库 —— 用不到
```

**这一周只用原生 HTML + CSS + JS，一个库都不装。**

**为什么：** 因为你要先知道"原生怎么写"，才知道框架帮你做了什么。

## 这一周的最终产出

**第 14 节课的个人主页。**

它要满足：

- 能打开，控制台没有报错；
- 内容是真的（不是课件的套话）；
- 手机模拟下不横向溢出；
- 只用键盘能操作；
- 至少有一个你自己想出来的功能。

**做完把它记进根目录 `CONTEXT.md` 的"我的作品"。** 三个月后面试时，这份清单就是你的答案。
