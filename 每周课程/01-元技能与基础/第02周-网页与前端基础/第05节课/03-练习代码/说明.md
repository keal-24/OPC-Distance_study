# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这两个文件：

```text
calc.html   计算器页面
calc.js     你自己写的 JS
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么这节课必须自己敲

- `==` 和 `===` 的差别，只有自己跑过 `0 == ""` 是 `true` 才会记住；
- `Number("")` 是 0 不是 NaN，这个坑必须亲手撞一次；
- `return` 后面换行会失效，这个坑极其隐蔽，自己试过才不会犯。

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成 `calc.html` 或 `calc.js`；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. `Ctrl + S` 保存，浏览器按 `F5` 刷新，按 `F12` 看控制台。
