# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这个文件：

```text
index.html
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么不让复制

- 复制粘贴学不会：手会了脑子没会；
- 敲的过程会遇到漏闭合标签、中文引号、缩进错乱，这些问题正是你要练的；
- HTML 出错不会报错，只有亲手敲过才知道错在哪里。

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成 `index.html`；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. 自己敲代码，`Ctrl + S` 保存；
7. 双击 `index.html` 用浏览器打开，按 `F5` 刷新看效果。

## 提醒

先确认 Windows 已打开"文件扩展名"显示，否则你新建的 `index.html` 实际会叫 `index.html.txt`，双击打开只会看到一堆代码。
