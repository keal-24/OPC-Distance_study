# 第 0 步：网页到底是什么（5 分钟）

## 0.1 先破除一个误解

很多人以为“做网页”是一件很神秘的事。

**其实网页就是一个文本文件。**

打开任何一个网站，它最终送到你电脑上的东西，就是一个（或几个）文本文件。浏览器读了这个文本文件，把它“画”成你看到的画面。

## 0.2 三个东西的关系

```text
HTML：决定"有什么内容"（标题、段落、图片、按钮）
CSS ：决定"长什么样"（颜色、大小、位置）
JavaScript：决定"能做什么"（点击、计算、变化）
```

**用一个房子打比方：**

| 技术 | 房子里的对应 |
|---|---|
| HTML | 墙、门、窗、房间（结构） |
| CSS | 刷什么漆、地板什么颜色、灯装在哪（外观） |
| JavaScript | 电灯开关、水龙头、门锁（功能） |

**今天只做 HTML。** 因为先要有墙，才谈得上刷漆。

## 0.3 网页文件的三个特点

```text
① 后缀名是 .html
② 用浏览器打开就能看
③ 用记事本就能改
```

**第三条很重要：** 你不需要装什么专业软件就能做网页。记事本 + 浏览器就够了。

## 0.4 今天的交付物

| 文件 | 位置 | 内容 |
|---|---|---|
| `TASK.md` | `01-任务` | 你正在读的这份 |
| `NOTES.md` | `02-笔记` | 你的学习记录 |
| `index.html` | `03-练习代码` | 你自己写的第一个网页 |

# 第 2 步：先认识 HTML 长什么样（15 分钟）

## 2.1 一个最小的网页

**新建文件 `index.html`：**

1. 在 `03-练习代码` 文件夹空白处右键 → 新建 → 文本文档。
2. 文件名改成 `index.html`。
3. 弹出“是否更改文件扩展名”，点“是”。
4. 用 Visual Studio Code 打开。

**现在自己敲下面这段（不要复制）：**

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>你好，这是我写的网页</h1>
  <p>这是第一段文字。</p>
</body>
</html>
```

## 2.2 逐行拆开看

### 第 1 行：`<!DOCTYPE html>`

**这是什么：** 告诉浏览器“这是一个 HTML 文件，按最新标准解析”。

**为什么必须有：**
没有它，浏览器可能会用很老的兼容模式，导致某些样式不生效。

**`DOCTYPE` 读作：** “文档类型”（document type）。

### 第 2 行：`<html lang="zh-CN">`

**这是什么：** 整个网页的最外层容器。

**`lang="zh-CN"` 是什么意思：**

- `lang` = language（语言）；
- `zh` = 中文（Chinese）；
- `CN` = 中国。

**为什么写它：**
浏览器和搜索引擎读到这个，会知道“这是中文网页”。影响两件事：

1. 浏览器可能提示“是否翻译”；
2. 屏幕阅读器（给视障用户用的）会选中文语音。

### 第 3—6 行：`<head>` 里面

```html
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
</head>
```

**`<head>` 是什么：** “给浏览器看的说明”，**不会显示在页面上**。

**`<meta charset="UTF-8">` 是什么：**

- `charset` = 字符集；
- `UTF-8` = 一种编码方式，能正确显示中文。

**这一行如果不写会怎样：**
中文会变成乱码，显示成 `ä½ å¥½` 这样的东西。

**`<title>` 是什么：** 浏览器标签页上显示的标题。

**验证一下：** 这个网页做完后，看浏览器标签页，应该显示“我的第一个网页”。

### 第 7—10 行：`<body>` 里面

```html
<body>
  <h1>你好，这是我写的网页</h1>
  <p>这是第一段文字。</p>
</body>
```

**`<body>` 是什么：** 页面上真正能看见的所有内容。

**`<h1>` 是什么：** 一级标题（heading 1）。字最大。

**`<p>` 是什么：** 段落（paragraph）。

### 最后的 `</html>`

**所有标签都要闭合。** 开了 `<html>`，最后要关 `</html>`。

## 2.3 标签的三种写法

这是 HTML 最基础也最容易搞错的规则。

### 写法一：成对出现

```html
<h1>内容</h1>
<p>内容</p>
<div>内容</div>
```

**规则：** 有开始标签 `<h1>`，就必须有结束标签 `</h1>`（多一个斜杠）。

### 写法二：自闭合

```html
<br>
<img src="a.png" alt="图片">
<meta charset="UTF-8">
```

**规则：** 这类标签没有“内容”，所以不需要结束标签。

**容易搞错的地方：** 有人写成 `<br></br>`，虽然浏览器大多能容忍，但不符合规范。

### 写法三：带属性

```html
<html lang="zh-CN">
<meta charset="UTF-8">
<a href="https://example.com">链接文字</a>
```

**规则：** 属性写在开始标签里，格式是 `名字="值"`。

**注意：** 属性值必须用引号包起来（单引号双引号都行，但全项目要统一）。

## 2.4 马上自测

不看上面，回答：

1. `<head>` 里的东西会不会显示在页面上？
2. 不写 `<meta charset="UTF-8">` 会出现什么问题？
3. `<h1>` 和 `<p>` 有什么区别？
4. 哪个标签不需要结束标签？

# 第 3 步：在浏览器里打开它（10 分钟）

## 3.1 打开方式

**操作（最简单的方式）：**

1. 在文件夹里找到 `index.html`。
2. 双击它。

**会发生什么：** 默认浏览器打开，显示你的网页。

**操作（指定用某个浏览器）：**

1. 右键点 `index.html`。
2. 选“打开方式”。
3. 选 Chrome 或 Edge。

## 3.2 屏幕上应该看到什么

```text
你好，这是我写的网页
```

（大字号，加粗）

```text
这是第一段文字。
```

（正常字号）

**标签页标题应该是：** 我的第一个网页

## 3.3 如果看到的是代码，不是网页

**这说明：** 文件被存成了 `.txt`。

**检查方法：**

1. 回到文件夹；
2. 看文件名是 `index.html` 还是 `index.html.txt`；
3. 如果是后者，右键 → 重命名 → 改成 `index.html` → 提示点“是”。

## 3.4 如果中文全是乱码

**这说明：** 缺了 `<meta charset="UTF-8">`，或者文件保存的编码不是 UTF-8。

**两步修复：**

**第一步：确认那行代码在不在**

```html
<meta charset="UTF-8">
```

**第二步：确认文件保存编码**

1. 在 Visual Studio Code 里看右下角，会显示 `UTF-8` 或 `GBK` 之类的字样；
2. 如果显示的不是 `UTF-8`，点它；
3. 选“通过编码保存”；
4. 选 `UTF-8`；
5. 保存。

## 3.5 改完怎么看效果

**操作：**

1. 在 Visual Studio Code 里改代码；
2. `Ctrl + S` 保存；
3. **回到浏览器，按 `F5` 或 `Ctrl + R` 刷新。**

**关键：浏览器不会自动看到你的修改。** 必须刷新。

**这就是为什么很多人说“我改了怎么没变”——他们忘了刷新。**

## 3.6 一定要养成的一个习惯

```text
改代码 → Ctrl + S 保存 → 切到浏览器 → F5 刷新 → 看效果
```

**这四个动作要连成一套。**

**如果发现“改了没变”，按顺序检查：**

1. 文件保存了吗？（标题栏有没有小圆点）
2. 浏览器刷新了吗？
3. 打开的是不是同一个文件？（地址栏路径看一眼）

# 第 4 步：加上更多内容（15 分钟）

## 4.1 现在扩展你的页面

**目标：** 做一个简单的自我介绍页。

**在 `<body>` 里加上下面内容。** 注意：**要加在 `<body>` 和 `</body>` 之间**，不要加到 `</html>` 后面。

```html
<body>
  <h1>你好，我是（你的名字）</h1>
  <p>我正在学习用 AI 做开发，这是第 8 节课的练习。</p>

  <h2>我会的三件事</h2>
  <ul>
    <li>用 WorkBuddy 整理需求</li>
    <li>用命令行运行 JavaScript</li>
    <li>用 Git 存档代码</li>
  </ul>

  <h2>我想学的</h2>
  <ol>
    <li>做一个能用的网站</li>
    <li>接第一个项目</li>
  </ol>

  <hr>

  <p>下面是一个链接：</p>
  <a href="https://www.example.com">点我去一个示例网站</a>

  <br>

  <p>下面是一张图片：</p>
  <img src="https://www.example.com/pic.png" alt="示例图片">
</body>
```

**注意：上面的 `<a>` 和 `<img>` 里的地址是假的，打开会失败。** 这是故意的，让你看到“地址写错会怎样”。

## 4.2 新出现的六个标签

### `<h2>`：二级标题

```html
<h2>我会的三件事</h2>
```

比 `<h1>` 小一号。**一个页面通常只有一个 `<h1>`，可以有多个 `<h2>`。**

**为什么只能有一个 `<h1>`：**
因为它相当于页面的“大标题”。多个 `<h1>` 会让搜索引擎和屏幕阅读器搞不清这页讲什么。

### `<ul>` 和 `<li>`：无序列表

```html
<ul>
  <li>第一项</li>
  <li>第二项</li>
</ul>
```

- `ul` = unordered list（无序列表），显示成圆点；
- `li` = list item（列表项）。

### `<ol>` 和 `<li>`：有序列表

```html
<ol>
  <li>第一步</li>
  <li>第二步</li>
</ol>
```

- `ol` = ordered list（有序列表），显示成 1. 2. 3.

### `<hr>`：分隔线

```html
<hr>
```

一条横线。**它是自闭合标签，不需要 `</hr>`。**

### `<a>`：链接

```html
<a href="https://www.example.com">点我去一个示例网站</a>
```

- `a` = anchor（锚点、链接）；
- `href` = hypertext reference（超链接地址）。

**`href` 里的地址必须写完整**，包括 `https://`。

### `<img>`：图片

```html
<img src="https://www.example.com/pic.png" alt="示例图片">
```

- `src` = source（来源，图片地址）；
- `alt` = alternative text（替代文字）。

**`alt` 为什么必须写：**

1. 图片加载失败时，会显示这段文字；
2. 视障用户用屏幕阅读器时，会读这段文字；
3. 搜索引擎靠它理解图片内容。

**`<img>` 是自闭合标签，不需要 `</img>`。**

## 4.3 敲完刷新

**按 `F5` 刷新浏览器。**

**你应该看到：**

- 大标题
- 一段话
- 两个小标题
- 一个圆点列表（3 项）
- 一个数字列表（2 项）
- 一条横线
- 一个链接
- 一张加载失败的图片（显示 alt 文字）

**图片加载失败是对的**，因为地址是假的。**这正好让你看到 `alt` 的作用。**

## 4.4 一个必须自己试的实验

**操作：**

1. 删掉 `</ul>` 这一行。
2. 保存，刷新。

**你会看到：** 后面的内容可能全都被当成列表项了，或者排版乱掉。

**为什么：**
因为浏览器要看到 `</ul>` 才知道“列表结束了”。没有它，它会一直以为还在列表里。

**这个实验说明：** **闭合标签不是形式要求，是结构要求。** 漏一个，整块结构就错。

**记得改回来。**

# 第 5 步：学会看 HTML 的结构（10 分钟）

## 5.1 为什么要“看结构”

因为你以后会改别人的 HTML。**看不出结构，就不知道该改哪里。**

## 5.2 用缩进表达结构

**对比这两段，内容完全一样：**

**没缩进：**

```html
<body>
<h1>标题</h1>
<div>
<p>一段话</p>
<ul>
<li>项目</li>
</ul>
</div>
</body>
```

**有缩进：**

```html
<body>
  <h1>标题</h1>
  <div>
    <p>一段话</p>
    <ul>
      <li>项目</li>
    </ul>
  </div>
</body>
```

**为什么后者更好：**
一眼能看出 `<p>` 和 `<ul>` 都在 `<div>` 里面。

**缩进规则（本课程统一）：**

```text
每往里面一层，加两个空格。
不用 Tab（不同编辑器宽度不一样）。
```

## 5.3 用 Visual Studio Code 自动整理

**操作：**

1. 在 Visual Studio Code 里打开 `index.html`；
2. 按 `Shift + Alt + F`（Windows）。

**会发生什么：** 代码自动按层级缩进。

**如果没反应：**
可能没装格式化插件。右键文件 → “格式化文档”，或安装 “Prettier” 插件。

## 5.4 `<div>` 是什么

**上面例子里出现了 `<div>`，前面没讲过。**

```html
<div>
  <p>一段话</p>
</div>
```

- `div` = division（区块、分区）；
- 它本身**没有任何视觉效果**，只是用来“把一些东西装在一起”。

**为什么需要它：**
因为后面要用 CSS 给它上色、定位。**没有容器，就没法给一组东西统一样式。**

**比喻：** `<div>` 像一个透明盒子。你看不见盒子，但可以把东西装进去，然后给盒子贴标签。

## 5.5 试着读一段别人的 HTML

**下面这段你没见过。用 3 分钟读懂它，然后回答后面的问题。**

```html
<div class="card">
  <h2>商品名称</h2>
  <p class="price">¥99.00</p>
  <ul>
    <li>包邮</li>
    <li>7 天无理由退货</li>
  </ul>
</div>
```

**问题：**

1. 这个卡片里有几个元素？
2. 哪些是标题？
3. `class="card"` 是干什么用的？
4. 这个卡片显示出来大概长什么样？

**答案：**

1. 一个 `<h2>`、一个 `<p>`、一个 `<ul>`（里面两项），共三个直接子元素；
2. 一个 `<h2>`；
3. `class` 是“类名”，给 CSS 用来选中这个元素。**它本身不影响显示**，只是贴个标签；
4. 一个标题、一个价格、一个两项的列表，从上到下排列。

**`class` 这个词第一次出现，记住它：**
它是 HTML 里最重要的属性之一。**后面 CSS 全靠它来选元素。** 今天先知道有这么个东西，第 10 节课会正式讲。

# 第 6 步：故意制造三个错误（10 分钟）

**这一步很重要。** 网页的错误特点是：**它不报错，只是显示不对。** 所以你必须认识“显示不对”长什么样。

## 错误 1：漏掉闭合标签

**操作：**

1. 找到 `<h1>你好，我是（你的名字）</h1>`；
2. 删掉 `</h1>`；
3. 保存，刷新。

**你会看到：** 后面的内容可能全变成大标题样式。

**原因：** 浏览器以为标题还没结束。

**记住：** HTML 的错误不会弹窗提示你，它只是默默显示错。

## 错误 2：中文引号

**操作：**

1. 找到 `<a href="https://www.example.com">`；
2. 把英文双引号 `"` 改成中文引号 `"` `"`；
3. 保存，刷新。

**你会看到：** 链接可能点不动，或者地址变成一长串奇怪的东西。

**原因：** 中文引号不是代码符号，浏览器不认识。

**这个坑特别隐蔽，因为中文引号看起来几乎一样。**

**怎么防止：**

- 写代码时确保输入法是英文状态；
- 如果是从微信、网页复制的，检查引号是不是弯的。

## 错误 3：`<img>` 写成成对标签

**操作：**

1. 找到 `<img src="..." alt="示例图片">`；
2. 改成 `<img src="..." alt="示例图片"></img>`；
3. 保存，刷新。

**你会看到什么：** 可能没变化（浏览器容忍了）。

**那为什么还要说这个：**
因为它虽然“能跑”，但不符合规范。而且有些标签写错真的会出问题（比如 `<br></br>` 在某些情况下会产生两个换行）。

**规范建议：** 自闭合标签就写单个，不要加 `</...>`。

## 三个错误总结

```text
漏闭合标签 → 结构错乱，后面的内容被吞进前一个标签
中文标点   → 属性失效、地址错误
自闭合写错 → 一般能跑，但不符合规范
```

**这三种错误有一个共同点：都不会报错。** 所以你必须靠“看效果”来判断。

# 第 7 步：把页面做得像样一点（10 分钟）

## 7.1 现在的问题

页面能显示，但很难看：字挤在一起，没有边距，全是黑字白底。

**这是因为还没写 CSS。** 但今天不写 CSS（下节课讲），先用三个最简单的办法让它好一点。

## 7.2 办法一：加 `<br>` 换行

**在段落里需要换行的地方加 `<br>`：**

```html
<p>
  第一行<br>
  第二行<br>
  第三行
</p>
```

**注意：** 在 HTML 里直接按回车换行是**没用的**，浏览器会把所有空白合并成一个空格。**必须用 `<br>` 才能真的换行。**

**这个坑每个新手都会踩。**

## 7.3 办法二：`<strong>` 和 `<em>`

```html
<p>这是<strong>很重要</strong>的内容。</p>
<p>这是<em>需要强调</em>的内容。</p>
```

- `<strong>`：重要，显示为**粗体**；
- `<em>`：强调，显示为*斜体*。

**为什么不用 `<b>` 和 `<i>`：**
`<b>` 和 `<i>` 只是“看起来粗/斜”，`<strong>` 和 `<em>` 是“语义上重要/强调”。屏幕阅读器会用不同语气读，搜索引擎也会区别对待。

## 7.4 办法三：`<!-- 注释 -->`

```html
<!-- 这是注释，浏览器不会显示它 -->
<h1>标题</h1>
```

**注释的用处：**

- 给自己留提示：“这块是联系方式，以后要改”；
- 临时屏蔽一段代码（不删掉，先注释掉）。

**快捷键（Visual Studio Code）：** 选中几行，按 `Ctrl + /`。

# 附：常见问题速查

| 情况 | 原因 | 怎么做 |
|---|---|---|
| 双击打开看到一堆代码 | 存成了 `.txt` | 打开扩展名显示，重命名成 `.html` |
| 中文全是乱码 | 缺 charset 或编码不是 UTF-8 | 加 `<meta charset="UTF-8">`，另存为 UTF-8 |
| 改了代码页面没变 | 没保存或没刷新 | `Ctrl + S` 后按 `F5` |
| 标签页标题是文件名 | 没写 `<title>` | 在 `<head>` 里加 `<title>` |
| 按了回车但没换行 | HTML 合并空白 | 用 `<br>` |
| 后面内容变成大标题 | 漏了 `</h1>` | 检查闭合标签 |
| 链接点不动 | 引号是中文的 | 改成英文 `"` |
| 图片显示不出来 | 地址错或图片不存在 | 正常的，本次练习用的是假地址 |
| `alt` 文字显示出来了 | 图片加载失败 | 这是 `alt` 的正确行为 |
| 页面全挤在左边 | 还没写 CSS | 正常，下节课讲 |
| Visual Studio Code 缩进乱了 | 没格式化 | `Shift + Alt + F` |
| 显示两个换行 | 用了 `<br></br>` | 改成单个 `<br>` |
| 中文引号看起来和英文一样 | 字体原因 | 放大看，弯的是中文 |
