# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这些文件：

```text
event.html      四种事件的练习页
event.js        事件代码
todo.html       待办清单
todo.js         待办逻辑
calc-live.html  上节课计算器的实时版
calc-live.js    实时版逻辑
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么这节课必须自己敲

- `addEventListener("click", update())` 加括号的坑，只有自己踩过才知道为什么会"加载时就执行一次"；
- 忘了 `preventDefault` 的现象是"闪一下就没"，不看自己敲的根本发现不了；
- 事件冒泡要自己点一次、看控制台输出两次，才会真的相信。

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成课件里要求的名字；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. `Ctrl + S` 保存，浏览器按 `F5`，`F12` 看控制台。
