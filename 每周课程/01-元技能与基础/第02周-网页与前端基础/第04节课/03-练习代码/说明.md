# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己新建这两个文件：

```text
form.html   注册表单
style.css   表单样式
```

课件里的代码只作对照，不要整段复制粘贴。

## 为什么这节课必须自己敲

- `label` 的 `for` 和 `id`，差一个字符就不生效，必须自己撞过；
- `radio` 的 `name` 要相同，只有自己试过"两个都能选中"才会记住；
- 按钮漏 `type` 会导致页面刷新，这个坑必须亲手踩一次。

## 怎么新建文件

1. 在这个文件夹的空白处点鼠标右键；
2. 选"新建"→"文本文档"；
3. 文件名改成 `form.html` 或 `style.css`；
4. 如果弹出"是否更改文件扩展名"，点"是"；
5. 右键这个文件 →"打开方式"→ 选 Visual Studio Code；
6. `Ctrl + S` 保存，浏览器按 `F5` 刷新。
