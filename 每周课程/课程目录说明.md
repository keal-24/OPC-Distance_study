# 每周课程目录说明

每周课程按学习阶段分组，每一周再按主题分组，每一节课内部继续分类。

## 课程层级

```text
每周课程/
└── 01-元技能与基础/
    └── 第01周-AI工具/
        └── 第01节课/
```

## 每节课的固定结构

```text
第01节课/
├── 01-任务/
│   ├── TASK.md          本节课要做什么，第一步先读这里
│   └── 说明.md           这个分类放什么
├── 02-笔记/
│   ├── NOTES.md         本节课学到了什么、卡在哪里、如何解决
│   └── 说明.md
└── 03-练习代码/
    ├── try.js           本节课的代码、网页、接口、测试文件
    └── 说明.md
```

## 以后每节课怎么用

1. 打开 `01-任务/`，先读 `TASK.md`。
2. 代码只放 `03-练习代码/`。
3. 学习过程中遇到的问题和解决办法写到 `02-笔记/NOTES.md`。
4. 示例资料和提交记录，如果需要，分别放在 `02-笔记/` 里记录。
5. 提交整个学习仓库，不需要为每节课单独创建 Git 仓库。

## 文件放哪里，一眼判断

| 你手里的东西 | 放在哪个文件夹 |
|---|---|
| 今天的任务说明 | `01-任务/` |
| 自己写的代码 | `03-练习代码/` |
| 网页文件 | `03-练习代码/` |
| 测试文件 | `03-练习代码/` |
| 学习笔记 | `02-笔记/` |
| 示例数据、参考资料、提交截图和检查记录 | `02-笔记/` |

以后每节课只保留三个分类：任务、笔记、练习代码。
