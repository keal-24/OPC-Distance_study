# 每周课程目录说明

每周课程按学习阶段分组，每一周再按主题分组，每一节课内部继续分类。

## 课程层级

```text
每周课程/
└── 01-元技能与基础/
    └── 第01周-AI工具/
        └── 第01节课/
```

## 每节课的固定结构

```text
第01节课/
├── 01-任务/
│   ├── TASK.md          本节课的课件，第一步先读这里
│   └── 说明.md           这个分类放什么
├── 02-笔记/
│   ├── NOTES.md         你要填的学习记录
│   └── 说明.md
└── 03-练习代码/
    ├── 说明.md           这个文件夹故意留空
    └── （你的代码，自己新建）
```

## 三条硬规则

### 一、`03-练习代码` 故意留空

**这个文件夹里不放任何现成代码，只有一份 `说明.md`。**

课程里出现的代码全部是**对照用的标准答案**，学员要自己新建文件、自己敲。

原因：

- 复制粘贴只会手会，脑子没会；
- 敲的过程会遇到拼错、漏括号、缩进不对，这些正是要练的；
- 亲手敲错过、报错过，才知道报错长什么样。

### 二、`02-笔记/NOTES.md` 是填的，不是读的

每一行都要有字。真没有内容就写"暂时没有"，不要留空。

### 三、`01-任务/TASK.md` 是学员课件

包含：概念解释、逐步操作、屏幕预期、错误处理、练习、验收。

**不放**：教师口播稿、录课说明、教案式的备课内容。

---

## 以后每节课怎么用

1. 打开 `01-任务/`，先读 `TASK.md`。
2. 在 `03-练习代码/` 里自己新建文件，按课件一步步敲。
3. 学到的内容和卡点写到 `02-笔记/NOTES.md`。
4. 每节课结束提交一次整个学习仓库。

## 文件放哪里，一眼判断

| 你手里的东西 | 放在哪个文件夹 |
|---|---|
| 今天的课件 | `01-任务/` |
| 自己写的代码 | `03-练习代码/` |
| 网页文件 | `03-练习代码/` |
| 测试文件 | `03-练习代码/` |
| 学习笔记 | `02-笔记/` |
| 报错截图、检查记录 | `02-笔记/` |

以后每节课只保留三个分类：任务、笔记、练习代码。
