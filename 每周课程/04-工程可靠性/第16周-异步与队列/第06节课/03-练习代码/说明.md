## 今天要同时开三个终端

```text
终端 A：node api.js          端口 3002
终端 B：node worker-v2.js    干活
终端 C：浏览器 http://localhost:3002
```

**少一个都跑不起来。** 这不是麻烦，这是"关注点分离"的代价：
API 挂了 worker 还在跑，worker 挂了 API 还能收任务。

## 必须自己观察的五件事

**① 1.5 秒一跳的进度**

F12 → Network → 找 `/api/jobs/xxx`，看两次请求的间隔。

**② 刷新页面后的第一个请求**

按 F5，Network 里会立刻出现一个查询 —— **因为 `localStorage` 里存着 jobId。**

**③ 完成后的请求停止**

任务 `done` 之后，Network 里不该再出现新请求。**没停就是 bug。**

**④ 切后台时的请求暂停**

切到别的标签页 10 秒，回来数一下 Network 里的请求数。

**⑤ `SELECT *` 和精简字段的差别**

改一次 `SELECT`，对比 Response Size。
