# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己建：

```text
03-练习代码/
└── job-queue/
    ├── package.json
    ├── jobs.db           （运行后自动生成，别提交进 Git）
    ├── db.js             建表、开 WAL、导出 db
    ├── add-job.js        投递一个任务
    ├── worker.js         独立进程，死循环取任务
    └── show.js           练习一：查一个任务
```

**`jobs.db`、`jobs.db-wal`、`jobs.db-shm` 三个文件不要提交。**

在 `job-queue/` 里建一个 `.gitignore`：

```text
node_modules/
*.db
*.db-wal
*.db-shm
```

## 必须自己观察的五件事

**① 状态的变化**

```text
pending → running → done
```

用 `console.table` 在两分钟内多查几次，**你要亲眼看到它跳。**

**② `attempts` 什么时候变**

不是投递时变，是**认领时**变。想想为什么。

**③ 两个 worker 的日志**

同一个任务 id **绝不能**出现在两个终端里。

**④ "先查再改"的后果**

改错一次，看到重复领取，你就一辈子不会写错了。

**⑤ 杀掉 worker 之后表里留下的东西**

`status = running`、`worker_id = 死掉的那个`。**这是排查线上问题的第一现场。**
