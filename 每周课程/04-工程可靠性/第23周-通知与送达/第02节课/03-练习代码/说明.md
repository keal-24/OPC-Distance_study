## 短信的三段式

```text
【签名】固定文字 {变量} 固定文字
  ↑        ↑        ↑       ↑
报备    不能改   只能填值  不能改
```

## 必须自己观察的七件事

**① 短信不是"内容"，是"签名 + 模板 ID + 变量"**

```javascript
// ❌ 直接传 content（会被拒，或者走高价通道）
{ phone, content: "【某某】您的验证码是 123456" }

// ✅ 传模板 ID + 变量
{ phone, templateId: "SMS_100001", params: { code: "123456", ttl: "5" } }
```

**② `ttl` 必须是 enum，不能是数字**

```text
你报备"5 分钟"
实际发"7 分钟"
→ 内容与报备不符 → 被拦
```

**③ 变量类型检查是防止"发出半成品"的最后一道**

```text
code: { type: "digits", len: 6 }
→ 传 "abcdef" 直接抛错，不会发出"您的验证码是 abcdef"
```

**④ 超长只警告，不抛错**

```text
超长不是错误，是多花钱（按 2 条计费）
抛错会让业务停摆
```

**判断标准：这个不合规会导致"发不出去"吗？**

**⑤ 报备 1–3 工作日，不能加急**

```text
新功能上线前 1 周就要提交模板
不要"今天写完代码，明天想上线"
```

**⑥ 营销短信必须有"回 T 退订"，且只能在 9–20 点发**

**两条都是运营商硬性要求，不满足直接拒。**

**⑦ `Math.random()` 不能生成验证码**

```javascript
Math.random().toString().slice(2, 8)   // ❌ 可预测（xorshift 算法）
crypto.randomInt(100000, 1000000)      // ✅ 密码学安全
```
