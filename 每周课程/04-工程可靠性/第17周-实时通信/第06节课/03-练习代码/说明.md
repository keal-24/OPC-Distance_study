## 必须自己观察的五件事

**① F12 里的 WS 标签**

```
Network → WS → 点开连接 → Messages
绿色 = 你发的，红色 = 服务器发的
```

**不在 `Response` 里。** 第一次找不到是正常的。

**② 两个窗口的"加入了/离开了"**

关掉一个，另一个必须收到系统消息。**收不到就是 `close` 里的广播没写。**

**③ `/api/rooms` 的人数**

```bash
curl http://localhost:3000/api/rooms
```

**断网之后这个数字会不会变？不变就是没做心跳。**

**④ 断网 60 秒后的"踢掉僵尸连接"**

**这是今天唯一必须动手拔网线才能验证的事。**

**⑤ 断线期间发的消息**

断开 → 打字 → 发送 → 重连后消息补发出去。**没队列就会丢。**
