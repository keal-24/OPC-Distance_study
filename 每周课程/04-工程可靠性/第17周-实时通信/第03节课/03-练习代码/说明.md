## 必须自己观察的五件事

**① 杀掉服务后 Network 里的重连**

每隔约 3 秒一个失败的 `/stream` 请求。**这是浏览器自己在干，不是你写的。**

**② 重连请求里的 `Last-Event-ID` 头**

F12 → Network → 点开重连后的 `/stream` → Headers → Request Headers。

**你会看到 `Last-Event-ID: 12` 这类值。**

**③ 服务端日志里的"续传补发"**

```text
续传：从 #12 补发了 5 条
```

**没有这一行，`id:` 和 `replay` 至少有一个没接上。**

**④ 重启服务后补不出来**

内存里的 `history` 清空了。**这就是为什么真值要放数据库。**

**⑤ 断开时的页面状态**

必须显示"正在重连（第 N 次）"，**不是一片安静。**
