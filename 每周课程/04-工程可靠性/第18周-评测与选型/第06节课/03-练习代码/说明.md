## 必须自己观察的七件事

**① `typical` 层三个模型差不多**

```text
83% / 92% / 92%
```

**典型题不区分模型。** 所以如果你只测典型题，会误以为"便宜模型够用"。**这是本课最重要的一条实测。**

**② `boundary` 层差距最大**

```text
38% / 75% / 75%
```

**37 个点。** 这才是分水岭。而 `boundary` 在真实流量里占 20–30%。

**③ 有些层所有模型都 < 30%**

`reject` 和 `inject` 大概率全军覆没。**这不是模型问题，是提示词没教它"该拒答"。**

**识别规则：某层所有模型都失败 → 改提示词，别换模型。** 这类层不参与选型决策。

**④ token 便宜 18 倍，总成本可能反而更贵**

因为人工是大头。

```text
cheap：token ¥156/月 + 人工 ¥22500/月
big：  token ¥2906/月 + 人工 ¥10500/月
```

**这个反转如果不算，你永远看不出"便宜模型很贵"。**

**⑤ 1 条致命错误的差异在噪声范围内**

第 122 节测出的差异率大概率 20%。1 条 = 3.3 点 < 20%。**所以 mid 和 big 的致命错误差异统计上不成立。**

**必须诚实写进报告。** 不写，你的结论就是建立在噪声上的。

**⑥ 致命错误要人工复核**

判分器会误判。**7 条里可能有 2 条是误判。** 复核后通过率会变，结论可能变。

**⑦ 结论必须有"什么情况下换回来"**

**这一栏是给三个月后的自己留的护栏。** 不写，你会在看到账单时冲动换模型，然后线上炸。
