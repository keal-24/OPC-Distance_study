# 第 0 步：三件事决定你能不能收这笔钱（10 分钟）

## 0.1 客户的三句话，决定你的收入上限

| 客户说 | 你没有主体会怎样 |
|---|---|
| "能开票吗？" | 开不出，这单黄 |
| "要专票，能抵扣" | 个体户小规模可以代开，但流程要走 |
| "打款要打到对公账户" | 你只有个人卡，财务不批 |

**没有经营主体 = 只能接"老板私人转账"的单 = 单价上不去、也做不大。**

## 0.2 顺序搞错的代价

```text
❌ 先接单 → 客户要票 → 临时去注册 → 来不及 → 单丢了
✅ 先注册 → 有主体 → 接单就能开票 → 单能接住
```

**注册个体户：线上办，几百元，几天到两周。这笔钱不能省。**

## 0.3 一分钟结论

| 阶段 | 建议主体 | 理由 |
|---|---|---|
| 年收入 < 50 万，客户多为中小企业 | **个体户** | 注册简单、成本低、能开票 |
| 年收入 50-100 万，或客户要求"必须是公司" | 个体户 → 考虑有限公司 | 看客户要求 |
| 年收入 > 100 万，或要承担较大责任 | **有限公司** | 有限责任 |

> **不要一上来就注册公司。** 公司的代账费、年报、社保、银行户，一年多几千到上万，第一年很容易白交。

# 第 1 步：个体户还是公司（25 分钟）

## 1.1 五维对比

| 维度 | 个体户 | 有限公司 |
|---|---|---|
| **注册** | 线上，材料少，几天到两周 | 要章程、地址、监事，慢一些 |
| **成本** | 几百元 + 代账约 2000-3000/年 | 几千元 + 代账约 3000-6000/年 |
| **税** | 增值税 + 经营所得个税 | 增值税 + 企业所得税 + 分红个税 |
| **责任** | **无限责任**（生意债要用个人财产还） | **有限责任**（以出资为限） |
| **能开专票** | 小规模可申请代开 | 可以自开 |
| **形象** | 一般 | 客户/招投标更认 |

## 1.2 "无限责任"到底意味着什么

**说人话：**

```text
你给客户做的系统出了事故，法院判赔 50 万。
个体户：你要用房子、存款、车去还。
有限公司：公司账上没钱就到此为止（除非你有过错）。
```

**什么样的项目会有这种风险：**

| 项目类型 | 风险 |
|---|---|
| 涉及钱（支付、结算、对账） | 算错钱要赔 |
| 涉及人身安全（医疗、设备控制） | 高 |
| 涉及大量个人信息 | 泄露要赔 |
| 内部工具、文档问答、展示页 | **低** |

> **做低风险项目（企业内部工具、内容站、问答助手），个体户完全够用。**
>
> **一旦碰钱、碰个人信息、碰设备，认真考虑公司。**

## 1.3 核定征收 vs 查账征收

| | 核定征收 | 查账征收 |
|---|---|---|
| 税怎么算 | 按收入 × 核定率 | 按（收入 - 成本）× 税率 |
| 需要账吗 | 简单 | **要完整账** |
| 适合 | 收入小、成本难核算 | 成本高、利润薄 |
| 现在还能办吗 | **各地收紧，很多地方不给新办** | 主流 |

> **这一条必须问当地税务局。** 同一个政策，不同城市执行差别很大。

## 1.4 一张决策表（照着自己填）

```markdown
| 问题 | 我的答案 |
|---|---|
| 预计第一年收入 | |
| 客户会不会要专票 | |
| 客户会不会要求对公账户 | |
| 项目会不会碰钱/个人信息/设备 | |
| 我能承受的启动成本 | |
| **结论：个体户 / 有限公司** | |
```

# 第 2 步：开票（30 分钟）

## 2.1 2026 年的关键政策（已核对官方口径）

**依据：**《财政部 税务总局关于增值税法施行后增值税优惠政策衔接事项的公告》（2026 年第 10 号）等。

| 事项 | 现行口径 |
|---|---|
| 增值税法施行 | **2026 年 1 月 1 日起施行** |
| 小规模纳税人起征点 | 月销售额 **10 万**（季 **30 万**）以下免征增值税 |
| 征收率 | 3% **减按 1%** 征收（2026.1.1—2027.12.31） |
| 个体户个税 | 年应纳税所得额不超过 **200 万**的部分，**减半**征收 |
| "六税两费" | 小规模纳税人**减半**（2023.1.1—2027.12.31） |

> **上面这几条是写课件时的官方口径，但有效期都是"到某年某月"。**
>
> **每次签合同前，花 10 分钟搜一次"小规模纳税人 征收率 最新"，或者直接打 12366。**
>
> **税率变了，你的报价就要跟着变；用旧税率报价，亏的是你。**

## 2.2 开票的三种情形

| 情形 | 怎么做 |
|---|---|
| 客户要**普票** | 自己开（电子税务局 / 开票软件），最省事 |
| 客户要**专票**，你是小规模 | 可以**自开**或去税局**代开**；税率按 1%（减征期内） |
| 客户是**个人**，不要票 | 也要记账，但不用开票 |

**电子发票现在是主流，开完直接发 PDF/OFD 给客户。**

## 2.3 开票信息一次问全（少跑三趟）

**把这段直接发给客户：**

```text
麻烦提供开票信息，我这边开电子发票：
1. 公司全称
2. 纳税人识别号（统一社会信用代码）
3. 注册地址 + 电话（专票需要）
4. 开户行 + 账号（专票需要）
5. 要普票还是专票
6. 发票内容开什么（技术服务费 / 软件开发费 / 信息技术服务费）
7. 接收邮箱
```

> **第 6 条最容易出问题。** 开成"办公用品"客户财务不认，要重开。
>
> **服务类一般开"信息技术服务*软件开发服务"或"技术服务*技术开发"。不确定就问客户的财务。**

## 2.4 发票和合同金额对不上怎么办

| 情况 | 处理 |
|---|---|
| 客户先付 30%，要全额票 | **不给。** 按实收开票，否则你先垫税 |
| 客户要求拆成多张票 | 可以，但总额必须等于合同额 |
| 客户要求开给第三方 | **拒绝**，票流要和合同流、资金流一致 |
| 合同 1.65 万，客户只付 1.4 万 | 按 1.4 万开，剩下的要么收，要么签补充协议减免 |

> **"三流一致"（合同、发票、资金）是最基本的合规要求。** 不一致，客户财务不敢收，你也麻烦。

# 第 3 步：报税（25 分钟）

## 3.1 你要报哪些税

| 税种 | 频率 | 说明 |
|---|---|---|
| **增值税** | 月报或季报 | 小规模通常按季 |
| **附加税** | 跟着增值税 | 城建、教育附加等 |
| **经营所得个税** | 季度预缴 + 年度汇算 | 个体户 |
| **个人所得税（工资）** | 月报 | 如果你给自己发工资（公司） |
| **企业所得税** | 季报 + 年报 | 有限公司 |
| **印花税** | 按合同 | 技术服务合同通常要贴 |

## 3.2 最要命的一句话：没收入也要报

```text
零申报 ≠ 不用报。
```

| 你以为 | 实际 |
|---|---|
| 这个月没收入，不用管 | **必须做零申报** |
| 晚几天没事 | 逾期有罚款，还影响信用 |
| 反正没收入不会查我 | 系统自动比对，异常会被列名录 |

**不报的后果：**

| 后果 | 说明 |
|---|---|
| 罚款 + 滞纳金 | 按天算 |
| 列入经营异常名录 | 影响贷款、投标、甚至出行 |
| 影响个人征信 | 个体户的经营者和主体是绑定的 |
| 被吊销 | 长期不报 |

## 3.3 报税时间表（贴在墙上）

| 时间 | 事项 |
|---|---|
| 每月/每季 15 日前 | 增值税 + 附加税申报（遇节假日顺延） |
| 每季 15 日前 | 经营所得个税预缴 |
| 次年 3 月 31 日前 | 经营所得汇算清缴 |
| 次年 6 月 30 日前 | 工商年报（**个体户也要报**） |

> **工商年报最容易忘。** 忘了会被列异常，恢复要跑手续。

## 3.4 代账公司：这笔钱别省

| 自己做 | 找代账 |
|---|---|
| 免费 | 2000-4000 元/年 |
| 出错风险高 | 有人兜底 |
| 政策变了你不知道 | 他们会提醒 |
| 每年花 20-50 小时 | 每年花 2 小时 |

**判断标准：**

> **你一小时值 150 元以上，一年花 30 小时做账 = 4500 元。代账 3000 元，还更准。**
>
> **算不过这账的人，才会自己报税。**

**选代账公司的三条：**

| 检查 | 不合格的信号 |
|---|---|
| 有没有代理记账许可证 | 拿不出来 |
| 会不会主动提醒申报期 | 每次都要你催 |
| 能不能解释"为什么这个数" | 只会说"系统算的" |

# 第 4 步：记账（20 分钟）

## 4.1 三本账，一本都不能少

| 账本 | 记什么 | 为什么要 |
|---|---|---|
| **收入账** | 每笔收款：日期、客户、金额、对应合同、开票号 | 报税 + 催款 |
| **支出账** | 每笔花钱：服务器、模型费、软件、交通 | 抵成本 + 算真实利润 |
| **发票账** | 开出的票 + 收到的票 | 对账 + 汇算 |

## 4.2 模板（写进 `记账模板.md`）

```markdown
# 收入账

| 日期 | 客户 | 项目 | 金额 | 对应合同条款 | 发票号 | 到账账户 |
|---|---|---|---|---|---|---|
| 11-16 | XX机械 | 问答助手 | 4,950 | 第四条第1款 定金30% | 24310000000012345678 | 对公 |

# 支出账

| 日期 | 项目 | 金额 | 类别 | 有没有票 | 备注 |
|---|---|---|---|---|---|
| 11-16 | 云服务器 | 99 | 服务器 | 有（电子票） | 客户项目测试用 |

# 发票账

| 开票日期 | 发票号 | 客户 | 金额 | 税率 | 类型（普/专） | 状态 |
|---|---|---|---|---|---|---|
```

**"类别"只有六个：** `服务器 / 模型调用 / 软件订阅 / 差旅 / 办公 / 其他`

## 4.3 凭证要留什么（出事时的证据链）

| 凭证 | 留多久 | 为什么 |
|---|---|---|
| 合同 + 附件 | **5 年以上** | 争议、审计 |
| 发票（开出的和收到的） | 5 年以上 | 税务 |
| 银行流水 / 收款记录 | 5 年以上 | 三流一致 |
| 微信/邮件的关键确认 | 项目结束后 3 年 | 需求变更的证据 |
| 验收单（签字） | 5 年以上 | 尾款的依据 |

> **扫描件存云盘 + 本地各一份。** 手机丢了、电脑坏了，凭证不能丢。

## 4.4 每月 15 分钟的动作

**每月最后一天，做四件事：**

| 动作 | 检查 |
|---|---|
| 把本月收入填进收入账 | 和银行流水对得上吗 |
| 把本月支出填进支出账 | 有没有漏记的小额支出 |
| 核对发票 | 开出的、收到的，张数和金额对不对 |
| 更新收款台账 | 有没有逾期 |

# 第 5 步：算一次"我到底赚了多少"（15 分钟）

**用第 246 节课的成本表 + 今天的税，算一个季度：**

```markdown
## 2026 年 Q4 真实利润

| 项 | 金额 |
|---|---|
| 收入（已开票） | |
| 减：增值税及附加 | |
| 减：服务器/模型/软件 | |
| 减：代账费 | |
| 减：其他 | |
| = 税前利润 | |
| 减：经营所得个税（估算） | |
| **= 到手** | |
| **÷ 我工作的小时数** | **= 真实时薪** |
```

> **这个数字才是你的"工资"。**
>
> **算完如果你发现"还不如去上班"，那不是坏事——你终于知道了真相，而且知道该改哪一项。**
