# 03-练习代码

**最后一课，四份文件。它们是你以后每个项目的"标准交付样板"。**

```text
03-练习代码/
├── 交付清单.md      ← 八件套 + 逐项自检
├── 交接表.md        ← 账号、密码存放、谁续费
├── 脱身预案.md      ← 出事时别人怎么接手
└── 复盘.md          ← 252 天 + 接下来 90 天
```

## 这四份文件的关系

```text
交付清单  → 你交付什么
交接表    → 资产在谁名下
脱身预案  → 你不在时谁接手
复盘      → 你以后靠什么吃饭
```

## 三条硬规矩

| 规矩 | 说明 |
|---|---|
| **账号全部转到客户名下** | 你不替客户保管资产，也不背续费责任 |
| **密码绝不写进表里** | 交接表会被转发、打印、截图 |
| **交付前轮换所有 key** | 交出去的 key 客户能看到用量 |

## 仓库里绝对不要提交

| 不要提交 | 为什么 |
|---|---|
| 真实账号、密码 | 一看就出事 |
| 客户的服务器 IP、域名后台 | 可被攻击 |
| `.env` | `.gitignore` 里必须有它 |
| 验收单上的签章页 | 客户签名是个人信息 |
| 复盘里的真实收入明细 | 不想公开就写比例 |

**模板里的账号一律写 `客户公司账号`、`由客户 IT 保管`。**

## 检验自己有没有真做完

1. 把部署文档给一个没参与过项目的朋友，他能部署起来吗？
2. 交接表上还有哪个账号在你名下？
3. 你今晚失联，明天客户找谁？
4. 一句话说清 252 天学到了什么。

**第一问答不上，说明你还不能被替换。**
