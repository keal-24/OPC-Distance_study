# 03-练习代码

**本节课要新建两份文件：**

```text
03-练习代码/
├── 知识产权备忘.md      ← 默认条款文本 + 依赖协议表 + 字体白名单
└── 软著申请清单.md      ← 五类材料 + 三个坑 + 时间线
```

## 知识产权备忘不是知识，是你每次签合同要复制粘贴的东西

**判断标准：** 打开 `知识产权备忘.md`，能直接抄出三段文字放进合同——著作权条款、独占加价说明、开源组件声明。

抄不出来，说明这文件还是"笔记"，不是"工具"。

## 三条硬规矩

| 规矩 | 说明 |
|---|---|
| **默认写 B（保留通用组件）** | 你三年能不能规模化，取决于这一条 |
| **独占必须加价** | 不加价就是把自己的资产一次性卖掉 |
| **每个项目交付前跑一次 Copyright 扫描** | 五分钟，防一次几万的索赔 |

## 仓库里的注意

`知识产权备忘.md` 里如果列了客户项目，用代号。

**不要提交：** 软著申请里的真实身份信息、营业执照扫描件、商标受理通知书。

## 本文不是法律意见

课件里的协议解释、软著流程、商标费用都是通用口径，**具体条款和费用以官方最新公告为准**。

**单项目金额超过 10 万，或者客户要求独占著作权，花 1000-3000 找律师看一遍合同。** 这笔钱通常一次就赚回来。

## 检验自己有没有真做完

合上文件，回答：

- 客户说"著作权必须归我们"，我加价多少？给他什么折中方案？
- 我项目里有没有 GPL 的包？哪些？
- 我用的字体能不能商用？
- 我下一个项目的软著，什么时间提交？

**四个问题都要能立刻回答。答不上，就是在裸奔。**
