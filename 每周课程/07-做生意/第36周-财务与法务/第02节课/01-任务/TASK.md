# 第 0 步：先看清"涨价"到底涨的是什么（10 分钟）

## 0.1 从成本到报价，中间隔着一道除法

**大多数人算报价：**

```text
成本 15,755 元 → 加 20% → 报 18,900
```

**结果：毛利率 16%，你一年干 6 个这样的项目，挣不到 2 万。**

**正确的算式：**

```text
报价 = 总成本 ÷ (1 - 目标毛利率 - 税率)
```

**为什么是除法不是加法：**

| 算法 | 成本 1 万，目标毛利 40%，税 6% | 实际毛利 |
|---|---|---|
| 加法：1 万 × 1.4 × 1.06 | 14,840 | 32% |
| **除法：1 万 ÷ (1-0.4-0.06)** | **18,519** | **40%** |

> **加法和除法差 3,700 元。这就是"报价永远偏低"的数学原因。**

## 0.2 毛利率不是"赚多少"，是"还剩多少"

```text
毛利率 = (报价 - 总成本) ÷ 报价
```

**报价 2 万，成本 1.2 万：毛利率 40%。**

**这 8,000 里还要出什么：**

| 项 | 说明 |
|---|---|
| 你的生活费 | 这才是你的"工资" |
| 没项目的那些月份 | 一年可能有一半时间空着 |
| 设备折旧、软件订阅 | |
| 学习成本 | 你在学新东西的时候不赚钱 |

> **毛利率 40% 意味着一人公司"勉强活着"，不是"赚翻了"。**
>
> **毛利率 30% 意味着你在给自己发一份低于市场价的工资，还得自负盈亏。**

# 第 1 步：先把公式写成一行（15 分钟）

## 1.1 完整公式

```text
① 总成本 = 时间成本 + 现金成本 + 隐性成本

② 时间成本 = 总工时 × 你的小时单价

③ 报价 = 总成本 ÷ (1 - 目标毛利率 - 税率)

④ 实际小时收入 = (报价 × (1 - 税率) - 总成本) ÷ 总工时

⑤ 保本报价（毛利率 0） = 总成本 ÷ (1 - 税率)
```

**五个式子，缺一个你就算不清。**

## 1.2 用一个真实数字跑一遍

| 输入 | 值 |
|---|---|
| 总工时 | 115 小时 |
| 小时单价 | 182 元 |
| 现金成本 | 780 元 |
| 隐性成本（维护 15 小时折）= 15 × 182 | 2,730 元 |
| 时间成本 = 115 × 182 | 20,930 元 |
| **总成本** | **24,440 元** |
| 目标毛利率 | 40% |
| 税率 | 6% |

```text
报价 = 24,440 ÷ (1 - 0.4 - 0.06) = 24,440 ÷ 0.54 = 45,259 元
```

**你可能第一反应是"太贵了，客户不会买"。**

**看清楚这个数字意味着什么：**

| 项 | 金额 |
|---|---|
| 报价 | 45,259 |
| 税 | 2,716 |
| 成本 | 24,440 |
| **你到手** | **18,103** |
| 除以 115 小时 | **157 元/小时** |

> **157 元/小时，比你"希望"的 182 还低。因为毛利里有一部分要填"没项目的月份"。**
>
> **你觉得 4.5 万贵，是因为你把自己当成了月薪 8000 的打工人，而不是一家公司。**

## 1.3 报不上去怎么办：三个真实选项

| 选项 | 做法 | 代价 |
|---|---|---|
| **涨技能** | 做别人做不了的（私有化、行业深度） | 时间 |
| **缩范围** | 只做 3 条核心需求，工时从 115 降到 60 | 收入总额低，但毛利高 |
| **提效率** | 把通用部分做成模块复用（第 20 节课的工程化） | 前期投入 |
| **换客户** | 去找预算 5 万以上的客户 | 获客成本 |

**唯一不该做的：按 45,259 的活，报 16,500。**

## 2.3 写 JS（这一课的核心）

```javascript
// app.js

// 1. 把所有输入框抓出来
var inputs = {
  hours:  document.getElementById('hours'),
  rate:   document.getElementById('rate'),
  cash:   document.getElementById('cash'),
  hidden: document.getElementById('hidden'),
  margin: document.getElementById('margin'),
  tax:    document.getElementById('tax')
};

var output = document.getElementById('output');

// 2. 读一个数字，读不到就当 0
function num(el) {
  var v = parseFloat(el.value);
  return isNaN(v) ? 0 : v;
}

// 3. 金额格式化：12345 → 12,345
function money(n) {
  return n.toLocaleString('zh-CN', { maximumFractionDigits: 0 });
}

// 4. 核心计算
function calc() {
  var hours  = num(inputs.hours);
  var rate   = num(inputs.rate);
  var cash   = num(inputs.cash);
  var hidden = num(inputs.hidden);
  var margin = num(inputs.margin) / 100;
  var tax    = num(inputs.tax) / 100;

  // --- 校验 ---
  if (hours <= 0) {
    output.innerHTML = '<p class="warn">总工时必须大于 0。</p>';
    return;
  }
  if (margin + tax >= 0.95) {
    output.innerHTML = '<p class="warn">目标毛利率 + 税率不能超过 95%，否则价格会趋近于无穷大。</p>';
    return;
  }

  // --- 计算 ---
  var timeCost  = hours * rate;
  var totalCost = timeCost + cash + hidden;
  var price     = totalCost / (1 - margin - tax);
  var breakEven = totalCost / (1 - tax);
  var afterTax  = price * (1 - tax);
  var profit    = afterTax - totalCost;
  var hourly    = profit / hours;
  var realMargin = price > 0 ? profit / price : 0;

  // --- 输出 ---
  output.innerHTML =
    '<table>' +
      '<tr><th>时间成本</th><td>' + money(timeCost) + ' 元</td></tr>' +
      '<tr><th>总成本</th><td>' + money(totalCost) + ' 元</td></tr>' +
      '<tr><th>保本报价（毛利 0）</th><td>' + money(breakEven) + ' 元</td></tr>' +
      '<tr class="big"><th>建议报价</th><td>' + money(price) + ' 元</td></tr>' +
      '<tr><th>税后收入</th><td>' + money(afterTax) + ' 元</td></tr>' +
      '<tr><th>到手利润</th><td>' + money(profit) + ' 元</td></tr>' +
      '<tr><th>实际毛利率</th><td>' + (realMargin * 100).toFixed(1) + '%</td></tr>' +
      '<tr><th>实际小时收入</th><td>' + money(hourly) + ' 元/小时</td></tr>' +
    '</table>' +
    '<p class="note">建议报价 ≈ 保本价 × ' + (price / breakEven).toFixed(2) + '</p>';
}

// 5. 任何输入变化都重算
Object.keys(inputs).forEach(function (k) {
  inputs[k].addEventListener('input', calc);
});

// 6. 页面打开先算一次
calc();
```

# 第 3 步：加一个"三档"输出（25 分钟）

## 3.1 光有一个价不够，要出三档

**在 `calc()` 后面加一个新函数：**

```javascript
function tiers(basePrice) {
  var basic    = basePrice * 0.55;   // 基础版：只做核心，工时少一半
  var standard = basePrice;          // 标准版：就是算出来的价
  var full     = basePrice * 1.9;    // 完整版：加后台、对接、私有化
  return { basic: basic, standard: standard, full: full };
}
```

**然后在输出里加一段：**

```javascript
var t = tiers(price);
output.innerHTML +=
  '<h2>三档</h2>' +
  '<table>' +
    '<tr><th>基础</th><td>' + money(t.basic) + ' 元</td></tr>' +
    '<tr class="big"><th>标准（推荐）</th><td>' + money(t.standard) + ' 元</td></tr>' +
    '<tr><th>完整</th><td>' + money(t.full) + ' 元</td></tr>' +
  '</table>';
```

## 3.2 为什么基础版系数是 0.55 而不是 0.7

| 系数 | 问题 |
|---|---|
| 0.7 | 差太小，客户直接选基础，你干得一样累 |
| 0.55 | 差得明显，但基础版"能用但明显不方便" |
| 0.4 | 基础版会变成亏本引流，客户选了你就亏 |

**0.55 的经验依据：** 基础版工时通常降到 50-60%，但**沟通和部署成本不会等比下降**（还是要开会、还是要部署），所以价格只能降到 55% 左右。

> **这是三档设计里最容易搞错的数学：工时降一半，价格不能降一半。**

## 3.3 完整版系数为什么是 1.9

| 完整版多出来的 | 工时占比 |
|---|---|
| 后台管理（用户/权限/日志） | +30% |
| 对接现有系统 | +25% |
| 私有化部署 | +30% |
| 培训 2 次 + 录屏 | +5% |

**合计约 +90%，所以 1.9 是成本翻倍，不是宰客。**

## 4.2 三个"涨价"的真话

| 想涨价时你在想 | 真实情况 |
|---|---|
| "客户会跑" | 会跑的那部分客户，本来就是毛利最低的 |
| "我技术还不够" | 客户买的不是技术，是"问题解决" |
| "同行报价更低" | 低价的同行通常做不完，客户会回来找你 |

**涨价的唯一前提：** 你能说清"为什么值这个钱"。说不清，就回到第 242 节课写服务介绍。

# 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 建议报价算出来大得离谱 | 毛利率 + 税率接近 100% | 检查输入，正常 40% + 6% |
