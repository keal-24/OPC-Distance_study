## 把钱合法地拿到手，然后干净地脱手

---

## 这一周的目标

上一周你拿到了"有人愿意付钱"。这一周解决后面三件事：**这单到底赚多少、钱怎么安全到账、项目结束后怎么走开。**

要做到六件事：

1. **算清四类成本** —— 时间、现金、税费、隐性，估工时乘 1.8；
2. **用除法报价** —— `报价 = 总成本 ÷ (1 − 毛利率 − 税率)`，不是加价；
3. **把附件写成合同** —— 功能清单每条带数字上限，验收标准可被第三方执行；
4. **让钱按节点到** —— 五级催款阶梯，暂停服务不等于关系统；
5. **合规开票记账** —— 个体户 vs 公司、三本账、零申报也必须报；
6. **弄清代码归谁，然后交得干净** —— 保留通用组件、交付八件套、脱身预案。

## 为什么排在这一周

**因为你现在有了一个真实的客户，而真实的客户会问四个问题：**

```text
「能开票吗？」          → 第 250 节
「合同你发我看看」       → 第 248 节
「这个价能不能便宜点」    → 第 247 节（这时你要能算出底线在哪）
「做完这些代码是我们的吧」 → 第 251 节
```

**这四个问题，一个都答不好，单子就飞。**

**更常见的情况是单子没飞，但钱没到手：**

```text
做完了 → 客户说"再改改" → 改了两个月 → 客户说"预算没了"
你把系统上线了，但尾款没结，你也不敢下线（下线等于撕破脸）
```

**这一周就是防这个。** 五级催款阶梯、验收标准、"逾期未异议视为通过"，全是给这个场景准备的。

## 这一周最反直觉的一件事

```text
你以为的报价：成本 × 1.4 = 报价（加 40%）
真实的报价：成本 ÷ (1 − 40% − 6%) = 报价
```

**两个算法差 3,700 元（成本 1 万时）。**

**这是"报价永远偏低"的数学原因，也是这一周唯一一个真正的公式。**

```text
加法：成本 1 万 × 1.4 × 1.06 = 14,840   → 实际毛利率 32%
除法：成本 1 万 ÷ (1 − 0.4 − 0.06) = 18,519 → 实际毛利率 40%
```

**为什么加法错：** 因为毛利率是**"报价里剩下多少"**，不是"成本上浮多少"。你想留 40%，那 40% 是报价的一部分，成本只能是 60%。**分母变了，不是分子变了。**

**这一条搞错，你越努力越穷。**

## 这一周的四条铁律

```text
一、报价用除法，不用加法。
    报价 = 总成本 ÷ (1 − 目标毛利率 − 税率)
    毛利率是"报价里剩下的"，不是"成本上浮的"。

二、合同的价值全在附件，不在正文。
    正文是模板，网上抄一份就行。
    功能清单（每条带数字上限）和验收标准（可被第三方执行）才是合同。
    80% 的纠纷，吵的都是附件没写清。

三、首付不到不开工，验收不过不交源码。
    你只有一个人，垫不起。开工前收 30%—50%，这是行业惯例，不是你不信任他。

四、交付时一定要留一份"我怎么走开"的预案。
    客户会换供应商，也可能自己找人接手。
    你不写交接文档，将来出事他第一个找的是你。
```

## 这一周最容易白干的四件事

**第一：把"合同"当成一份模板**

```text
错：网上找一份《软件开发合同》，签了，以为万事大吉
```

**模板只规定了"做什么类的事"，没有规定"做到什么程度算完"。**

```text
真实纠纷长这样：
  客户：这个导出功能不对，我要按门店分开导出
  你：合同里写的是"数据导出功能"
  客户：那不就是按门店分开吗
  你：……
```

**第 248 节要你写的是：**

```text
功能：数据导出
上限：支持导出订单明细，单次最多 5000 条，字段固定为 12 个（附件一列明）
不含：按门店/日期分组、自定义字段、定时导出
```

**"不含"那一行比"含"那一行保命。**

**第二：以为"个体户"和"公司"只是名字不同**

```text
个体户：注册快、成本低、能开普票和专票、个税按经营所得
公司：  要记账报税、有企业所得税 + 分红个税、但有有限责任

关键区别不是税，是责任：
  个体户欠债 → 你个人财产承担责任
  公司欠债   → 以注册资本为限（一般情况）
```

**第 250 节的结论是"先去注册个体户"，理由是"先有资格收钱"比"最优税务结构"重要一百倍。**

**第三：把"催款"当成伤感情的事**

```text
错：客户拖了两个月，你不好意思问，怕伤关系
结果：又拖了一个月，你现金流断了
```

**真相是：按时催款的人，客户更尊重。**

```text
因为按时催款 = 你在按合同办事 = 你的报价和服务也是认真的
一直不催 = 你自己都不把自己的合同当回事
```

**第 249 节的五级阶梯，从"友好提醒"到"暂停服务"，每一级都有具体话术。**

**第四：交付完就消失了**

```text
错：代码给了，尾款收了，微信不回
```

**这会让你损失掉最便宜的一类客户：回头客和转介绍。**

**第 252 节的交付八件套里有一份"操作手册"和一份"交接表"，作用不是让客户感激你，是让他下次有事第一个想到你。**
