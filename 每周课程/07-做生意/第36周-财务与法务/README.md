# 第36周 · 财务与法务 · 第246-252节课

## 把钱合法地拿到手

---

## 这一周的目标

个体户还是公司、开票、报税、合同模板、软件著作权、商标、你的代码归谁、交付与脱身预案。

## 为什么排在这一周

收到钱和「合法地收到钱」是两件事。不懂这些，你会遇到：客户要专票你开不出、尾款催不回来、代码被客户拿去卖你没办法。

---
