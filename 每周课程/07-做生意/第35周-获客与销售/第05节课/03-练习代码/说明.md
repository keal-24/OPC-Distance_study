# 03-练习代码

**本节课要新建：**

```text
03-练习代码/
├── 报价单.md          ← 三档 + 三笔 + 有效期
└── 报价前必问.md      ← 六问 + 追问话术
```

## 报价单不是草稿，是能直接发给客户的文件

**判断标准：** 把 `报价单.md` 转成 PDF 发出去，客户能不能只看这一份就决定买哪档。

如果客户还要问你"包含什么""怎么付钱""多久"，说明报价单不完整。

## 三条硬规矩

| 规矩 | 说明 |
|---|---|
| **不写工时明细** | 写"11 天"，客户就开始算你一天赚多少 |
| **不写利润率** | 跟他无关，只会招砍价 |
| **不写"可以再谈"** | 这句一出现，价格立刻掉 20% |

## 仓库里的脱敏

报价单里的客户名用 `XX 机械`，具体金额可以保留（这是你自己的定价，不是客户的商业机密）。

**但不要提交：** 客户联系方式、客户内部文档、任何能定位到具体公司的信息。

## 检验自己有没有真做完

合上文件，回答：

- 我中间那档卖多少钱？为什么是这个数？我实际每小时赚多少？
- 基础版为什么"能用但明显不方便"？我砍掉了什么？
- 客户说"别人报价是你一半"，我第一句话说什么？

**答不出来，说明报价单还是抄的，不是算的。**
