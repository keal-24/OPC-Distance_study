# 第 242 节课：写服务介绍——一句话让人记住你，一段话让人敢问你

> **这份文件是你（学员）一步一步照着做的操作手册。**
> 这节课写三个版本的自我介绍：**10 秒版（微信/名片）、1 分钟版（饭桌/电话）、详细版（发给采购/老板看）**。
> 三种场合，三种长度，内容不能互相矛盾。

**建议用时**：100 分钟
**你需要先完成**：第 241 节课（有三个案例）

---

# 第 0 步：先看三个反面样本（10 分钟）

## 0.1 你会怎么写，别人就怎么忘

| 写法 | 问题 | 对方的真实反应 |
|---|---|---|
| "我是全栈开发者，精通 Node.js、React、AI 应用" | 说的是"我会什么" | "哦，做程序的"（然后忘了） |
| "提供一站式数字化解决方案" | 一个词都不具体 | "又来一个" |
| "我帮企业用 AI 降本增效" | 谁都能说 | "具体干啥的？" |

## 0.2 客户脑子里只有三个格子

**任何人听你介绍时，只会往里填三个格子：**

| 格子 | 你必须在 10 秒内填上 |
|---|---|
| **给谁做** | 哪一类人（不是"企业"） |
| **解决什么** | 具体那件事（不是"效率"） |
| **变成什么样** | 结果（最好带数字） |

**填不满三个格子，这段介绍就是无效的。**

## 0.3 一句公式

```text
我帮【谁】把【什么麻烦】变成【什么结果】。
```

**照着填：**

| 元素 | 差的填法 | 好的填法 |
|---|---|---|
| 谁 | 企业 | 有几十份产品资料的制造厂 |
| 什么麻烦 | 效率低 | 新销售查不到参数，报错价丢单 |
| 什么结果 | 提升效率 | 微信里问一句就能出答案，还带原文出处 |

**填完：**

```text
我帮有几十份产品资料的制造厂，把"新销售查参数靠问人、答错丢单"变成
"微信里问一句就出答案，还标出是哪份文件"。
```

> **这句话可能不够漂亮，但它能让人立刻问下一句："多少钱？"**
>
> **能引出追问的介绍，就是好介绍。**

## 0.4 今天的交付物

| 文件 | 位置 | 内容 |
|---|---|---|
| `服务介绍.md` | `03-练习代码` | 10 秒版 / 1 分钟版 / 详细版 / 不做什么 |

# 第 1 步：写 10 秒版（20 分钟）

## 1.1 硬性限制

| 限制 | 数值 | 为什么 |
|---|---|---|
| 字数 | **40 字以内** | 超过就记不住 |
| 技术名词 | **0 个** | 对方听不懂就等于没说 |
| 行业 | **必须出现** | 决定他会不会想到"我认识一个这样的人" |

## 1.2 写 5 个版本，然后选 1 个

**别指望一次写好。写 5 个，念给 AI 听，让它挑。**

```text
我写了 5 个一句话自我介绍，都是"我帮【谁】把【麻烦】变成【结果】"的格式。

请你扮演一个 45 岁的工厂老板，不懂技术：
1. 每个版本告诉我：我听完知道你是干什么的吗？我能不能想起身边哪个人需要这个？
2. 挑出最好的一个，并说明为什么另外四个更差；
3. 不要帮我改写，只做判断。

1. （贴你的第 1 个版本）
2. ……
```

## 1.3 一个自检清单

| 检查 | 不合格的信号 |
|---|---|
| 有没有具体行业 | 出现"企业""客户""中小企业" |
| 有没有具体麻烦 | 出现"效率""成本""体验""数字化转型" |
| 有没有结果 | 完全没有数字或场景 |
| 能不能背下来 | 你念的时候要看着屏幕 |

> **合格标准：不看屏幕，能一口气说完，而且说完对方会问一句"那你这个多少钱？"或者"我认识一个做这行的"。**
>
> **对方说"哦，挺好"然后换话题，就是不合格。**

# 第 2 步：写 1 分钟版（25 分钟）

## 2.1 结构：四句话

| 顺序 | 说什么 | 时长 |
|---|---|---|
| 1 | 一句话版（原样，不要改） | 10 秒 |
| 2 | **一个具体场景**："上个月有个客户……" | 20 秒 |
| 3 | **我怎么做的**（3 句，客户语言） | 20 秒 |
| 4 | **结果**（一个数字）+ 一句"这类项目通常 1-3 万" | 10 秒 |

**第 4 句为什么要提前说价格区间：**

> **不说价格，对方会一直防着你"什么时候开始推销"。**
>
> **先给区间，他反而会开始认真评估"值不值"。**

## 2.2 一个完整例子（照着结构写你自己的）

```text
我帮有几十份产品资料的制造厂，把"新销售查参数靠问人"变成"问一句就出答案"。

上个月有个客户，他们新来的销售把 8 米车床的承重答成了 6 米的，报了价，客户直接不理了。
一年这种事丢三五单，一单二三十万。

我做的事很土：把他们现有的产品手册、报价表、技术文档整理成一个能问答的库，
新销售在手机上问一句"8 米车床承重多少"，它直接从文档里找答案，还标出是哪一页。

现在他们内勤说，以前要问老销售的事，八成自己能查到。
这类项目我一般做 1-3 万，看文档量和要不要对接他们现有系统。
```

## 2.3 三条纪律

| 纪律 | 原因 |
|---|---|
| **只讲一个客户，不讲三个** | 讲三个等于没讲，对方一个都记不住 |
| **数字必须是具体的** | "三五单""二三十万"比"很多""很高"可信十倍 |
| **最后一句主动给价格区间** | 筛掉预算不够的，省双方时间 |

# 第 3 步：写详细版（25 分钟）

## 3.1 详细版的结构（顺序不能换）

```text
1. 一句话版
2. 你在解决什么问题（3 条，每条一句）
3. 你怎么做（3 步，客户视角，不是技术视角）
4. 交付什么（清单）
5. 多久 / 多少钱（区间 + 影响价格的因素）
6. 我不做什么（划边界）
7. 案例（三个的一句话版）
8. 怎么开始（下一步动作）
```

## 3.2 第 2 节：问题怎么写

**每条格式：`【谁】在做【什么】的时候，会【怎样】，导致【什么损失】。`**

```text
- 新销售查产品参数要问老销售，老销售不在就只能等，等到客户没耐心。
- 同一型号的参数在 3 个文件里不一样，谁也不敢确定哪个对。
- 答错了没人知道，要等客户投诉才发现。
```

**这一节的作用：让客户在心里点头三次。** 点三次头，他就信你了。

## 3.3 第 6 节：不做什么（最重要的一节）

**大多数人会漏掉这一节。它是保护你自己的一节。**

```markdown
## 我不做什么

- **不做手机 App**：只做网页，手机上用浏览器打开就行。
- **不保证答案 100% 正确**：AI 会答错，所以每条答案都带原文出处，需要人工核对。
- **不管你们的服务器和网络**：我只交付应用，服务器由你们提供或我代买（另计）。
- **不做和现有 ERP 的自动同步**：第一期只做导入导出，对接要单独评估。
- **不含内容录入**：文档要你们提供电子版，扫描件识别另算。
```

**为什么必须写：**

| 作用 | 说明 |
|---|---|
| 挡掉 80% 的白聊 | 他要的是 App，你不做，一分钟就结束，双方都省事 |
| 提前消灭纠纷 | 后面他说"你怎么没做 App"，你有这句话 |
| 显得专业 | 什么都做的人，通常什么都做不好 |

> **"不做什么"写得越清楚，客户越信你"能做什么"。**

## 3.4 第 5 节：价格怎么写

**只能写区间 + 影响因素，不能写一口价。**

```text
这类项目通常 1-3 万，取决于三件事：
- 文档有多少份、乱不乱（10 份和 200 份差一倍工作量）
- 要不要对接你们现有系统（要对接就往上走）
- 要不要私有部署到你们内网（要的话另加 50%）
```

**为什么不写一口价：**

| 原因 | 说明 |
|---|---|
| 你还没看到他的文档 | 现在报价一定是猜的 |
| 一口价没有退让空间 | 他砍价你只能硬扛或者认亏 |
| 区间能让对话继续 | 他会主动说"我们文档不多"，你就有了信息 |

# 第 4 步：三个版本的互相校验（10 分钟）

**三个版本不能互相矛盾。用这张表过一遍：**

| 检查项 | 10 秒版 | 1 分钟版 | 详细版 |
|---|---|---|---|
| 目标客户一致吗 | | | |
| 解决的问题一致吗 | | | |
| 价格区间一致吗 | 不提 | 提了 | 提了 |
| 有没有说"我也做别的" | **不许** | **不许** | 只能出现在"不做什么"里 |

**最容易犯的错：为了多接单，在介绍里加一句"其他类型也能做"。**

> **加了这一句，你从"做这一件事的人"变成"什么都能做的人"。**
>
> **前者有溢价，后者只能比价。**

# 第 5 步：让 AI 用客户视角读一遍（10 分钟）

```text
下面是我的服务介绍（详细版）。请你扮演两类人，分别读一遍并回答问题。

【角色一：一家 120 人制造厂的老板，48 岁，不懂技术，时间很少】
1. 我读完知道你能帮我干什么吗？
2. 哪一段我会跳过？
3. 看完我下一步会做什么？（如果答案是"什么都不做"，说明缺什么）

【角色二：同一家公司的采购】
1. 我关心的问题（多少钱、多久、出问题谁负责）有没有答案？
2. 哪句话会让我觉得你在推责任？

不要夸我，只回答上面的问题。
```

**然后把它的答案当参考，不要当判决。** 它的"角色"是演的，但它的挑刺往往准。

# 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 写完自己都觉得空 | 缺具体行业和麻烦 | 回到第 239 节课的画像卡，抄它的字段 |
| 一句话版写不进 40 字 | 想说太多 | 只留"谁 + 麻烦 + 结果"，其他全砍 |
| 不敢写价格区间 | 怕报高了吓跑 | 区间下限写你能接受的最低价，上限写你希望的价 |
| "不做什么"写不出来 | 你想接所有单 | 想想你被坑过的场景，那就是该写进去的 |
| 客户听完说"挺好"就没下文 | 没有一句能让他联想到具体的人 | 行业必须具体到"机械厂""汽配""诊所"这一级 |
| 介绍里全是"AI" | 你在卖技术 | 换成"它能让你干什么" |
