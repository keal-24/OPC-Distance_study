## 周末的验收

不要急着进下一周。先确认这三条：

- [ ] 这一周每节课都有 commit（打开 GitHub 看绿点，一节课都不能缺）
- [ ] `第01节课/` 到 `第07节课/` 里都有 `NOTES.md`，而且「卡在哪」写了内容

> **第三条才是真标准。** 说不出来，说明这一周只是跟着点了七次，没真的进脑子。
