# 第35周 · 获客与销售 · 第 239—245 节课

## 从"我会做"到"有人愿意付钱"

---

## 这一周的目标

前 238 节课你练的是**把东西做出来**。这一周练的是另一件事：**让某个具体的人掏钱。**

要做到六件事：

1. **圈出会付钱的人** —— 不是"中小企业"，是能报出名字的三个人；
2. **问出真需求** —— 客户原话和你的推断必须分开写；
3. **做出能看的证据** —— 三个案例，不是简历、不是截图合集；
4. **让人敢问你** —— 10 秒 / 1 分钟 / 详细三个版本，外加"我不做什么"；
5. **报出三个数** —— 只有一种价格的人，只能被砍价；
6. **把六份文档变成一个链接** —— 能发给任何人、能被搜索到、能追来源。

## 为什么排在这一周

**因为前 34 周有一个共同的假设：需求已经存在。**

```text
第 3 周  「客户说要个对话应用」        → 需求是别人给的
第 24 周 「客户要能管 5 个部门」        → 需求是别人给的
第 34 周 「客户要私有化部署」          → 需求是别人给的
```

**这一周把那个假设拿掉。** 没有人给你需求，你得自己找到那个有痛点的人，并且让他相信你能解决。

**技术再好，没有客户就是零。** 这是整条路线里唯一教「怎么找到人愿意付钱」的一周，也是最多人跳过、最后卡死的一周。

**卡死的方式很具体：**

```text
你会写代码，会部署，会接模型。
你在朋友圈发了一句"接单，什么都能做"。
三个月，零咨询。

然后你得出一个结论："这行不行。"
真实原因：你在等客户来找你，而客户不知道你是谁。
```

## 这一周最反直觉的一件事

```text
你以为的销售：把一个东西说得很好，让对方买
真实的销售：先问清对方到底要什么，然后决定"这个单我接不接"
```

**七节课里有三节在讲"不接"：**

```text
第 239 节  砍掉五类候选客户
第 242 节  写清"我不做什么"
第 243 节  三档报价里有一档是"你不需要我做"
```

**这三节是这一周最值钱的部分。**

```text
接错一个单，代价不是"少赚"，是：
  三个月的时间 + 一个差评 + 一段你不敢给任何人看的代码
  + 一个在行业群里说你不行的人

拒绝一个错单，代价是：一次不舒服的对话。
```

**你只有一个人。时间是你唯一的原材料，卖错了收不回来。**

## 这一周的四条铁律

```text
一、画像必须能报出一个真人名。
    "中小企业""餐饮老板""想做 AI 的公司"——这些不是画像，是愿望。
    报不出名字，说明你还没找到人，只是想象了人。

二、客户原话和你的推断，必须分开写。
    "他们说想要个报表" —— 这是你的转述，可能已经错了。
    "张总原话：'我每周一早上要花三小时把三个店的数抄到一个表里'" —— 这才是需求。
    需求清单里每一条后面都要标：来自原话 / 来自我的推断。

三、报价只能降范围，不能降价格。
    客户说贵，你砍价 30%，你就教会了他"你的价格是假的"。
    正确做法：把功能清单砍掉一块，价格降下来，但单价不动。

四、下一步必须是"具体动作 + 时间"。
    "我回头再联系您" —— 这句话等于结束。
    "我周三下午把方案发您微信，您周五前给我一句话就行" —— 这才是推进。
```

## 这一周最容易白干的四件事

**第一：写一份"什么都能做"的自我介绍**

```text
错：我是一名全栈开发者，擅长前端后端数据库，可以做小程序、网站、AI 应用……
```

**这句话的信息量是零。** 客户读完的反应是"哦，那他跟别人有什么区别"。

**它还有一个更严重的副作用：** 你把筛选客户的工作交给了客户。**而客户不会筛，他会全部问一遍，然后全部嫌贵。**

**第二：把自建项目写成客户项目**

```text
错：案例一：某企业内部知识库系统
    背景：客户需要……   ← 客户是谁？你编的
```

**这是最容易翻车的一处。** 客户只要问一句"这个能给我看看吗？能联系下他们吗？"，你就得当场承认。

**正确写法：**

```text
案例一：自己的资料检索工具（自建项目）
背景：我有 3000 篇笔记，搜不到东西
做法：……
结果：找资料从平均 4 分钟降到 20 秒
还做不到：只能搜文字，图片里的字搜不到
```

**"自建项目"这四个字写出来，可信度反而更高。** 因为它真。

**第三：报价时只给一个数字**

```text
错：这个项目 2 万。
客户：太贵了，1 万行不行？
你：……行吧。
```

**从这一刻起，你所有的报价都会被砍。** 因为客户学到了"这个人会松口"。

**三档报价的作用不是让你多赚，是让你有一个不松口的理由：**

```text
"2 万是按您说的三个功能做的。如果您只做前两个，是 1.4 万。
 不是打折，是少做一块。您看哪个更合适？"
```

**第四：等客户回复**

```text
发完提案 → 等 → 三天没动静 → 不敢问 → 一周后客户找了别人
```

**一人公司没有"跟进"这个动作就活不下去。** 第 244 节的六句话应答卡里有一句就是催回复的，**用它的唯一成本是打几个字。**

- [ ] 每节课的 `NOTES.md` 都填了，「卡在哪」写了真实内容

>

## 这一周不用学什么

明确排除，避免你分心：

```text
营销漏斗 / 增长黑客        你没有流量，先有一个客户
SEO 技术优化               第 245 节只讲最基础的三件事，深的不碰
投流 / 信息流广告          花的是真钱，你没到那个阶段
CRM 系统（销售易/纷享销客）  Excel 和 30 人名单够了
销售话术的心理学模型        SPIN / BANT 这些是团队用的，你一个人先练"问对问题"
商业计划书 / BP            你要的是第一个客户，不是融资
定价策略的理论（价格歧视等） 三档报价就是全部你需要的
个人品牌 / 内容运营          长期事，等你有三个客户再说
```
