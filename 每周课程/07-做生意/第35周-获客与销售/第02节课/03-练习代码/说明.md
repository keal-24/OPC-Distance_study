# 03-练习代码

**本节课要新建两个文件：**

```text
03-练习代码/
├── 访谈记录.md      ← 一场真实（或模拟）访谈的原话记录
└── 需求清单.md      ← 8-15 条需求，每条带原话依据
```

## 记录的三条硬规矩

1. **原话照抄。** 客户说"这玩意儿太啰嗦"，你就写"太啰嗦"，不要改成"界面信息密度过高"。
2. **推断单独放一节，标"待验证"。** 混在一起写，一周后你自己也分不清哪句是客户说的。
3. **数字全部单独表列。** 人数、工时、金额、频次——这些是报价的唯一依据。

## 不要放进仓库的东西

- 客户手机号
- 具体报价数字（等第 243 节课再写，而且要用代号）
- 客户的内部文件、截图里的真实数据

**用 `张总（XX机械）` 这种写法就够了。**

## 检验自己有没有真做完

不看文件，回答：

- 客户现在是怎么凑合解决的？为什么快凑合不下去了？
- 他一年的损失大概多少？这个数字是他说的，还是我算的？
- 我最后只留了哪三条？为什么砍掉其他？

**答不出来，说明这还是一场客套聊天，不是访谈。**
