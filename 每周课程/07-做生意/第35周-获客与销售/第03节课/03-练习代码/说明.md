# 03-练习代码

**本节课要新建：**

```text
03-练习代码/
├── 案例.md
└── screenshots/
    ├── case1-qa.png
    ├── case2-admin.png
    └── case3-excel.png
```

## 截图规矩

| 规矩 | 说明 |
|---|---|
| 必须脱敏 | 客户名、手机号、金额、真实产品型号一律涂掉 |
| 只截一条路径 | 输入 → 结果，两屏以内 |
| 命名有意义 | `case1-qa.png`，不要 `微信截图20261116.png` |
| 用系统截图 | Win + Shift + S，别用手机拍屏幕 |

## 案例类型必须标注

```text
真实项目 / 自建项目 / 演示项目
```

**把自建项目写成客户项目的，这一课算没做。** 客户问两句就露馅，一句谎话毁掉全部信任。

## 仓库里不能有的东西

- 客户的真实数据、内部文件
- 客户的合同金额、报价单
- 任何能定位到具体客户的信息

**仓库会推到 GitHub，公开的。**

## 检验自己有没有真做完

不看文件，回答：

- 我的三个案例分别覆盖什么担心？为什么不能三个都是问答助手？
- 每个案例里我主动承认了什么"还做不到"？
- 我的数字是实测的，还是编的？

**"看着挺厉害"不是合格，两分钟内让客户对上自己的问题才是。**
