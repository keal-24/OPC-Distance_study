# 03-练习代码

**本节课要新建：**

```text
03-练习代码/
├── 提案.md        ← 一页纸，五格
└── 话术卡.md      ← 六句话 + 四种异议 + 演示三条纪律
```

## 一页纸的硬标准

**打印预览，A4 一页。** 装不下就是话太多，删掉：

| 先删什么 | 为什么 |
|---|---|
| "关于我们""我的技术栈" | 客户最不关心的就是这些 |
| 技术架构图 | 他看不懂，只会觉得你在拖时间 |
| 第三个案例 | 一个够用，三个是炫耀 |
| "期待与您的合作" | 没有动作，等于没结尾 |

## 话术卡要能背

`话术卡.md` 不是给你收藏的，是给你**在被问住的当场翻**的。

**做法：** 打印出来，或者存成手机备忘录，第一次真实谈客户时放在手边。

## 仓库里的脱敏

提案里客户名写 `XX 机械`，金额可以保留（那是你的定价）。

**不要提交：** 客户联系人、电话、内部数据截图。

## 检验自己有没有真做完

合上文件，回答：

- 客户打开我的提案，第 1 屏能看到哪三样东西？
- 我的"下一步"是什么动作？他答应的成本有多低？
- 客户说"再考虑考虑"，我下一句问什么？

**"再考虑考虑"之后没有追问，就等于这单结束了。**
