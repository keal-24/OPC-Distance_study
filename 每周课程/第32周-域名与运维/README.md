## 有域名、有锁、挂了知道、续费不忘

---

## 这一周的目标

域名解析、备案、HTTPS、备份与恢复演练、监控告警、日志收集、成本监控、续费清单。

## 为什么排在这一周

没有 HTTPS 客户会慌。没有监控，客户比你先发现问题。而忘记续费域名，网站会在某个凌晨直接消失——这是最冤的一种死法。
