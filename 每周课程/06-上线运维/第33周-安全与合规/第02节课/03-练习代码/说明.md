# 03-练习代码

**这个文件夹故意留空。**

本节你要自己建一个只有两个接口的小项目，用来做"被绕过"的实验：

```text
03-练习代码/
└── valid-lab/            ← 你自己建
    ├── package.json
    ├── server.js         ← 两个接口：注册、发消息
    ├── validate.js       ← 手写校验
    ├── schema.js         ← zod schema
    ├── public/
    │   └── index.html    ← 带前端校验的表单
    └── requests.md       ← 8 条 curl 和结果
```

## 为什么单独建

```text
① 这节课要故意"不校验"，看你被绕过 —— 真项目里不能这么干
② 要故意传 1MB 的 body 打内存 —— 线上会把服务打死
③ 要改 .env 之外的配置反复重启 —— 别碰在跑的项目
```

## 怎么建

1. 建 `valid-lab` 文件夹，`npm init -y`；
2. `npm install express zod`；
3. 按课件第 1.2 步写一个"只有前端校验"的版本，先在浏览器里点通；
4. 再用 `curl` 绕过它，把结果记进 `requests.md`；
5. 然后按第 3 步补手写校验，按第 4 步改成 zod；
6. 最后按第 7 步把 8 个请求全跑一遍。

## 这一节的实验清单

```text
① 改 maxlength，提交 50000 字
② curl 少字段 / 类型错 / 多传 role:admin
③ 不给 Content-Type，看会不会 500
④ 传 ?id=1&id=2 看 query 变成什么
⑤ 传 __proto__ 看有没有污染
⑥ 传 1MB body，看 413 还是内存暴涨
⑦ 传带单引号的内容，看响应里有没有 SQL 报错
```

## 检查清单

- [ ] `requests.md` 里 8 行都填了状态码
- [ ] 响应体里搜不到 `SQLITE` / `syntax` / `at Object`
- [ ] `role: "admin"` 传进去之后，返回值里没有 `role`
- [ ] `?id=1&id=2` 返回 400，而不是 500
- [ ] 1MB body 返回 413，而且进程内存没有明显上涨
