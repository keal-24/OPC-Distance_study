# 03-练习代码

**这个文件夹故意不留代码。** 这一节不写业务代码，产出的是一张表和一份清单。这两份东西比代码活得久。

---

## 本节课你要建什么

```text
03-练习代码/
├── SECURITY-CHECKLIST.md        ← 核心产物：20 项，能拿给客户看
├── 修复清单.md                   ← 不通过的项目，风险 + 临时措施 + 截止日
└── security-check.sh            ← 能自动化的项写成脚本，一次跑完
```

## 为什么这一节的产物是文件不是代码

因为你以后会需要它三次：

```text
① 三个月后复查     —— 你早忘了当时怎么检查的
② 客户问"安全吗"   —— 你有一张别人能复现的表
③ 第 34 周交付      —— 直接改成验收单，不用重做
```

**代码会重写，表能一直用。**

## `SECURITY-CHECKLIST.md` 的五个要素

每一项都必须有：

```text
① 检查什么     具体到能执行（"密钥不在 Git 历史里"，不是"密钥安全"）
② 怎么验       给命令，别人能复制粘贴
③ 通过标准     什么算通过（"输出为空"）
④ 结论         通过 / 不通过 / 不适用
⑤ 证据         贴输出，或截图路径
```

**少任何一个，这一项都不算检查过。**

## 汇总表必须真实

```markdown
| 分组 | 通过 | 不通过 | 不适用 |
|---|---|---|---|
| A 密钥与凭据 | | | |
| B 输入与权限 | | | |
| C 注入与上传 | | | |
| D 日志依赖运维 | | | |
```

**20 项全打勾的表，客户不信，你自己也不该信。**

真实的表长这样：通过 16、不通过 1（有修复计划）、不适用 3（有理由）。

## ⚠️ 这一节的三个假动作

**第一：五分钟填完表**

20 条命令真跑一遍，最低 50 分钟。五分钟填完的表一定没跑过。

**第二：把"不适用"当出口**

"我没有上传功能"是理由。"我不想做"不是。**先 grep 一遍证明你确实没有：**

```bash
grep -rn "multer\|formidable\|multipart" server.js package.json
```

**第三：修完不改表**

改完代码、跑完命令、贴上新输出、把 ❌ 改 ✅、更新汇总数字和日期。**少一步，表就在骗人。**

## 这一节要留下的证据

| 证据 | 证明什么 |
|---|---|
| `git log --all -- .env` 的空输出 | 密钥没进历史 |
| 越权批量测试的 `id -> code` 列表 | 归属检查真的生效 |
| `npm audit` 的 `found 0 vulnerabilities` | 依赖是干净的 |
| `certbot renew --dry-run` 的成功输出 | 90 天后不会挂 |
| 一次真实的恢复演练输出 | 备份能用，不只是存在 |

## 检验自己有没有真学会

- "我检查过了"为什么不算证据？
- 越权为什么返回 404 而不是 403？
- 哪五项必须在服务器上跑？为什么在家里跑没意义？
- 20 项全打勾，你信吗？为什么？
