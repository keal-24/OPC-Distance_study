# 03-练习代码

**这个文件夹故意留空。**

本节课不放任何现成代码。你要在这里自己建两个东西：

```text
03-练习代码/
├── key-audit.md          ← 你自己写：钥匙盘点表 + 应急卡
└── drill/                ← 你自己建：演练用的小项目
    ├── .git/             ← git init 自动生成
    ├── .env              ← 假的密钥，演练完删掉
    ├── .env.example      ← 模板，要提交
    ├── .gitignore
    └── server.js         ← 一个能启动的最小 Express
```

## 为什么要有 `drill/`

因为这一节要做的操作，**在真项目里做会出事**：

```text
把 .env 提交进 git          → 真项目会永久泄露
用 filter-repo 重写历史      → 真项目所有哈希都变，协作者全乱
改成 chmod 600 再改回来      → 真项目可能 500
```

**所以建一个只用假数据的小项目，所有破坏性实验都在里面做。**

## 怎么建

1. 在 `03-练习代码/` 里新建 `drill` 文件夹；
2. 进去，Git Bash 里 `git init`；
3. 写一个最小的 `server.js`，只做一件事：读 `process.env.OPENAI_API_KEY` 并打印前 6 位；
4. 建 `.env`，里面写 `OPENAI_API_KEY=sk-test-xxxx`（**假 key**）；
5. 建 `.gitignore`，按课件第 7.1 节的四行写；
6. 开始做课件的实验。

## 这一节的实验清单

```text
① 故意先不建 .gitignore，提交一次，看 .env 进仓库
② git log -p -- .env 把 key 打出来
③ git rm --cached + 再查历史，确认历史还在
④ git show HEAD~1:.env 证明"删了也能拿出来"
⑤ 备份 + filter-repo + 强制推送，验证历史为空
⑥ 加 pre-commit 钩子，用 git add -f 试它拦不拦
```

## 检查清单

- [ ] `git log --all --oneline -- .env` 最后是空的
- [ ] `git show HEAD~1:.env` 报 `fatal: path ... does not exist`
- [ ] `git add -f .env` 之后 `git commit` 被钩子拒绝
- [ ] `key-audit.md` 里没有出现任何真实的 key 字符串

**如果 `key-audit.md` 里出现了真实 key，立刻把它删掉，并去后台吊销那把 key。** 这张表本身也是泄露源。
