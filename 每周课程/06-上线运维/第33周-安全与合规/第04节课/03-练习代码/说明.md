# 03-练习代码

**这个文件夹故意留空。**

本节你要建一个"三个洞都有"的小项目，然后一个一个补：

```text
03-练习代码/
└── inject-lab/           ← 你自己建
    ├── package.json
    ├── db.js             ← users + messages 两张表
    ├── server.js         ← 登录（SQL）、转码（命令）、发消息（XSS）
    ├── lab.db            ← 跑起来自动生成
    ├── public/
    │   └── index.html    ← 渲染消息列表
    └── payloads.md       ← 九条 payload 和结果
```

## 为什么单独建、为什么用假数据

```text
① 要故意写"拼接 SQL"——真项目里不能有这一段
② 要故意执行 "'; DROP TABLE"——只在 lab.db 上做
③ 要故意跑 exec 拼命令——会真的在你这台机器上执行
④ 要故意用 innerHTML——会真的执行 JS
```

**所有账号、密码、消息都是假的。** 不要拿真项目的 `.env` 和数据库来练。

## 怎么建

1. 建 `inject-lab`，`npm init -y`；
2. `npm install express better-sqlite3`；
3. 按课件第 1.1 步写 `db.js`，跑一次建表；
4. 按第 1.2 步写"拼接版"登录，在 `payloads.md` 里记下四条 payload 的结果；
5. 按第 2 步改成参数化，再跑一遍四条，确认全部 401；
6. 按第 3 步加 `ORDER BY` 白名单；
7. 按第 4 步把 `exec` 改成 `execFile` + `safeName`；
8. 按第 5 步做 XSS 实验，再改成 `textContent`；
9. 最后跑第 6.2 节的七条 curl，加浏览器里的两条。
