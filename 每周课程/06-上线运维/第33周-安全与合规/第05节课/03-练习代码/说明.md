# 03-练习代码

**这个文件夹故意不留代码。** 这一节要建一个只干一件事的最小上传服务，专门用来挨打。

---

## 本节课你要建什么

```text
03-练习代码/
├── upload-lab/                  ← 你自己建
│   ├── server.js                ← 先写"有洞版"，再写"修好版"
│   ├── uploads/                 ← 修好版之前，这里不能被直链访问
│   ├── storage/                 ← 修好版之后文件放这里（web 根外面）
│   ├── attacks.md               ← 七种攻击：传了什么、修好前、修好后
│   └── payloads/                ← 你自己造的测试文件
│       ├── evil.html
│       ├── evil.svg
│       └── big.bin
└── 上传体检.md                   ← 正式项目里每个收文件的地方
```

## 为什么 `payloads/` 要自己造

因为这七种攻击里，**没有一种能从网上直接下载到"正好适合你代码"的样本**。

你要自己写：

```text
evil.html     一行 <script>alert(document.domain)</script>
evil.svg      <svg xmlns="..."><script>alert(1)</script></svg>
big.bin       随便 dd 出来的 50MB
```

**造样本的过程本身就是学习。** 你会知道攻击者到底传了什么字节。

## 修好版的五道关

```text
① 扩展名白名单      只认 jpg / jpeg / png / webp / gif
② 魔数校验          看文件头，不看它自称的类型
③ 大小上限          multer 的 limits + Nginx 的 client_max_body_size
④ 文件名服务端生成   UUID，原始名只进数据库用来显示
⑤ 存储位置           web 根外面，读取走鉴权接口
```

**少任何一道都能被打穿。** 五道是叠加的，不是备选。

## ⚠️ 这一节的三个高危动作

**第一：`client_max_body_size` 调太大**

调到 `100m` 图省事，结果有人并发传 20 个 100MB，磁盘满了，全站 500。**按业务真实需要设，图片给 5m 就够。**

**第二：把文件放进 `public/` 图方便**

`public/` 下的任何文件都是**直接可下载**的，而且只要扩展名是 `.html`，浏览器就会当网页执行。**这是"你的域名下跑着别人的钓鱼页"的标准成因。**

**第三：收了 SVG 还允许直链访问**

SVG 是 XML，里面能放 `<script>`。浏览器打开 SVG 直链时会执行它。**要么不收 SVG，要么转成 PNG 再存。**

## 这一节要留下的证据

| 证据 | 证明什么 |
|---|---|
| 访问 `evil.html` 直链时页面真的弹了 alert | 洞是真的 |
| 修好后同一个地址 404 | 洞是真的堵了 |
| `413` 的两种响应体（Nginx 的和应用的） | 你能分辨是谁拦的 |
| `file` 命令或 `xxd` 看到的文件头 | 魔数校验是有依据的 |
| `storage/` 里全是 UUID 文件名 | 文件名不可控 |
| `attacks.md` 七行都有前后对比 | 你不是"看了一遍" |
