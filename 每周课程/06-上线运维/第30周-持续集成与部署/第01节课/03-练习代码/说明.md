# 03-练习代码

**这个文件夹故意留空。**

本节课你要在这里建一个**独立的练手仓库**：

```text
03-练习代码/
└── ci-lab/                  ← 你自己 clone 下来的仓库
    ├── .git/                ← git clone 自动生成
    ├── .github/
    │   └── workflows/
    │       └── hello.yml    ← 你今天要写的
    ├── .gitignore
    ├── package.json         ← npm init -y 生成
    ├── package-lock.json    ← npm install 生成
    └── README.md
```

## 为什么要单独建仓库

因为这一周会往仓库里塞一堆"只在 CI 里才有意义"的东西：

```text
.github/workflows/*.yml
故意写错的代码（第 2 节要让它变红）
Secrets（第 6 节要配密钥）
Dockerfile（第 4 节）
```

**这些东西不该出现在你的正式项目 `chat-app` 里。**

**而且第 2 节要故意提交语法错误的代码 —— 你不想让它在正式仓库的历史里留一辈子。**

## 怎么建

1. GitHub 上 `New repository` → 名字 `ci-lab` → **选 Private** → 勾 `Add a README file`；
2. 在本文件夹里打开终端（地址栏输 `cmd`）；
3. `git clone https://github.com/你的用户名/ci-lab.git`；
4. `cd ci-lab`；
5. `mkdir -p .github/workflows`；
6. 用 VS Code 打开 `ci-lab`，新建 `.github/workflows/hello.yml`；
7. 照着课件第 4 步写第一个 workflow。

**Windows 上没法用鼠标新建 `.github` 这种点开头的文件夹。** 用 `mkdir -p` 命令，或者先建成 `github` 再 `mv`。

## 这一课的检查重点

不是"文件写好了"，是"那个勾是绿的"：

```text
GitHub 仓库页面 → Actions 标签 → 左侧 hello → 右边一个 ✅
```

**绿勾旁边还会有一行 `in 12s`。** 那 12 秒里大部分是"分配机器"，不是你的命令。
