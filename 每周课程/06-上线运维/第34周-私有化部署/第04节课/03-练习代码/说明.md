# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己写这些文件：

```text
03-练习代码/
└── 235-本地模型/
    ├── llm-client.js            改好的模型调用代码
    ├── llm-client.stream.js     流式版本
    ├── ollama-compose.yml       带 ollama 的编排片段
    ├── prompt-template.md       本地模型用的提示词模板
    └── 模型测试记录.md           耗时、并发、抽测正确率
```

## 每个文件的要求

| 文件 | 必须包含 |
|---|---|
| `llm-client.js` | `baseURL` 从环境变量读、`apiKey` 非空、`timeout` ≥ 120 秒 |
| `llm-client.stream.js` | `stream: true`，逐段回调 |
| `ollama-compose.yml` | 固定版本 tag、模型目录挂载、**没有 `ports`** |
| `prompt-template.md` | 三条以上约束，"不编造"要单独列 |
| `模型测试记录.md` | 至少 3 次真实耗时 + 并发结果 + 20 题抽测 |

## 硬性要求

```text
① 代码里不许出现云端模型地址
② ollama 的 11434 不许映射到 0.0.0.0
③ 模型目录必须挂在 ./data/ 下，不许用匿名卷
④ 验收标准必须是可测量的，不许写"用户满意"
```

## 绝对不要做的事

```text
✗ 把 API key 写进代码
✗ 在内网执行 ollama pull
✗ 在 8G 内存机器上同时跑 7B + 数据库还开 4 并发
✗ 用"和演示一样"当验收标准
```
