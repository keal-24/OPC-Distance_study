# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己建出这些文件：

```text
03-练习代码/
└── 233-部署方案/
    ├── 部署方案.md          架构图 + 端口表 + 容量估算
    ├── docker-compose.yml   三个服务：nginx / app / postgres
    ├── .env.example         变量清单，不含真实密码
    ├── nginx/
    │   └── default.conf     反向代理配置
    └── 交付边界.md          合同附件，双方签字用
```

## 三个文件的用途

| 文件 | 给谁看 | 必须包含 |
|---|---|---|
| `部署方案.md` | 客户领导 + 客户 IT | 架构图、端口表、资源需求、实施计划 |
| `docker-compose.yml` | 你自己 + 客户 IT | 固定版本 tag、restart、healthcheck、bind mount |
| `交付边界.md` | 商务 + 客户 | 交付内容、不包含内容、响应时间、验收方式 |

## 硬性要求

```text
① 数据库和应用不许写 ports
② 镜像不许用 latest
③ 密码必须走 .env，且 .env 不许进 Git
④ 数据必须 bind mount 到 ./data/
⑤ 每个服务必须有 restart 和 logging 限制
```

## 绝对不要做的事

```text
✗ 把真实密码写进 compose 或方案文档
✗ 把真实客户 IP 写进架构图
✗ 把 .env 提交到仓库
✗ 在客户机器上跑 docker system prune -a 做"清理"
```
