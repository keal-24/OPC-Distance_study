# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己写这三个脚本和一份记录：

```text
03-练习代码/
└── 237-升级与备份/
    ├── backup.sh            备份：数据库 + 上传 + 配置 + 元信息 + 校验
    ├── upgrade.sh           升级：备份 → 换镜像 → 健康检查 → 冒烟 → 失败回滚
    ├── rollback.sh          回滚：换回旧镜像 → 健康检查
    ├── migrations/
    │   ├── 004_add_department.sql
    │   └── run.sh           按顺序执行，跳过已执行的
    └── 升级演练记录.md       一次失败回滚的完整记录
```

## 每个脚本的硬性要求

| 脚本 | 必须包含 |
|---|---|
| `backup.sh` | `set -euo pipefail`、`-Fc`、大小检查、保留策略、`meta.txt` |
| `upgrade.sh` | 前置检查、强制备份、记录旧版本、冒烟检查、失败自动调用回滚 |
| `rollback.sh` | 检查旧镜像存在、换 tag、健康检查、打印备份位置 |
| `run.sh` | 判断 `schema_migrations`、`ON_ERROR_STOP=1` |

## 三条铁律

```text
一、升级前必须备份，备份失败就终止。
二、镜像只用版本号 tag，永远不用 latest。
三、迁移只加不减，每个脚本跑两遍都不报错。
```

## 绝对不要做的事

```text
✗ 在生产库上做恢复演练
✗ 直接用 DROP DATABASE 不先备份当前数据
✗ 在 cron 里用 docker compose exec 不加 -T
✗ 第一次上线就带 rm -rf 的定时任务
```
