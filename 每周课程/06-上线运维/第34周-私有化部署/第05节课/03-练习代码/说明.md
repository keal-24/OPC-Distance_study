# 03-练习代码

**这个文件夹故意留空。**

本节课你要自己写这三份文件：

```text
03-练习代码/
└── 236-权限交接/
    ├── 交接清单.md          15 项，双方签字
    ├── 账号移交记录.md       谁在什么时候改了什么
    ├── 售后支持说明.md       通道、响应时间、边界
    └── 离场自查记录.md       十条检查的实际输出
```

## 每份文件的要求

| 文件 | 必须包含 |
|---|---|
| `交接清单.md` | 15 项、保管人、双方签字栏、日期 |
| `账号移交记录.md` | 时间、账号、动作、执行人、见证人 |
| `售后支持说明.md` | 临时账号流程、响应时间表、不含范围 |
| `离场自查记录.md` | 十条命令的真实输出 |

## 交接清单的 15 项

```text
root 密码 / 客户管理员 / 数据库超级用户 / 数据库应用账号
应用管理员 / SSH 密钥 / HTTPS 证书 / 备份位置
日志位置 / 开机自启 / 端口清单 / 定时任务
第三方账号 / 文档 / 联系人
```

**一项都不能少。少一项，就是一年后的一次扯皮。**

## 绝对不要做的事

```text
✗ 在文档里写真实密码
✗ 写"乙方保留维护账号，便于支持"
✗ 承诺 7×24 响应
✗ 只写"密码已交接"而不写"已由甲方重置"
```
