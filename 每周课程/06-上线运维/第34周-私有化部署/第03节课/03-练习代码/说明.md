## 每条东西的作用

| 文件 | 作用 | 缺了会怎样 |
|---|---|---|
| `manifest.txt` | 清单，也是交付签收单 | 现场不知道哪个文件是必须的 |
| `SHA256SUMS` | 校验包没坏 | 装到一半 `unexpected EOF` |
| `images/*.tar` | 镜像 | 起不了服务 |
| `docker-*.tgz` | 客户机器没装 Docker 时用 | `docker: command not found` |
| `docker-compose-linux-*` | compose 插件 | `'compose' is not a docker command` |
| `.env.example` | 变量清单 | 现场不知道要填哪些 |
| `install.sh` | 一键安装 | 手敲 20 条命令，漏一条就返工 |

## 文件命名规范

```text
镜像包：  镜像名-版本.tar           chat-app-1.2.0.tar
工具包：  工具-版本-架构.tgz        docker-27.3.1.tgz
总包：    项目名-offline-版本.tar.gz chat-app-offline-1.2.0.tar.gz
```

**版本号必须在文件名里。** 不许出现 `chat-app-new.tar` 这种名字。

## 绝对不要做的事

```text
✗ 用 docker export 代替 docker save
✗ 用 latest 作为镜像 tag
✗ 不生成校验和就拷走
✗ 在客户生产机器上跑 docker system prune -a
✗ 把 .env（含真实密码）打进离线包
```
