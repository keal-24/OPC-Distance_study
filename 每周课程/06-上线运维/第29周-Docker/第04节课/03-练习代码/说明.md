## 本节课你要改什么

```text
03-练习代码/
└── chat-app-docker/
    ├── server.js          ← 改：key 从 process.env 读；加启动检查
    ├── .env               ← 确认：不进 Git、不进镜像
    ├── .env.example       ← 新建：只有键名
    ├── .dockerignore      ← 确认：有 .env
    └── .gitignore         ← 确认：有 .env
```

## 三处改动

**① 所有 key 都从 `process.env` 读**

```js
// ❌ 不要
const API_KEY = "sk-xxxxxxxx"

// ✅ 要
const API_KEY = process.env.OPENAI_API_KEY
```

**② 启动时检查必填变量**

```js
const required = ["OPENAI_API_KEY", "OPENAI_BASE_URL"]
const missing = required.filter((k) => !process.env[k])
if (missing.length > 0) {
  console.error("缺少环境变量：" + missing.join(", "))
  process.exit(1)
}
```

**③ 新建 `.env.example`，只有键名**

```text
PORT=3000
OPENAI_API_KEY=
OPENAI_BASE_URL=https://api.example.com/v1
```

## 这个文件夹里绝不能出现的东西

```text
❌ 真实 key 的任何副本（哪怕改名成 key.txt）
❌ 打包好的镜像 tar 文件（几百 MB，而且可能含 key）
❌ 带真实密码的连接串截图
```

**笔记里要贴 key 的时候，一律写成 `sk-xxxx`。**

## 这一节要留下的证据

| 证据 | 证明什么 |
|---|---|
| `ls -a /app` 没有 `.env` | 文件没进镜像 |
| `grep -rn 'sk-' /app` 输出 `clean` | 镜像里搜不到密钥 |
| `od -c` 看到（或看不到）`\r` | 换行符是 LF |
| `docker inspect .Config.Env` 有 key | 密钥只活在运行时 |
| `Exited (1)` + "缺少环境变量" | fail fast 生效了 |
