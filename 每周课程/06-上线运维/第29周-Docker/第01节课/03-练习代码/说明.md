## 本节课你要建什么

```text

└── docker-lab/              ← 你自己建

```

**`docker-lab/` 里不放代码。** 今天所有实验都是敲命令，不写文件。

## 为什么单独建一个 `docker-lab`

因为这一周会反复做这几件事：

```text
删容器
删镜像
在容器里乱建文件
把容器搞崩
```

**这些操作要有一个固定的"作案现场"。** 后面第 2—7 节会往这个目录里加 `Dockerfile`、`.dockerignore`、`compose.yaml` 的**草稿**。

**正式的那一份，最后会放进你 `chat-app` 的副本里**（第 2 节会告诉你在哪建副本）。

## `命令记录.md` 怎么用

每敲一条命令，把「命令 + 输出」成对贴进去，像这样：

```text
$ docker run hello-world
Unable to find image 'hello-world:latest' locally
...
Hello from Docker!
```

**贴真实输出，不要贴"应该看到"的那份。** 你机器上的容器 ID、镜像大小、时间都会和课件不一样，那才对。

## 这一课的实验清单

| 实验 | 要留下什么 |
|---|---|
| `docker version` | Client 和 Server 两段的版本号 |
| `docker info` | `Registry Mirrors` 那几行（没有就写"没有"） |
| `docker run hello-world` | 完整输出 |
| `docker ps` / `docker ps -a` | 两张表（第二张要有内容） |
| `docker images` | 镜像列表 |
| `docker run -it ubuntu bash` | 容器里 `node -v` 报错那一行 |
| `docker system df` | 那张四行的表 |
