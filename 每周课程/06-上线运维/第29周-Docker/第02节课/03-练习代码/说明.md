# 03-练习代码

**这个文件夹故意不留代码。** 你要自己复制一份项目进来。

---

## 本节课你要建什么

```text
03-练习代码/
└── chat-app-docker/           ← 你自己建，从 chat-app 复制过来
    ├── package.json
    ├── package-lock.json
    ├── server.js              ← 你的入口文件，名字可能不同
    ├── .env                   ← 复制过来，但绝不进镜像
    ├── public/
    ├── data/
    ├── .dockerignore          ← 你手写
    └── Dockerfile             ← 你手写
```

## 复制哪些，不复制哪些

```text
✅ server.js / src/ / public/ / package.json / package-lock.json
✅ data/          （本地测试用，但写进 .dockerignore）
✅ .env           （本地测试用，但绝不能进镜像）

❌ node_modules/  （容器里重新装，你 Windows 的包在 Linux 里用不了）
❌ .git/          （几百 MB，镜像里不需要）
```

## 为什么要在副本里做

这一周对 `chat-app-docker/` 做的操作包括：

```text
反复 build 失败十几次
故意把 .env 打进镜像
第 5 节会删数据、删容器
第 7 节会删镜像
```

**在正式项目里做，你的作业就没了。**

## 检验自己有没有真学会

- 为什么 `COPY package*.json ./` 要单独一行？
- 改一行 `server.js`，哪一层会重跑？为什么？
- `.dockerignore` 漏了 `node_modules` 会怎样？
- 容器里 `Cannot find module` 一般是什么原因？

**四题都答得出来再往下走。** 第 3 节开始就假设你的镜像已经能跑。
