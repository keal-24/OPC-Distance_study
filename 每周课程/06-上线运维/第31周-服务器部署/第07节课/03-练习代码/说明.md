# 03-练习代码

**这个文件夹故意留空，不放现成脚本。**

本节课要写两个东西，都放在这里（先写成本地文件，再提交进仓库）：

```text
03-练习代码/
├── deploy.sh      ← 你自己写，发布脚本
└── RUNBOOK.md     ← 你自己写，一页运维手册
```

**⚠️ `deploy.sh` 最终要放到项目仓库的根目录（`chat-app/deploy.sh`），
服务器上就是 `/srv/app/deploy.sh`。
放在课程仓库的 `03-练习代码/` 里只会变成一份"副本"，不会被服务器执行。**

## `deploy.sh` 要满足五条

```text
① 有 set -euo pipefail
② 先 cd 到 /srv/app
③ 记住当前 commit（回滚锚点）
④ 健康检查循环，不能只查一次
⑤ 失败要回滚，并 exit 1
```

## `deploy.sh` 里绝对不能有

```text
❌ 密码
❌ token
❌ 私钥
❌ .env 的值
```

**脚本只用 `git`、`npm`、`pm2`、`curl`，全都不需要密码。**

## `RUNBOOK.md` 至少要有六块

```text
① 这台机器的基本信息（IP、配置、目录、到期日）
② 五条最常用的命令
③ 网站打不开的八步表
④ 常见症状对照表
⑤ 回滚步骤（可直接复制）
⑥ "我绝对不能做的事"
```

## 一个血的教训，写在这里

```text
不要等到出事才写 RUNBOOK。
出事的时候你在慌，写不出来。
```

**现在写，因为你还记得每一条命令为什么这么敲。**
