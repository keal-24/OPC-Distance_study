# 03-练习代码

**这个文件夹故意留空，不放现成代码。**

本节课的成果在服务器上（一个常驻进程），这里只留一张"以后天天要看"的卡片：

```text
03-练习代码/
└── pm2-笔记.md     ← 你自己建
```

## pm2-笔记.md 里必须有

```text
应用名（chat-app）
启动命令（完整的那一条）
日志路径（out 和 error 两个）
save 和 startup 的状态
重启验证的结果
```

## 建议做成这种形式

```text
===== 我的服务 =====
名字：chat-app
入口：/srv/app/server.js
启动：cd /srv/app && pm2 start server.js --name chat-app
日志：/root/.pm2/logs/chat-app-out.log
      /root/.pm2/logs/chat-app-error.log

===== 每天三条 =====
pm2 list
pm2 logs chat-app --lines 50 --nostream
pm2 restart chat-app

===== 出事三条 =====
ss -lntp | grep 3000
pm2 describe chat-app | grep cwd
systemctl status pm2-root
```

**为什么要做成卡片：**

```text
凌晨两点网站挂了，你不会想翻课件找命令。
你会想打开一个文件，看到三条命令，照着敲。
```

## 这里绝对不能有

```text
❌ .env 的值
❌ 服务器密码
❌ 私钥
```

## 可选：一个恢复脚本

如果你愿意，可以写一个 `restore.sh`：

```text
#!/bin/bash
cd /srv/app || exit 1
pm2 delete chat-app 2>/dev/null
pm2 start server.js --name chat-app
pm2 save
pm2 list
```

**⚠️ 这个脚本只在你确认"代码和 .env 都在"的时候用。** 它不负责拉代码。
