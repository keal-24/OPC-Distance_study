# 03-练习代码

**这个文件夹故意留空，不放任何现成代码，也不放私钥。**

本节课的成果在你的电脑用户目录里，不在这个文件夹里：

```text
C:\Users\你\.ssh\
├── id_ed25519          私钥（600，永不外传）
├── id_ed25519.pub      公钥（可以给任何人）
├── config              别名配置
└── known_hosts         你连过的机器指纹
```

## 这个文件夹里要建什么

```text
03-练习代码/
└── ssh-笔记.md      ← 你自己建
```

`ssh-笔记.md` 里写这四样：

```text
① 我的别名：ssh 后面敲什么就能进去
② 验证命令：怎么证明"完全不靠密码也能进"
③ 验证密码被关的命令，以及它的输出
④ 被锁死时走哪三条路
```

## 绝对不能写进去的

```text
❌ 私钥内容（-----BEGIN OPENSSH PRIVATE KEY----- 那一段）
❌ root 密码
❌ 服务器的 authorized_keys 全文（里面是公钥，不算致命，但没必要）
```

**这个文件夹会被 `git add`。** 私钥进去一次，你所有装了这把公钥的机器都要换钥匙。

## 为什么这节课要单独记一份

因为第 214、215 节你要反复 SSH 上去。到时候你只想看一行：`ssh myserver`。

`NOTES.md` 是理解过程，`ssh-笔记.md` 是"以后每天用的那张卡片"。
