# 03-练习代码

**这个文件夹故意留空，不放现成代码。**

本节课要装的东西都在服务器上，不在这个文件夹里。这里只留一份**能复刻的记录**：

```text
03-练习代码/
└── 环境清单.md     ← 你自己建
```

## 环境清单里必须有

```text
系统版本（cat /etc/os-release）
CPU 架构（uname -m）
核数（nproc）
内存和 swap（free -h）
硬盘（df -h /）
git 版本
node 版本
npm 版本
nginx 版本
npm 源地址
swapon --show 的输出
```

**要求：抄真实输出，不要抄课件里的示例。**

因为课件的示例是 `v20.11.1`，你装的那天可能已经是 `v20.19.x`。**版本号一定会变，以你机器上的为准。**

## 为什么连版本号都要记

```text
① 换服务器时，照着这份清单装一遍，省一小时
② 出问题时，第一件事是"版本对不对"
③ 交给客户时，这就是"运行环境说明"
④ 半年后你回来，会想知道"当时用的什么"
```

