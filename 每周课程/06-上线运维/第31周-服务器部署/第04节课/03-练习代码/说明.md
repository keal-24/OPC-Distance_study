# 03-练习代码

**这个文件夹故意留空，不放现成代码，也不放 `.env`。**

本节课的代码在服务器上：`/srv/app`。这里只留一份"怎么复现"的记录：

```text
03-练习代码/
└── 上传记录.md     ← 你自己建
```

## 上传记录里必须写

```text
仓库地址（https://github.com/...）
用的是 public 还是 private
认证方式（无 / PAT / deploy key）
部署路径（/srv/app）
clone 时用的完整命令
git log -1 --oneline 的输出
.env 有哪几个变量名（只写名字，不写值）
.env 的权限
npm ci 的结果（added 多少包 / 用了多久）
有没有遇到 Killed
```

## 绝对不能写

```text
❌ .env 里的任何真实值
❌ PAT（token）
❌ 私钥
❌ 数据库密码
```

**PAT 和服务器密码一样，只存在你的密码管理器里。**

## 为什么连"变量名"都要记

因为半年后你不会记得这个项目需要哪几个环境变量。

```text
换服务器 → 打开上传记录 → 照着变量名建 .env → 十分钟搞定
不记      → 启动报错 → 一个个试 → 两小时
```

**变量名不是秘密，变量的值是秘密。** 这两者要分清楚。

## 可以顺手做的一件事

把 `.env.example` 复制一份到这里，改名 `env-模板-仅键名.md`，把值全部清空：

```text
PORT=
MODEL_API_KEY=
MODEL_BASE_URL=
MODEL_NAME=
DATABASE_URL=
```

**这样你手里永远有一份"这个项目需要什么"的清单，而里面没有一个字是秘密。**
