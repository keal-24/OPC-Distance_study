# 03-练习代码

**这个文件夹故意留空，不放现成配置。**

nginx 的配置必须放在 `/etc/nginx/`，不能放在课程仓库里（放了也不生效）。**但你可以在这里留一份"抄回来的"版本**，方便以后重建服务器。

```text
03-练习代码/
└── nginx-笔记.md     ← 你自己建
```

## nginx-笔记.md 里放什么

```text
① 完整的 server 块（从服务器上抄回来的）
② 三个文件路径（配置、软链接、日志）
③ 三条排查命令
④ 一次 502 的 error.log 原文
```

**建议写成这样：**

```text
===== 配置路径 =====
/etc/nginx/sites-available/chat-app
/etc/nginx/sites-enabled/chat-app  （软链接）

===== 日志 =====
/var/log/nginx/access.log
/var/log/nginx/error.log
journalctl -u nginx

===== 改完必做三步 =====
nginx -t
systemctl reload nginx
curl -I http://127.0.0.1

===== 出错先看 =====
nginx -T | grep -n "proxy_pass"
tail -20 /var/log/nginx/error.log
pm2 list
```

## 为什么不把配置直接放在这个文件夹里当"答案"

因为 **nginx 只读 `/etc/nginx/sites-enabled/` 下的东西**。

放在这里：
- 不会被加载
- 你会误以为"我配了"
- 换服务器时你还要手动复制

**所以这里的文件是"笔记"，不是"配置"。** 真正的配置在 `/etc/nginx/`。

## 这里绝对不能有

```text
❌ 任何 key
❌ 任何密码
```

（nginx 配置本身通常不含密钥，但如果你以后配了 basic auth，那个密码文件不要放这里。）
