# 03-练习代码

**这个文件夹故意留空，不放任何现成代码。**

本节课不写程序。你要在这里留一份**采购记录**，因为后面六节课每天都会用到里面的 IP 和端口。

```text
03-练习代码/
└── 采购记录.md      ← 你自己建，内容见 TASK.md 第 6.4 节
```

## 采购记录里必须有

```text
云厂商
实例名（建议改成 chat-app-prod）
公网 IP
地域
配置（2 核 2G / 40G）
系统镜像（Ubuntu 22.04 LTS）
带宽和月流量
月费
下单日期
到期日期
安全组默认开了哪些端口
```

## 采购记录里绝对不能有

```text
❌ root 密码
❌ 任何 API key
❌ 私钥内容
```

**这个文件夹以后会被你 `git add`。** 密码一旦进去，就跟着历史走到天荒地老。

**密码存在你自己的密码管理器里**（或者手写在一张纸上贴在显示器边上，比放进仓库安全）。

## 为什么连学习笔记都要单独一份采购记录

因为 `NOTES.md` 是给自己看的思考，`采购记录.md` 是给"三个月后的自己"看的**速查表**。

三个月后你不会记得那台机器的 IP，也不会记得到期日。你只会打开这个文件，看一眼，然后继续干活。
