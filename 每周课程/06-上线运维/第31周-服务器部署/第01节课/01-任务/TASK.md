# 第 1 步：服务器到底是什么（15 分钟）

## 1.1 一句大白话

> **一台永远开着、有公网 IP、放在机房里的电脑。没有显示器，没有键盘，你只能通过网络操作它。**

**"永远开着"是重点。** 你的笔记本合上盖子就断网，服务器不行 —— 它一关，所有用户的页面就打不开。

## 1.2 它和你的电脑差在哪

| | 你的电脑 | 服务器 |
|---|---|---|
| 开关机 | 随时关 | **不能随便关**（关了网站就挂） |
| IP | 每次重连都可能变（动态） | **固定公网 IP** |
| 系统 | Windows 11 | **几乎都是 Linux** |
| 操作方式 | 鼠标点 | **只能打命令**（SSH） |
| 谁在用 | 你一个 | 可能几十个人同时 |
| 出问题 | 重启一下 | **重启可能让所有人断线** |

**看到"只能打命令"别慌。**

你在 Git Bash 里用过的这些东西，服务器上一模一样能用：

```text
pwd        我在哪个目录
ls -la     这目录有什么
cd         进目录
mkdir      建目录
cat        看文件内容
```

**你已经在练了，只是没意识到。**

**不一样的地方只有一个：** Windows 的 `dir`、`type`、`copy` 在 Linux 上叫 `ls`、`cat`、`cp`。**课件里两个都会给。**

## 1.3 公网 IP 是什么

**大白话：这台机器在全世界的门牌号。**

```text
47.98.xx.xx
```

四段数字，每段 0—255。**全世界唯一**，不会重复。

**你的家用宽带也有一个公网 IP，但：**

```text
① 它通常是动态的，重启光猫就变
② 运营商一般不允许你对外提供网站服务（80 端口被封）
③ 你家停电，网站就没了
```

**所以必须租机房的机器。**

## 1.4 为什么服务器几乎都是 Linux

三个原因，一句话一个：

```text
① 免费。Windows Server 的授权费要单独买，一个月几十上百。
② 轻。2G 内存跑 Windows 会卡死，跑 Linux 还有富余。
③ 稳。Linux 可以连续跑几年不重启，这是它的本行。
```

**你要买的是 Ubuntu 22.04。** 这是 Linux 的一个发行版，也是全世界服务器上最常见的那一个。

**为什么是 22.04 而不是最新版：** 22.04 是 LTS（长期支持版），官方支持到 2027 年。**装它的教程最多，你卡住了能搜到答案。**

> 版本号会变。等你看到这份课件时可能已经有 24.04 LTS 了。**原则是选"LTS 版本"，具体号以云厂商镜像列表里的为准。**

## 1.5 一个必须接受的事实

**你没有图形界面。**

```text
没有桌面
没有开始菜单
没有文件管理器
没有"右键 → 新建文件夹"
```

**所有事都靠打字。** 这是这一周最大的门槛，也是唯一一次性的门槛 —— 过了这周，你会发现打字比点鼠标快。

# 第 2 步：三种产品，选错一个就白花钱（25 分钟）

## 2.1 云厂商卖给你三种东西

打开腾讯云或阿里云，搜"服务器"，你会看到一堆名字。**其实只有三种：**

```text
① 轻量应用服务器   ← 你要买的
② 云服务器 CVM / ECS
③ 虚拟主机（也叫"云虚拟主机"、"空间"）  ← 千万不能买
```

**名字很像，能力差很远。**

## 2.2 三种的对比

| | 轻量应用服务器 | 云服务器 CVM / ECS | 虚拟主机 |
|---|---|---|---|
| 你能登进去吗 | ✅ 能（SSH，root 权限） | ✅ 能（SSH，root 权限） | ❌ **不能** |
| 能跑 Node 吗 | ✅ 能 | ✅ 能 | ❌ **不能** |
| 能装 nginx 吗 | ✅ 能 | ✅ 能 | ❌ 不能，只能用厂商给的 |
| 价格 | **60—100 元/月** | 100 元/月起，还要另买带宽 | 10—30 元/月 |
| 配置方式 | 简单，套餐制 | 灵活，什么都能调 | 网页控制面板 |
| 适合谁 | **起步、小项目、学习** | 业务稳定后、要多台 | 只放静态 HTML 的老网站 |

**一句话：**

```text
轻量 = 简配版云服务器，够用、便宜、省事
CVM  = 全配版，什么都能调，也什么都要自己配
虚拟主机 = 只能放 php/html 的"托管空间"，不是服务器
```

## 2.3 逐行读这张表

| 行 | 为什么重要 |
|---|---|
| **能登进去吗** | 这一整周的核心就是"登进去打命令"。登不进去 = 这一周没法上 |
| **能跑 Node 吗** | `chat-app` 是 Node 程序，要 `node server.js`。虚拟主机不给你执行程序的环境 |
| **能装 nginx 吗** | 第 216 节要用 nginx 做反向代理。虚拟主机的 nginx 是厂商的，你改不了 |
| **价格** | 虚拟主机最便宜，但便宜的东西在这里等于"不能用" |
| **配置方式** | 轻量的套餐制 = 少犯错；CVM 的自由度 = 新手容易配错带宽和磁盘 |
| **适合谁** | 你现在是"一个人做一个产品"，选第一个 |

## 2.4 为什么起步买轻量

四个理由：

```text
① 便宜：同样 2 核 2G，轻量常常比 CVM 便宜三分之一
② 套餐制：CPU、内存、硬盘、带宽、流量一次给全，不用自己算
③ 自带防火墙页面：安全组在网页上点，比命令行配 iptables 友好
④ 出问题好重装：控制台一键重装系统，CVM 也能，但选项多容易选错
```

**什么时候该换 CVM：**

```text
① 需要挂第二块数据盘（大文件、备份）
② 需要和数据库、对象存储放同一个内网
③ 需要按秒计费、随时升降配
④ 一台机器扛不住了，要上负载均衡
```

**这四条你现在一条都不需要。** 等需要了再换，换的时候数据可以迁。

## 2.5 为什么绝对不能买虚拟主机

**因为虚拟主机卖的不是"一台机器"，是"机器上的一个文件夹"。**

你会遇到这些：

```text
① 没有 SSH，只有 FTP 和一个网页控制面板
② 没有 root 权限，装不了任何系统软件
③ 只能放静态文件，或者厂商预装好的 PHP
④ 端口不能自己开，80 之外一律不行
⑤ node 命令不存在，你连 npm 都跑不了
```

**症状长这样：**

```text
$ ssh root@47.98.xx.xx
ssh: connect to host 47.98.xx.xx port 22: Connection refused
```

**不是网络问题，是它根本没开 SSH。**

**规则：只要商品页上写着"虚拟主机""云虚拟主机""空间""建站主机"，直接关掉。**

> **怎么一眼认出来：** 虚拟主机的价格通常是"XX 元/年"，而且配置写的是"网页空间 1G、数据库 100M"。
> **服务器的价格是"XX 元/月"，配置写的是"2 核 2G、40G SSD"。**

# 第 3 步：算钱——为什么不是 8 核 16G（20 分钟）

## 3.1 先把价格摆出来

**下面是常见档位（价格会变，以官网当时为准）：**

| 配置 | 大概价格 | 能撑多少人 | 你该买吗 |
|---|---|---|---|
| 2 核 2G / 40G | **60—100 元/月** | 几十个用户 | ✅ **买这个** |
| 2 核 4G / 60G | 100—200 元/月 | 一两百个 | 暂时不用 |
| 4 核 8G / 80G | 300—500 元/月 | 上千 | 不用 |
| 8 核 16G / 100G+ | 800—1500 元/月 | 几千 | ❌ **绝对不用** |

**算一下差多少：**

```text
2 核 2G    × 12 个月 = 约 960 元/年
8 核 16G   × 12 个月 = 约 12000 元/年
```

**差了 11000 块。** 这 11000 块够你调多少次模型？

## 3.2 为什么 2 核 2G 就够

**因为你的程序不干重活。**

`chat-app` 收到一个请求之后做什么？

```text
① 解析 JSON                → 几毫秒
② 查一下数据库/文件          → 十几毫秒
③ 把问题转发给模型 API       → 等 2—10 秒（但你的 CPU 在睡觉）
④ 把结果转发回浏览器         → 几毫秒
```

**第 ③ 步是整个流程里最慢的，也是最不占 CPU 的。**

**因为真正算的那个东西不在你的服务器上，在模型厂商的机房里。**

**你的服务器全程只做一件事：转发。** 转发这件事，2 核足够。

## 3.3 逐行读这张"钱花在哪"的表

| 项目 | 单价 | 用量 | 月成本 |
|---|---|---|---|
| 服务器（2 核 2G） | 80 元/月 | 1 台 | 80 元 |
| 系统盘 40G | 含在套餐里 | — | 0 元 |
| 带宽 3Mbps + 月流量包 | 含在套餐里 | — | 0 元 |
| 域名 | 80 元/年 | 1 个 | 约 7 元 |
| SSL 证书 | 免费（Let's Encrypt） | — | 0 元 |
| **模型调用** | 按 token | 看用量 | **几十到几百元** |
| **合计（不含模型）** | | | **约 87 元/月** |

| 行 | 你要看懂什么 |
|---|---|
| 服务器 | 这是唯一"必须花"的固定成本 |
| 系统盘 | 40G 装系统 + 代码 + 日志，够用一整年 |
| 带宽 | **轻量给的是"带宽 + 月流量包"，超了要另外扣钱** |
| 域名 | 第 32 周才买，现在可以 0 |
| 证书 | 免费，别买几百块的"SSL 证书" |
| **模型调用** | **这才是大头**。你省服务器钱是对的，因为钱应该花在这里 |

## 3.4 带宽和流量，这里有个坑

**轻量应用服务器通常是这样卖的：**

```text
带宽：3 Mbps（峰值）
流量：200 GB / 月（套餐内）
超出：按 0.8 元/GB 左右另外收
```

**这两个数不是一回事：**

```text
带宽 = 水管有多粗（同时能跑多快）
流量 = 这个月一共用了多少水
```

**对 `chat-app` 来说，流量很小**（传的是文字，不是图片视频）。200GB 一个月，几十个用户根本用不完。

> **但如果你的页面里有大图、有大文件下载，流量会涨得很快。** 到时候不是换服务器，是把图片放到对象存储去。

**这一节要记住的就一句：**

```text
钱要花在模型调用上，不是花在核数上。
```

## 3.5 什么时候才该升级

**不要凭感觉升级，看这三个信号：**

```text
① free -h 里 available 长期低于 200M
② top 里 load average 长期大于核数（2 核就是大于 2）
③ 用户说"慢"，而 nginx 日志里请求耗时不高（说明不是网络，是 CPU）
```

**三个信号都没出现，就不要加钱。**

**真实情况：** 你的瓶颈大概率是模型 API 的响应速度，不是这台 2 核机器。

# 第 4 步：备案这条硬门槛（20 分钟）

## 4.1 一句话

> **服务器在中国大陆，域名必须备案。没有例外，没有捷径，没有"我朋友没备也用了"。**

**注意：必须备案的是"域名"，不是"IP"。**

```text
用 IP 访问（http://47.98.xx.xx）  → 这一周的做法，不需要备案
用域名访问（http://your-domain.com）→ 必须备案
```

**这就是为什么这一周全程用 IP。** 你可以在等备案的时候就把技术跑通。

## 4.2 什么时候要备案

| 服务器位置 | 用 IP 访问 | 用域名访问 | 说明 |
|---|---|---|---|
| 中国大陆 | 可以 | **必须备案** | 腾讯云/阿里云/华为云都一样 |
| 中国香港 | 可以 | 不用备案 | 国内访问稍慢（几十毫秒），能接受 |
| 新加坡/日本/美国 | 可以 | 不用备案 | 国内访问明显慢，客户会抱怨 |

**"稍慢"是什么概念：**

```text
大陆服务器    国内访问  10—40 毫秒
香港服务器    国内访问  40—80 毫秒
美国服务器    国内访问  150—300 毫秒
```

**150 毫秒以上，用户点一下会以为没点上。** 所以给国内客户做东西，服务器要在国内或香港。

## 4.3 备案要多久、要什么

**时间：7 到 20 个工作日。**

**"工作日"是不含周末的。** 20 个工作日 = 将近一个月。

**要准备的材料：**

```text
① 身份证（正反面照片）
② 手机号（要能接验证码）
③ 已实名认证的域名（域名注册后要做实名，1—3 天）
④ 服务器的"备案服务码"（在云控制台申请，免费）
⑤ 网站名称（不能写"测试""博客""论坛"这类，会被驳回）
⑥ 网站内容说明（一句话：做什么的、给谁用）
```

**最常见的驳回原因：**

```text
① 网站名称不合规（含"中国""国家""新闻"等字样）
② 域名没实名 / 实名刚做完还没同步
③ 身份证照片反光、模糊
④ 手机号不是本人实名
```

**被驳回不收费，改了重新提交。** 但每次都要重新排队。

## 4.4 最省事的路径（照这个顺序）

```text
① 买域名（第 32 周做，现在可以先不买）
② 买国内轻量服务器（这节课做）
③ 立刻提交备案（用服务器给的备案服务码）
④ 备案期间：用 IP 访问 + 本地开发，技术上全部跑通
⑤ 备案下来后，把域名 A 记录指向这台机器
```

**为什么顺序不能反：**

```text
❌ 先买服务器，不提交备案 → 机器在计费，网站不能对外开，纯亏
❌ 先备案域名，没有服务器 → 备案要填服务器信息，提交不了
✅ 服务器 + 域名都有了，立刻提交 → 等待期正好用来做技术
```

## 4.5 备案期间不能做什么

**这条要讲清楚，不然你会白干：**

```text
❌ 不能用域名访问（会被拦，显示"该网站未备案"）
❌ 不能把域名解析到大陆服务器对外提供页面
✅ 可以用 IP 访问（访问量小、自己测试，没人管）
✅ 可以在本地 3000 端口开发
✅ 可以用香港服务器挂域名先给客户看
```

**所以这一周你完全不受影响。** 你要的是 IP 能打开，不是域名。

## 4.6 一个反直觉的点

**备案是按"主体 + 域名"备的，不是按服务器。**

```text
一个人可以备多个域名
一个域名只能备在一个主体下
换了服务器不用重新备案（同一个云厂商内）
跨云厂商要变更备案
```

**子域名不用单独备案。** 主域名 `your-domain.com` 备过了，`api.your-domain.com`、`admin.your-domain.com` 都能直接用。

# 第 5 步：下单（25 分钟）

## 5.1 打开购买页

**操作：**

1. 登录腾讯云或阿里云（**域名和服务器建议在同一家买**，后面备案、解析、续费都在一个后台）；
2. 搜索"轻量应用服务器"；
3. 点"立即购买"。

**⚠️ 别点错：** 页面上会同时推"云服务器 CVM 特惠"和"虚拟主机"。看清商品名里有没有"轻量应用服务器"六个字。

## 5.2 选地域

**这一项决定了访问速度，也决定了要不要备案。**

| 地域 | 什么时候选 |
|---|---|
| 上海 / 北京 / 广州 | 客户主要在中国大陆 → **要备案** |
| 中国香港 | 想立刻上线、不想等备案 → 不用备案 |
| 新加坡 / 硅谷 | ❌ 给国内客户做，不选 |

**原则：离你的客户越近越好。**

**给自己做、给国内小客户做，选国内（上海/广州）。** 备案麻烦一次，后面一直快。

## 5.3 选镜像（这一项最容易错）

**"镜像"是什么：预装好的操作系统。就像买电脑时选的"预装 Windows 还是 Linux"。**

**操作：**

1. 找到"镜像"或"系统盘"这一栏；
2. 选 **"系统镜像"**（不是"应用镜像"）；
3. 选 **Ubuntu**；
4. 选 **22.04 LTS 64 位**。

**三种镜像的区别：**

| 类型 | 是什么 | 你该选吗 |
|---|---|---|
| 系统镜像 | 干净的系统，什么都没有 | ✅ **选这个** |
| 应用镜像 | 预装了宝塔/LNMP/WordPress | ❌ 不要，会和你手动装的环境打架 |
| 自定义镜像 | 你自己之前做的快照 | 现在没有 |

**为什么不选"应用镜像"里的宝塔面板：**

```text
① 它会在 8888 端口开一个网页管理面板，等于多开一个门
② 它装的 nginx / php 路径和你手动装的不一样，教程对不上
③ 出问题你不知道是面板干的还是你干的
```

**这一周你要学会"手动装"。** 学会了再用面板，才知道面板帮你做了什么。

**⚠️ 绝对不要选 Windows：**

```text
① 要额外付授权费（一个月几十上百）
② 2G 内存跑 Windows 会卡到你想砸键盘
③ 你后面所有命令都是 Linux 命令
```

## 5.4 选配置

**操作：**

1. CPU / 内存：**2 核 2G**；
2. 系统盘：**40G SSD**（默认就是，不用改）；
3. 带宽：套餐给多少就多少（通常 3—5 Mbps）；
4. 时长：**先买 1 个月**。

**为什么先买 1 个月：**

```text
① 你还没确认这台机器顺不顺手（地域、镜像、速度）
② 一个月后你就知道自己要不要换
③ 买一年便宜，但买错了退不了
```

**什么时候买一年：** 等你把第 217 节跑通、确认这台机器要长期用，再续一年。**续费通常比首购贵，注意看价格。**

## 5.5 设置 root 密码

**"root"是什么：Linux 里的最高权限账号，相当于 Windows 的"管理员"，但权力更大 —— 它能删掉整个系统。**

**操作：**

1. 找到"登录凭证"或"root 密码"；
2. 选"自定义密码"；
3. 设一个密码。

**密码要求（各家略有不同，以页面提示为准）：**

```text
8—30 位
必须含大写字母、小写字母、数字
有的还要求含特殊字符
不能和用户名相同
```

**怎么设才好记又安全：**

```text
✅ 一句你记得住的话 + 数字 + 符号
   例如：WoYaoShangXian2026!
❌ 12345678
❌ password
❌ qwerty123
❌ 你的生日
```

**⚠️ 立刻记下来。** 记在你自己的密码管理器里，**不要写进课程仓库，不要写进 `NOTES.md`**。

**为什么不能写进仓库：** 你 push 一下，全世界都知道了（公开仓库）。即使是私有仓库，历史里的东西也删不干净。

## 5.6 确认订单页

**下单前，逐项核对：**

| 项目 | 应该是 | 为什么 |
|---|---|---|
| 商品名 | 轻量应用服务器 | 不是 CVM、不是虚拟主机 |
| 地域 | 上海/广州/北京 或 香港 | 离客户近 |
| 镜像 | Ubuntu 22.04 LTS | 不是 Windows、不是宝塔 |
| 配置 | 2 核 2G | 不是 8 核 16G |
| 系统盘 | 40G | 默认值 |
| 时长 | 1 个月 | 先试 |
| 自动续费 | **先关掉** | 见下面 |

**为什么先关自动续费：**

```text
① 你可能一个月后就不用了（学习项目）
② 自动续费是按"原价"扣，比首购贵
③ 忘了关，几个月后才发现被扣钱
```

**⚠️ 但也别忘到期。** 到期不续费，云厂商会在几天后**释放实例，数据全没**。

**操作：** 下单完成后，立刻在手机日历里加一条提醒：**到期前 3 天**。

## 5.7 付钱，等开机

**付完之后：**

```text
① 一般 10—60 秒创建完成
② 控制台会显示"运行中"
③ 你会看到公网 IP，形如 47.98.xx.xx
```

**把 IP 抄下来。**

**这就是你未来一个月要反复输入的那串数字。**

## 6.1 第一件：确认实例状态

**操作：**

1. 进控制台 → "轻量应用服务器" → 实例列表；
2. 看状态列。

**应该看到：**


**逐列读：**

| 列 | 意思 | 不对怎么办 |
|---|---|---|
| 实例名 | 系统给的名字，可以改 | 改成 `chat-app-prod` 更好认 |
| 状态 | `运行中` 才是好的 | `启动中` 等一会；`已关机` 点开机 |
| 地域 | 你选的机房位置 | 选错了只能退/重买 |
| 公网 IP | **唯一能给你的信息** | 没有 IP 说明没分配完，等 |
| 配置 | 2 核 2G | 不对说明买错了 |

**建议顺手做的两件事：**

```text

② 加标签/备注：写清用途和到期日
```

**为什么：** 三个月后你有三台机器，不改名你根本分不清哪台是哪台。

## 6.2 第二件：看清楚安全组（防火墙）

**这是这一周最重要的一个页面，没有之一。**

**操作：**

1. 点进实例详情；
2. 找"防火墙"或"安全组"标签页；
3. 看已有的规则。

**你可能会看到两种结果：**

**情况 A —— 只有 22：**

```text
方向    协议    端口      来源          备注
入站    TCP     22        0.0.0.0/0     SSH
```

**情况 B —— 有 22、80、443：**

```text
方向    协议    端口      来源          备注
入站    TCP     22        0.0.0.0/0     SSH
入站    TCP     80        0.0.0.0/0     HTTP
入站    TCP     443       0.0.0.0/0     HTTPS
```

**⚠️ 不同厂商、不同套餐的默认规则不一样，你必须自己去看，不能假设。**

**但有一点是确定的：3000 和 3306 默认一定没开，你也永远不要开。**

## 6.3 逐行读这张"该开哪些端口"的表

| 端口 | 干什么 | 开不开 | 原因 |
|---|---|---|---|
| 22 | SSH 远程登录 | ✅ **必开** | 不开你就进不去 |
| 80 | HTTP | ✅ **必开** | 用户访问的入口 |
| 443 | HTTPS | ✅ 第 32 周开 | 上证书后要用 |
| 3000 | 你的 Node 程序 | ❌ **不对公网开** | 只让 Nginx 从本机转发 |
| 3306 | MySQL | ❌ **绝对不开** | 被爆破的头号目标 |
| 5432 | PostgreSQL | ❌ **绝对不开** | 同上 |
| 6379 | Redis | ❌ **绝对不开** | 未授权访问漏洞重灾区 |
| 8888 | 宝塔面板 | ❌ 不用宝塔 | 多一个门就多一个风险 |

**为什么 3000 不能开：**

```text
开了 3000 = 别人可以绕过 Nginx 直接打你的程序
            Nginx 能帮你做的事（限流、封 IP、加头、上 HTTPS）全部失效
            而且你的程序会直接暴露在扫描器面前
```

**为什么数据库端口绝对不能开：**

```text
一个开放 3306 的服务器，通常几小时内就会被扫到。
然后就是字典爆破，弱密码几分钟就破。
破进去之后：拖库、勒索、装挖矿程序。
```

**这不是危言耸听。** 你可以在搜索引擎里搜"Redis 未授权访问"，看看有多少人中招。

```markdown
| 配置 | 2 核 2G / 40G |
```

## 6.5 第四件：试一下 22 端口通不通

**这一步不登录，只确认"门开着"。**

**操作：**

1. 打开 Git Bash（Windows 开始菜单搜 `Git Bash`）；
2. 输入下面这行，把 IP 换成你的。

```bash
ssh -o ConnectTimeout=8 root@47.98.xx.xx
```

**应该看到：**

```text
The authenticity of host '47.98.xx.xx' can't be established.
ED25519 key fingerprint is SHA256:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.
This key is not known by any of the hosts you have connected to.
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

**看到这一行，说明 22 端口通了，机器活着。**

**然后直接按 `Ctrl + C` 退出。** 这节课不登录，下节课正式来。

**如果你看到的是：**

```text
ssh: connect to host 47.98.xx.xx port 22: Connection timed out
```

**说明 22 端口不通。** 常见原因：

| 原因 | 怎么查 |
|---|---|
| 实例还在启动 | 控制台等 1 分钟再试 |
| 安全组没放通 22 | 去防火墙页面看 |
| IP 抄错了 | 一个数字一个数字对 |
| 你公司的网络封了 22 | 换手机热点试 |

**如果你看到的是：**

```text
ssh: connect to host 47.98.xx.xx port 22: Connection refused
```

**"refused"和"timed out"不一样：**

```text
timed out  = 门根本找不到（防火墙挡了 / IP 错）
refused    = 门找到了，但里面没人开（sshd 没启动 / 端口不对）
```

**这个区别在第 217 节的排查里会反复用到。**

## 6.6 为什么这节课不登录

**因为登录有两件事必须一次做对：**

```text
① 第一次的 yes（要输全三个字母，不是 y）
② 输密码时屏幕不显示（新手会以为键盘坏了）
```

**这两件事值得单独一节课。** 而且下节课还要配密钥，一次讲完更连贯。

**今天你只需要确认一件事：这台机器是活的，22 端口是通的。**

# 第 8 步：故意犯六个错（25 分钟）

**⚠️ 这一节的错误，前两个会让你白花钱。看的时候别动手，看完再决定。**

## 错误 1：买了虚拟主机

**操作：**

去搜"云虚拟主机"，看商品页，加购物车（**别付款**）。

**会怎样：**

商品页上写的是：

```text
网页空间：1 GB
数据库：100 MB
支持：HTML / PHP
价格：199 元/年
```

**你会找不到这些东西：**

```text
❌ 没有"公网 IP"这一栏（它给你的是共享 IP）
❌ 没有"root 密码"
❌ 没有"SSH 登录"
❌ 没有"安全组"
```

**为什么：**

虚拟主机卖的是"一台服务器上的一块空间"，几十个客户共用同一个系统。

**它不给你 root，因为给了你就能看到别人的文件。**

**怎么修：**

```text
退掉 / 不付款，回去买"轻量应用服务器"。
```

**判断口诀：**

```text
看到"空间""建站""元/年" → 不是服务器
看到"2 核 2G""公网 IP""元/月" → 是服务器
```

## 错误 2：镜像选了 Windows

**操作：**

下单时，镜像那一栏选 `Windows Server 2022`。

**会怎样：**

订单页的价格会**突然变高**：

```text
Ubuntu 22.04     80 元/月
Windows Server   130 元/月     ← 多出来的 50 是授权费
```

**然后你登进去会看到：**

```text
Microsoft Windows [Version 10.0.20348]
(c) Microsoft Corporation. All rights reserved.

C:\Users\Administrator>
```

**为什么这是错：**

```text
① 每月多付几十块授权费
② 2G 内存跑 Windows，开个远程桌面就占满了
③ 后面六节课所有命令都是 Linux 的（apt、systemctl、nginx -t）
   你在 PowerShell 里一条都跑不了
```

**怎么修：**

控制台 → 实例 → **重装系统** → 选 Ubuntu 22.04。

**⚠️ 重装会清空系统盘。** 刚买的机器没数据，随便重装；有数据了就晚了。

## 错误 3：一上来买 8 核 16G

**操作：** 不用真买，算一下就行。

**会怎样：**

```text
8 核 16G / 100G，约 1000 元/月
一年 = 12000 元

而你的 chat-app：
  日均请求 200 次
  每次占用 CPU 约 3 毫秒
  一天总共用了 0.6 秒的 CPU
```

**你的 CPU 利用率大概是 0.001%。**

**为什么：**

因为瓶颈不在你这边。用户等的那 3 秒，是你的服务器在**等模型 API 返回**，不是在算。

**怎么修：**

```text
退掉，换成 2 核 2G。
把省下的钱记一笔，写进采购记录："每月省 920 元，可用于模型调用"。
```

## 错误 4：给国内客户买了美国服务器

**操作：** 地域选"硅谷"。

**会怎样：**

第 217 节你会看到：页面能打开，但每次点都要等一两秒。

**测一下延迟就有感觉：**

```bash
ping 47.98.xx.xx
```

**美国机房：**

```text
Reply from 47.98.xx.xx: bytes=32 time=213ms TTL=48
Reply from 47.98.xx.xx: bytes=32 time=208ms TTL=48
Reply from 47.98.xx.xx: bytes=32 time=221ms TTL=48
```

**上海机房：**

```text
Reply from 47.98.xx.xx: bytes=32 time=24ms TTL=52
Reply from 47.98.xx.xx: bytes=32 time=22ms TTL=52
Reply from 47.98.xx.xx: bytes=32 time=26ms TTL=52
```

**逐行读：**

| 字段 | 意思 |
|---|---|
| `bytes=32` | 每次发的测试包 32 字节 |
| `time=213ms` | **一个来回用了 213 毫秒**（这个数最重要） |
| `TTL=48` | 经过了多少跳，能粗略看出距离 |

**为什么 213ms 很糟：**

```text
一个页面要加载 10 个资源 → 2 秒多
每个接口要多等 200ms → 用户觉得"卡"
```

**而且你的程序还要调模型 API（本身就要 2—3 秒）。** 再加 200ms 的每一跳，体验会明显变差。

**怎么修：**

只能退掉重买（大部分云厂商支持 5 天内无理由退）。**所以地域一定要在下单前想清楚。**

## 错误 5：以为 `ping` 不通就是机器坏了

**操作：**

```bash
ping 47.98.xx.xx
```

**可能看到：**

```text
Pinging 47.98.xx.xx with 32 bytes of data:
Request timed out.
Request timed out.
Request timed out.
Request timed out.

Ping statistics for 47.98.xx.xx:
    Packets: Sent = 4, Received = 0, Lost = 4 (100% loss),
```

**别急着重装系统。**

**为什么：**

很多云厂商**默认禁 ICMP**（就是 `ping` 用的协议）。因为 ping 会被用来做攻击探测。

**所以：**

```text
ping 不通 ≠ 机器坏了
ping 通了 = 机器一定活着
```

**怎么判断机器到底活没活：**

```bash
ssh -o ConnectTimeout=8 root@47.98.xx.xx
```

**能看到 `Are you sure you want to continue connecting` 或 `password:`，就是活的。**

**这也是第 217 节"八步排查法"里第 2 步为什么不能只靠 ping 的原因。**

## 错误 6：密码设成 `123456`，两天后被爆破

**操作：**

密码设成 `123456`（或 `admin123`、`qwerty`）。

**会怎样：**

你的机器会在**几小时内**被扫到。日志里会出现：

```text
Failed password for root from 45.xx.xx.xx port 51234 ssh2
Failed password for root from 45.xx.xx.xx port 51235 ssh2
Failed password for root from 45.xx.xx.xx port 51236 ssh2
...（一秒钟几十条）
```

**密码被猜中之后：**

```text
① 你的模型 API key 被读走（.env 就在那儿）
② 机器被装挖矿程序，CPU 100%，账单暴涨
③ 你的 GitHub 凭据可能被偷
④ 服务器被当成跳板去攻击别人
```

**看自己的机器有没有被爆破：**

```bash
grep "Failed password" /var/log/auth.log | wc -l
```

**新机器放公网一天，这个数字通常是几百到几千。**

**为什么：**

因为公网上的扫描器是**全自动、7×24 小时**的。它们不在乎你是谁，只是把所有 IP 段扫一遍。

**怎么修：**

```text
① 密码改成 12 位以上，含大小写+数字+符号（现在就去改）
② 下节课配密钥登录，然后关掉密码登录
③ 关掉密码登录之后，这种日志会瞬间归零
```

**这就是第 212 节存在的理由。**

# 附：常见问题速查

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 控制台没有"公网 IP" | 实例还在创建 / 买的是虚拟主机 | 等 1 分钟；确认商品名 |
| `ssh` 提示 `Connection timed out` | 22 没开 / IP 错 / 机器没启动 | 查安全组、核对 IP、看实例状态 |
| `ssh` 提示 `Connection refused` | sshd 没跑 / 端口不是 22 | 控制台 VNC 进去看 `systemctl status ssh` |
| `ping` 100% loss | 云厂商默认禁 ICMP | 用 `ssh` 判断，别用 ping |
| 付款后价格比页面贵 | 选了 Windows 镜像 | 重装成 Ubuntu |
| 找不到 root 密码在哪设 | 下单页折叠了"登录凭证" | 找"更多设置"或下单后"重置密码" |
| 忘了密码 | 没办法找回，只能重置 | 控制台 → 重置密码 → 重启 |
| 提交备案被驳回 | 网站名称不合规 / 照片模糊 | 改名、重拍、重新提交 |
| 备案要等很久 | 7—20 个工作日是正常的 | 期间用 IP 访问，技术照跑 |
| 到期忘了续费 | 没设提醒 | 数据被释放前有几天宽限期，赶紧续 |
| 想换地域 | 买完不能改 | 退掉重买（看清退款政策） |
| 不知道买 1 个月还是 1 年 | 首次建议 1 个月 | 跑通第 217 节再续一年 |
| 账单里多出"流量费" | 超出套餐流量 | 控制台看流量用量，图片别放服务器 |
| 收到"漏洞扫描"短信 | 云厂商自动扫到开放端口 | 关掉 3000 / 3306，只留 22/80/443 |
