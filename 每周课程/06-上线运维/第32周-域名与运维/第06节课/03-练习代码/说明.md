# 03-练习代码

**这个文件夹里不放代码。你要放的是"三张表"。**

这一节课的产出是文档，不是程序。

## 你要在这里建三个文件

```text
03-练习代码/
├── 日志速查.md      ← 日志位置 + 五条命令 + 真实输出
├── 成本表.md        ← 单价 × 用量 = 月成本，含模型费公式
└── 续费清单.md      ← 项目 / 到期日 / 价格 / 提前提醒
```

## `日志速查.md` 的最低要求

```text
五份日志的路径
一行 access.log 的逐字段拆解
五条统计命令各自的真实输出（不是"成功了"）
我磁盘用了多少、谁占得最多
```

**"真实输出"是把终端里的字粘过来。** 这一份是你以后出事时第一个打开的文件。

## `成本表.md` 的最低要求

```text
固定成本：每一行都要有"单价 × 用量"
模型成本：公式 + 你的算例（代入你自己的数字）
三笔报价：开发费 / 服务器域名 / 模型费，各写清谁付
```

**⚠️ 不要抄课件里的 80 元、10.2 元。** 用你自己的真实用量算。

## `续费清单.md` 的最低要求

```text
至少四项：域名、服务器、证书、模型余额
每项都有到期日和"提前几天提醒"
标清哪些是自动续费、哪些要手动
```
