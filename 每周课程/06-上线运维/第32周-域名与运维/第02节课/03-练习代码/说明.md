# 03-练习代码

**这个文件夹里不放代码。你要放的是"配置证据"。**

这一节课的操作都在**域名商后台**、**云厂商备案系统**和**服务器的 Nginx 配置**里。

## 你要在这里建两个文件

```text
03-练习代码/
├── 备案判断表.md            ← 你的项目要不要备案、依据、要做什么
└── server_name-修改记录.md  ← 改前 / 改后的配置 + nginx -t 输出
```

## `server_name-修改记录.md` 里写什么

```text
1. 改之前 server_name 那一行是什么（原样复制）
2. 改之后是什么
3. nginx -t 的完整输出
4. curl -I http://your-domain.com 的状态码
5. curl -I -H "Host: 不存在的域名" 的结果
```

**"原样复制"的意思是连分号一起复制。** 少一个分号就是一次线上事故。

## `备案判断表.md` 里写什么

按课件 1.9 的模板填。**重点不是"要不要备案"，而是"依据是什么"。**

答"要备案"但说不出为什么，等于没懂。
