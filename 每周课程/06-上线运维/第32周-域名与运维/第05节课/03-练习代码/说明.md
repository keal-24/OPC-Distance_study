# 03-练习代码

**这个文件夹里不放应用代码。你要放的是"配置"和"演练记录"。**

这一节课的操作主要在 **UptimeRobot 网页**、**云厂商控制台**和**你的邮箱**里。

## 你要在这里建两个文件

```text
03-练习代码/
├── 监控配置.md        ← 监控项、类型、间隔、关键词、阈值
└── 告警演练记录.md    ← 停服务 → 收到 DOWN → 恢复 → 收到 UP 的时间线
```

## `监控配置.md` 里写什么

```text
1. UptimeRobot 里每个监控的名称 / 类型 / URL / 间隔 / 关键词
2. 免费版的限制（监控数量、最短间隔）
3. 云监控的三个阈值（CPU / 内存 / 磁盘）
4. Sentry 有没有接入，dsn 放在哪
```

## `告警演练记录.md` 里写什么

**这一份是本节课的核心交付物。**

```text
时间线表格：停服务 / curl 看到 502 / 收到 DOWN / 恢复 / 收到 UP
DOWN 邮件里的 Reason
从故障到收到告警用了几分钟
发现的问题（比如邮件进了垃圾箱）
```

**"用了几分钟"这个数字很重要。** 它决定了你能对客户承诺什么。
