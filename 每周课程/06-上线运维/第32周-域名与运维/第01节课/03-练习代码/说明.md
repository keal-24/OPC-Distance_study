# 03-练习代码

**这个文件夹里不放代码。你要放的是"证据"。**

这一节课的所有操作都在**域名商的后台**和**你的终端**里，没有需要写的程序。

## 你要在这里建两个文件

```text
03-练习代码/
├── 解析记录截图.png      ← 域名后台的记录列表截图
└── 解析验证.md           ← 三个命令的真实输出 + 你的判断
```

## 截图怎么截

1. 打开域名后台的「解析」页面；
2. 让三条记录（`@` / `www` / `api`）都在画面里；
3. 截图；
4. **IP 可以打码**，但自己本地留一份完整的（存在别处）。

**为什么要存这张图：**

改记录之前不截图，改完就永远不知道原来是什么。出事的时候，你没有"改回去"的依据。

## `解析验证.md` 里写什么

```text
1. ping 的完整输出
2. nslookup（本地 DNS）的完整输出
3. nslookup（8.8.8.8）的完整输出
4. curl -I 的状态码
5. 你的结论：解析是否生效？有没有遇到缓存？
```

**"完整输出"的意思是把终端里的字粘过来，不是写"成功了"。**

## 检验自己有没有真学会

不看课件回答：

- `api.your-domain.com` 里，哪一层是你花钱买的？
- 为什么主机记录填 `api.your-domain.com` 会失败？
- `ping` 超时但方括号里有 IP，为什么不能判定"网站挂了"？
- 改完解析，怎么判断"是域名商没同步"还是"我本地有缓存"？
- 换服务器时，为什么要提前两天把 TTL 调短？
