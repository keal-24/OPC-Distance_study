# 03-练习代码

**这个文件夹里不放代码。你要放的是"证书证据"。**

这一节课的操作都在**服务器的命令行**和**浏览器的开发者工具**里。

## 你要在这里建两个文件

```text
03-练习代码/
├── 证书信息.md      ← 域名、签发日、到期日、certbot 输出
└── https-验证.md    ← 跳转验证 + 续期演练输出
```

## `证书信息.md` 里写什么

```text
1. 签发前的五项检查结果
2. certbot certificates 的完整输出
3. openssl 的 notBefore / notAfter
4. 你自己算的"还剩几天"
5. 你加进日历的提醒日期
```

**⚠️ 永远不要把 `privkey.pem` 的内容粘进任何文件。** 只写路径，不写内容。

## `https-验证.md` 里写什么

```text
1. curl -I https:// 的第一行
2. curl -I http:// 的完整响应（看 Location）
3. curl -IL 的两段响应
4. certbot renew --dry-run 最后五行
5. 浏览器锁图标的截图（可选）
```
