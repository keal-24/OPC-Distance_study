# 03-练习代码

**这个文件夹里放两个脚本，但它们不是"成品代码"，是你自己敲出来的运维工具。**

## 你要在这里建三个文件

```text
03-练习代码/
├── check-health.sh      ← 用 curl -f 判断健康状态
├── backup.sh            ← 每日备份脚本（再复制到服务器 /srv/app/）
└── 恢复演练记录.md       ← 删除 → 恢复 → 验数据的完整记录
```

**⚠️ `backup.sh` 里不要写真实密码。** 用 `source /srv/app/.env` 读。

## `check-health.sh` 的要求

```text
1. 接受 URL 作为第一个参数，默认 http://127.0.0.1:3000/health
2. 用 curl -f，状态码 200 才算成功
3. 成功 exit 0，失败 exit 1
4. 输出一行结果，包含状态码
```

**写完后用 `echo $?` 验证退出码。** 这是这个脚本唯一的意义。

## `backup.sh` 的要求

```text
1. 第一行 set -euo pipefail
2. 备份数据库（pg_dump -F c）
3. 备份上传文件（tar -czf）
4. 备份 .env（注意权限 600）
5. 清理 7 天前的文件
6. 尝试上传到对象存储（没有就警告，不要失败）
7. 最后打印 ALL DONE
```

## `恢复演练记录.md` 的最低要求

```text
恢复前的行数 + 恢复后的行数 + 两者是否一致
errors ignored on restore 的数字
整个恢复用了多少分钟
```

**"用了多少分钟"这一栏不是凑数 —— 这个数字要写进第 224 节的 RUNBOOK。**
