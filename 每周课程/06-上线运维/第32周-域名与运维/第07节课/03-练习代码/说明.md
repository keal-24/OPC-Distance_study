# 03-练习代码

**这个文件夹里放的是"你项目自己的 RUNBOOK"，不是课件里的模板。**

## 你要在这里建两个文件

```text
03-练习代码/
├── RUNBOOK.md      ← 一页纸：八步排查 + 命令卡 + 找谁 + 回滚
└── 演练记录.md      ← 三个故障的定位/修复耗时
```

## `RUNBOOK.md` 的最低要求

```text
1. 顶部有"最后更新日期"
2. 第 0 节：手机 4G 能开吗（排除自己）
3. 第 1 节：八步排查表，每步都有命令 + "通过的样子"
4. 第 2 节：现象 → 结论
5. 第 3 节：命令卡（按场景分组，能直接复制）
6. 第 4 节：找谁（写到"点哪里"）
7. 第 5 节：回滚（代码 / 配置 / 数据）
8. 第 6 节：每月 1 号六件事
9. 第 7 节：已知脆弱点
```

**⚠️ 一页能看完。** 超了就先删"解释"，只留"命令 + 判断"。

**⚠️ 不写任何密码。** 写"密码在密码管理器的 xxx 条目"。

## `演练记录.md` 的最低要求

```text
至少三个故障
每个都记录：怎么制造的 / 定位多久 / 修复多久 / 卡在哪
最后写出"RUNBOOK 要改的三处"
```

**"卡在哪"必须是真实的。** 写"没有卡住"等于没演练。

## 做完之后还要做两件事

```text
① 复制一份到项目仓库根目录（确认没有密码）
② 导出 PDF / 截图，存到手机相册（确保离线能看）
```
