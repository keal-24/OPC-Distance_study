# w01-地基 · Day 1-7

## 网页与前端基础

---

## 这一周的目标

做出一个能在浏览器打开的页面。周末你能在页面上看到自己的字，改代码浏览器自动刷新。

## 为什么排在这一周

你需要先看到东西。写后端、写算法，跑完屏幕上一行字都没有，你根本不知道自己做对没有。前端是唯一能立刻看到结果的，最适合起步。

## 周末的验收

不要急着进下一周。先确认这三条：

- [ ] 这一周每天都有 commit（打开 GitHub 看绿点，一天都不能缺）
- [ ] `d01/` 到 `d07/` 里都有 `NOTES.md`，而且「卡在哪」写了内容
- [ ] 我能用一句话说清这一周学到了什么

> **第三条才是真标准。** 说不出来，说明这一周只是跟着点了七次，没真的进脑子。
>
> **一周七天，落一天没关系，落三天就等于重来。**
