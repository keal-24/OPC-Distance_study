# 开篇先导课

正式课程开始前，先完成这一节**大杂烩先导课**：

```text
先导课.md
```

这一节一次讲清：

- 现在人工智能时代发生了什么变化；
- 人工智能、大语言模型、智能体、MCP 分别是什么；
- WorkBuddy 和 Codex 分别适合做什么；
- 学完可以找什么方向的工作；
- 可以接什么项目、做什么产品；
- 为什么不能只学会聊天或让人工智能写代码；
- 为什么课程还要讲数据库、数据、服务器、域名、安全和经营；
- 接下来应该怎样学习、怎样留下作品。

看完后再进入正式课程：

```text
每周课程/01-元技能与基础/第01周-AI工具/第01节课/
```

学习记录可以写在：

```text
学习记录.md
```
