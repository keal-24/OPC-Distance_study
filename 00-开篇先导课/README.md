# 开篇先导课：为什么现在值得学 AI 开发

这不是正式课程的第一节技术课，而是正式学习前的**方向课**。

如果你还没有想清楚下面这些问题，先不要急着打开第一节技术课：

- 现在为什么要学人工智能？
- 我学完以后到底能做什么？
- 我没有计算机专业学历，还能不能学？
- 我是为了找工作、接项目，还是做自己的产品？
- 这套课程为什么要学这么多内容？
- 学习过程中遇到困难时，我应该怎么坚持？

## 看完先导课，你应该得到的结果

你不需要听完后马上决定辞职，也不需要相信“学完一定赚钱”这种话。

你只需要得到三样东西：

1. **知道方向**：知道人工智能开发能解决哪些真实问题；
2. **知道路径**：知道自己接下来为什么先学这一项，再学下一项；
3. **知道目标**：知道自己要做出什么作品，而不是只看视频和记概念。

## 重要说明

这套课程不承诺：

- 学完一定找到工作；
- 学完一定月入多少；
- 学完一定接到客户；
- 学完以后不用继续学习。

能不能就业、接项目或做出产品，取决于你的学习时间、实际作品、沟通能力、市场需求和持续行动。

课程能做的是：**把一条尽量完整的学习和交付路线拆开，带你一步一步走，并让每个阶段都留下可以检查的结果。**
