# w04-成本与流式 · Day 22-28

## 让它像产品，不让它烧钱

---

## 这一周的目标

算清每次调用花多少钱，做模型分级和缓存，最后做出打字机效果。

## 为什么排在这一周

不做流式，你的 AI 应用在客户眼里就是点了没反应的网页。这一周是产品感的分界线，也是你第一次能回答「这功能一个月花多少钱」。

---

## 每天做什么

进 `d01/` 到 `d07/`，每天一个文件夹。先读里面的 `TASK.md`，代码写在同一个文件夹，收工写 `NOTES.md`。

## 周末的验收

不要急着进下一周。先确认这三条：

- [ ] 这一周每天都有 commit（打开 GitHub 看绿点，一天都不能缺）
- [ ] `d01/` 到 `d07/` 里都有 `NOTES.md`，而且「卡在哪」写了内容
- [ ] 我能用一句话说清这一周学到了什么

> **第三条才是真标准。** 说不出来，说明这一周只是跟着点了七次，没真的进脑子。
>
> **一周七天，落一天没关系，落三天就等于重来。**
