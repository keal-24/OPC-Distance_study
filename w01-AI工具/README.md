# w01-AI工具 · Day 1-7

## 怎么让 AI 替你写代码

---

## 这一周的目标

把 Codex、Claude Code、Cursor、WorkBuddy 这类工具真正用起来：怎么下指令、怎么验收它的输出、改坏了怎么退回、什么时候不该用它。

## 为什么排在这一周

这是整条路线里唯一的元技能。后面 35 周你都在用 AI 写代码，但没人教过你怎么用。用得好省一半时间，用不好你会花更多时间在调试它写的烂代码上。

---

## 周末的验收

不要急着进下一周。先确认这三条：

- [ ] 这一周每天都有 commit（打开 GitHub 看绿点，一天都不能缺）
- [ ] `d01/` 到 `d07/` 里都有 `NOTES.md`，而且「卡在哪」写了内容
- [ ] 我能用一句话说清这一周学到了什么

> **第三条才是真标准。** 说不出来，说明这一周只是跟着点了七次，没真的进脑子。
