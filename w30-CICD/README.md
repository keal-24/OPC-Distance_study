## 这一周的目标

GitHub Actions 自动化测试与部署、环境变量与密钥管理、发布流程、回滚。

## 为什么排在这一周

你现在每次部署都是 SSH 上去 git pull 再手动重启。一天部署三次就是三遍手动作业，每次都可能出错。一人公司没有运维，能自动化的必须自动化。
