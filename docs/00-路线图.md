# 一人公司 AI 开发 · 196 天完整路线

起点 2026-11-15 · 终点 2027-05-29 · 28 周 · 每天 60–120 分钟

---

## 这份路线要解决什么

不是"学会写代码"。是**一个人把公司跑起来**。

会写代码的人很多，能把公司跑起来的人很少。差别不在技术难度，在于**一串没人告诉你的东西**：数据从哪来、客户从哪来、钱怎么合法收到手、代码归谁、你出事时项目怎么办。

这份路线把它们全排进去了。**196 天，28 周，从写第一行 HTML 到能签合同收钱。**

---

## 排序的三个原则

**原则一：每周必须有能看见的产出**

不能出现"这周学理论，下周才能做东西"。看不见进展的学习，三天就放弃。

**原则二：依赖在前面，应用在后面**

不能先学支付再学数据库。每个技术只出现在它被需要的那一刻。

**原则三：抽象的东西往后放**

前端能看见、AI 能对话，这两块最先做。测试、安全、财务这些看不见的，放在你已经有东西可测、可保护、可收钱之后。

## 六个阶段，读懂为什么这么分

### 阶段一：能看见（W1–W2，Day 1–14）

网页 → 后端 → 连起来 → 存数据库 → 接模型 → 上线

**为什么从这里开始**：你需要看到东西。写后端、写算法，跑完屏幕上一行字都没有，你不知道自己做对没有。

**结束时**：你有一个真的能对话的 AI 应用，别人点链接就能用。

### 阶段二：能用（W3–W5，Day 15–35）

提示词 → 结构化 → 成本 → 流式 → 登录

**为什么紧接着**：第一阶段的产物只是"能回话"。**能回话的东西任何人两天能做出来，不值钱。** 值钱的是"回得准、不烧钱、像产品、知道谁在用"。

### 阶段三：有数据（W6–W9，Day 36–63）**最关键，也最容易被忽略**

**抓数据** → **文档解析** → **检索** → **工具与 Agent**

**为什么单独给四周**：因为 AI 应用的瓶颈从来不是模型，是数据。

客户说"让 AI 懂我们的知识"，你问"知识在哪"，答案永远是这几种：

- "在我们的网站上" → 要爬
- "在这 300 个 PDF 里" → 要解析
- "在我们的数据库里" → 要对接
- "在老王的脑子里" → 没辙，得访谈整理

**你手上没有干净数据，后面再强的模型也白搭。**

顺序是死的：**先拿到（W6），再解析成文字（W7），再让它可被检索（W8），最后让 AI 用这些数据做事（W9）**。

### 阶段四：能靠（W10–W20，Day 64–140）

异步 → 评测 → 可靠 → 工程化 → **测试** → 性能 → 多模态 → 多租户 → 文件支付 → 平台集成 → 前端进阶

**这十一周是"从玩具到产品"的全部距离**：

- 不处理异步 → 长任务一跑就超时
- 不做评测 → 改一处坏三处，还发现不了
- 不做可靠 → 模型一挂，客户投诉
- 不做测试 → 每次改代码都是赌博，而你没人帮你复查
- 不分层 → 加第十个功能就崩
- 不做性能 → 数据一万条就卡
- 不支持图片语音 → 一半场景做不了
- 不支持多租户 → 第二个客户要重写
- 不能导 Excel、不能收钱 → 客户用不起来，你也赚不到
- 不能在企业微信里用 → 客户觉得不专业
- 手机打开排版乱 → 信任直接崩

**这十一周最没人愿意做，但它们决定了你的东西能不能活到客户上线。**

### 阶段五：能上线（W21–W25，Day 141–175）

服务器 → 域名运维 → 安全合规 → 小程序 → 私有化

**为什么放这里**：得先有东西可部署。空着服务器学 Nginx，配置改错了也不知道哪错了。

**这五周决定你的客单价上限**：

- 能部署 → 客户能看到东西
- 有域名有 HTTPS → 客户敢用
- 通过安全检查 → 客户敢把数据给你
- 能做小程序 → 接得住"要在微信里用"的需求
- 能做私有化 → 接得住国企、政府、医院这类高价单

**但有一件事必须提前**：如果你的服务器在国内，**域名备案要 7–20 个工作日**。不能等 Day 148 才去想。见 `02-部署上线.md`。

### 阶段六：能活（W26–W28，Day 176–196）**最多人跳过，最后卡死的地方**

**获客销售** → **财务法务** → **交付脱身**

**为什么必须放在最后三周**：

前面 175 天教你"做出来"。但这三件事决定你能不能**活下来**：

| 缺了会怎样 | 具体后果 |
|---|---|
| **不会获客** | 技术再好，没有客户就是零。这是最多人卡死的地方 |
| **不会报价** | 报低了做一半发现亏，报高了单子跑了 |
| **不会谈合同** | 客户无限加需求，你免费做三个月 |
| **不懂开票报税** | 客户要专票你开不出，这单就黄了 |
| **不懂软著商标** | 代码被客户拿去卖，你没办法 |
| **不懂交付脱身** | 你被一个客户绑死，同时只能干一个项目 |

**这三周不产出代码，但它们决定你前面 25 周能不能变成收入。**

## 每天固定五块

每一份 `TASK.md` 都有这五块，不增不减：

1. **学** —— 一句原理，看懂就行，不用背
2. **做** —— 编号步骤，每步写清点哪里、输什么、看什么，**并说明这一步的目的**
3. **你会看到什么** —— 自检，判断自己走对了没有
4. **可能出错** —— 表格：现象 / 原因 / 怎么办
5. **老板视角** —— 一句话讲清这个技术点对应的管理判断

## 每天的四步

1. **读** `dNN/TASK.md`，从第一句开始，不要跳
2. **做** 在同一个文件夹里写代码
3. **写** `dNN/NOTES.md`：今天做了什么 / 卡在哪 / 怎么解决的
4. **交** VS Code 左侧第三个图标 → 写 `dNN: 主题` → 点 `✓` → **点同步**

## 三条铁律

**一、每天 commit + push**

`commit` 是本地快照，`push` 才是备份。**只 commit 不 push，等于没备份。**

收工打一句 `git status`，看到 `ahead` 就是没推。

**二、`docs` 不要改**

它是刻度。改了就没法对照自己有没有偏离。

**三、`NOTES.md` 比代码重要**

代码 AI 三秒能重写，你踩过的坑只有你自己知道。

## 196 天后你会什么、不会什么

**技术上会**：

- 独立做出能上线的 AI 应用：登录、流式、数据库、识图
- 自己搞数据：调 API、写爬虫、解析 PDF、清洗、增量
- 让 AI 懂客户的私有资料，能调工具、能完成多步任务
- 用数字证明改动好坏，知道该选哪个模型
- 数据涨十倍不卡，搜索真好用
- 接支付、导 Excel、接飞书企微、做多租户
- 做小程序、接微信登录和支付
- 交付私有化部署（数据不出客户内网）
- 有测试、有监控、能回滚、挂了知道
- 通过基本安全检查

**生意上会**：

- 知道客户从哪来，会写提案、会报价、会谈判、会拒单
- 能合法收钱：个体户/公司选择、开票、报税
- 有合同模板，知道哪五条必须写
- 会申请软著，知道代码归谁
- 能把项目交接出去，同时跑几个项目

**不会**：

- 训练模型、微调、推理优化、算法研究
- 大规模分布式架构
- 复杂前端动效和视觉设计
- 融资、招人、股权设计（那是另一个方向）

**最后一句诚实话**：196 天给你的是"一个人能跑通一门生意的完整闭环"。真正的成熟来自第一个真实客户、第一次翻车、第一次自己判断对了。**所以 Day 196 之后别停，立刻接一个真活。**
