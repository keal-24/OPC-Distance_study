## 这一周的目标

做出一个能在浏览器打开的页面。这一周你会亲手写 HTML 和 CSS，不是让 AI 写。

## 为什么排在这一周

你必须先自己写过一遍，才知道 AI 写的东西哪里不对。跳过这一周的人，后面永远只能照抄。

## 周末的验收

不要急着进下一周。先确认这三条：

- [ ] 这一周每天都有 commit（打开 GitHub 看绿点，一天都不能缺）
- [ ] `d01/` 到 `d07/` 里都有 `NOTES.md`，而且「卡在哪」写了内容
- [ ] 我能用一句话说清这一周学到了什么

> **第三条才是真标准。** 说不出来，说明这一周只是跟着点了七次，没真的进脑子。
