# w09-智能体 · Day 57-63

## 工具调用与 Agent

---

## 这一周的目标

先让 AI 能调用你写的函数，再让它自己决定下一步做什么、循环到任务完成。

## 为什么排在这一周

这是 AI 从「会说话」到「会做事」的转折。也是最容易翻车的地方——能跑通 demo 和能稳定用，中间差十倍工作量。

---

## 周末的验收

不要急着进下一周。先确认这三条：

- [ ] 这一周每天都有 commit（打开 GitHub 看绿点，一天都不能缺）
- [ ] `d01/` 到 `d07/` 里都有 `NOTES.md`，而且「卡在哪」写了内容
- [ ] 我能用一句话说清这一周学到了什么

> **第三条才是真标准。** 说不出来，说明这一周只是跟着点了七次，没真的进脑子。
