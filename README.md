## 六个项目，只有一个主线

36 周里你会建六个代码项目。**搞混它们，252 节课结束你会有一堆 demo，没有一个能交付。**

| 项目 | 是什么 | 并回主线吗 |
|---|---|---|
| **`chat-app`** | **主线产品。** 第 18 节课建，一路长到能上线 | 它就是主线 |
| `auth-lab` | 登录 / 权限 / 后台 / 上传的实验室（第 8—10 周） | **要，第 70 节后并回 `chat-app`** |

## 这次补的九个技术缺口

前几轮补的都是"功能清单"。这一轮补的是**底层能力**——那些"不学会一直难受"的东西。

| # | 缺口 | 不学的后果 |
|---|---|---|
| 1 | **AI 编程工具** | 你天天在用，但没人教过。用不好会花更多时间调 AI 写的烂代码 |
| 2 | **Git 分支** | 只能一条线走。同时试两个方案就只能复制文件夹 |
| 3 | **手写 SQL** | 只会 `.insert()`。备份恢复、复杂查询、修脏数据全做不了 |
| 4 | **表单防刷** | 验证码被刷，短信费一夜几千 |
| 5 | **后台管理** | 客户改个字都找你，你变成免费客服 |
| 6 | **文件与图片** | 客户传 10MB 照片，页面卡死 |
| 7 | **实时通信** | 很多需求只能做"刷新页面才能看到" |
| 8 | **通知送达** | 验证码进垃圾箱 = 产品坏了 |
| 9 | **Docker + CI/CD** | 每次部署三遍手工作业，每次都可能出错 |

## 每节课的四步

**1. 读 `01-任务/TASK.md`** —— 从第一句开始，不要跳

**2. 在 `03-练习代码/` 里自己新建文件、自己敲** —— **不要复制粘贴**

> 这个文件夹故意留空，只有一份 `说明.md`。
> 课件里的代码是对照用的标准答案，不是素材。
> 复制粘贴只会手会，脑子没会；敲错了报错，才知道报错长什么样。

**3. 收工写 `02-笔记/NOTES.md`**

```markdown
本节课做了什么：
卡在哪：
怎么解决的：
```

**「卡在哪」别空着。** 代码 AI 三秒能重写，你踩过的坑只有你自己知道。

**4. 提交** —— 左侧第三个图标 → 写 `第01节课: 主题` → 点 `✓` → **点同步**

## 三条铁律

**一、每节课 commit + push**

`commit` 只是本地快照，`push` 才是云端备份。**只 commit 不 push 等于没备份。**

收工打 `git status`，看到 `ahead` 就是没推。

**二、`参考手册` 不要改**

它是刻度。

**三、`NOTES.md` 比代码重要**

代码能重写，坑不能。
